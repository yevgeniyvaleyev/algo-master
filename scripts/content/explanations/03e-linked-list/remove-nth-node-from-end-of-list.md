## Задача простыми словами

Дан связный список и число `n`. Нужно удалить **`n`-й узел с конца** и вернуть голову получившегося списка. Гарантируется, что `n` не больше длины списка.

Пример: `head = [1, 2, 3, 4, 5]`, `n = 2`. Второй с конца — узел `4`. Ответ `[1, 2, 3, 5]`. Если `head = [1]`, `n = 1`, удаляется единственный узел и ответ — пустой список.

## Наивный подход

В односвязном списке нельзя идти с конца. Очевидное решение — два прохода: сначала посчитать длину `sz`, потом дойти до узла перед удаляемым (он стоит на позиции `sz - n` с начала, если нумеровать с 1) и перешагнуть через удаляемый:

```ts naive
let sz = 0;
for (let c = head; c !== null; c = c.next) sz++;
const dummy = new ListNode(0, head);
let prev = dummy;
for (let i = 0; i < sz - n; i++) prev = prev.next!;
prev.next = prev.next!.next;
return dummy.next;
```

Это `O(sz)` по времени и `O(1)` по памяти — асимптотически уже оптимально. Но список проходится **дважды**: первый проход нужен только для того, чтобы узнать, где конец. Follow-up задачи просит сделать всё за **один проход**.

## Ключевое наблюдение

«`n`-й с конца» — это «стоящий на расстоянии `n` от конца». Если пустить два указателя с **фиксированным зазором**, то, когда передний дойдёт до конца, задний окажется ровно на нужном расстоянии от него. Длину знать не нужно: зазор отмеряет её за нас.

Нам нужен не сам удаляемый узел, а узел **перед ним** — поэтому зазор делаем `n + 1`.

## Техники

### Два указателя с зазором (fast / slow)

**Что это.** Два указателя идут по списку с одинаковой скоростью, но один стартует раньше на фиксированное число шагов. Расстояние между ними всё время постоянно.

**Типичный шаблон:**

```ts naive
let fast = head, slow = head;
for (let i = 0; i < gap; i++) fast = fast.next;
while (fast !== null) { fast = fast.next; slow = slow.next; }
// slow — на расстоянии gap от конца
```

**Когда применять.** Нужен элемент на заданном расстоянии **от конца** (`k`-й с конца, точка поворота списка), а длина заранее неизвестна. Родственный вариант — указатели с разной скоростью (середина списка, поиск цикла). Подробнее о методе двух указателей — во вкладке «Теория».

**Как применяется здесь.** Зазор `n + 1` от заглушки: когда `fast` станет `null` (выйдет за последний узел), `slow` окажется прямо перед удаляемым узлом.

### Фиктивная голова (dummy)

Если удаляется сама голова (`n` равно длине списка), «узла перед удаляемым» в списке нет. Заглушка перед головой играет его роль, и удаление головы ничем не отличается от остальных. Ответ — `dummy.next`.

## Разбор кода

```ts
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
  // Заглушка: удаление самой головы не требует особого случая
  const dummy = new ListNode(0, head);
  let fast: ListNode | null = dummy;
  let slow: ListNode = dummy;
```

Оба указателя стартуют с заглушки. `fast` может стать `null` (он уйдёт за конец), а `slow` — никогда: он всегда стоит на реальном узле или заглушке.

```ts
  // Уводим fast на n + 1 шаг вперёд: между slow и fast будет ровно n узлов
  for (let i = 0; i <= n; i++) fast = fast!.next;
```

Цикл с `i <= n` выполняется `n + 1` раз. Длина списка `sz >= n`, а с заглушкой узлов `sz + 1`, поэтому `fast` в худшем случае станет `null` ровно на последнем шаге — `fast!` безопасен.

```
n = 2, после разгона (3 шага):
dummy -> 1 -> 2 -> 3 -> 4 -> 5
slow              fast
```

```ts
  // Двигаем оба, пока fast не выйдет за конец списка
  while (fast !== null) {
    fast = fast.next;
    slow = slow.next!;
  }
```

Двигаем оба указателя синхронно, сохраняя зазор `n + 1`. Цикл останавливается, когда `fast` стал `null` — то есть стоит на воображаемой позиции «после последнего узла». `slow` в этот момент на `n + 1` позиций левее: `n` позиций до конца занимает удаляемый узел и узлы после него, значит, `slow` — прямо перед удаляемым.

```ts
  // slow стоит прямо перед удаляемым узлом — перешагиваем через него
  slow.next = slow.next!.next;
```

Удаление в односвязном списке: предшественник «перешагивает» через узел. Удалённый узел больше недостижим из головы. `slow.next!` безопасен: `n >= 1`, значит, после `slow` есть хотя бы один узел.

```ts
  return dummy.next;
}
```

Если удалили голову, `dummy.next` уже указывает на второй узел (или `null`). Возвращать исходный `head` было бы ошибкой именно в этом случае.

## Трассировка

`head = [1, 2, 3, 4, 5]`, `n = 2`.

Разгон `fast` (3 шага от `dummy`): `1`, `2`, `3`. `slow = dummy`.

Синхронное движение:

1. `fast = 4`, `slow = 1`.
2. `fast = 5`, `slow = 2`.
3. `fast = null`, `slow = 3`. Цикл завершён.

`slow = 3`, `slow.next = 4` — удаляемый. `3.next = 5`.

```
dummy -> 1 -> 2 -> 3 -> 5        (4 вырезан)
```

Ответ `[1, 2, 3, 5]`.

Удаление головы: `head = [1, 2]`, `n = 2`. Разгон: `fast = 1`, `2`, `null`. Цикл `while` не выполняется, `slow = dummy`. `dummy.next = 1.next = 2`. Ответ `[2]`.

Единственный узел: `head = [1]`, `n = 1`. Разгон: `fast = 1`, `null`. `slow = dummy`, `dummy.next = null`. Ответ `[]`.

## Почему это работает

Пронумеруем позиции: заглушка — `0`, узлы — `1..sz`, «после конца» (`null`) — `sz + 1`. После разгона `fast` на позиции `n + 1`, `slow` — на `0`; разница `n + 1`. В цикле оба сдвигаются на 1, разница сохраняется. Цикл заканчивается, когда `fast` на позиции `sz + 1`, значит, `slow` на позиции `sz - n`. `n`-й узел с конца имеет позицию `sz - n + 1`, то есть стоит сразу после `slow`. Именно его мы и вырезаем.

## Пограничные случаи

- **Удаление головы** (`n = sz`): `slow` остаётся на заглушке, ответ `dummy.next`.
- **Удаление последнего узла** (`n = 1`): `slow` — предпоследний узел, `slow.next` становится `null`.
- **Список из одного узла**: результат — пустой список (`null`).
- **`n` равно длине**: разгон ровно доводит `fast` до `null`, ошибки доступа нет.

## Сложность

- **Время `O(sz)`**: `fast` проходит список один раз (разгон + синхронный цикл — суммарно `sz + 1` шагов), `slow` — меньше. Один проход.
- **Память `O(1)`**: два указателя и заглушка.

## Типичные ошибки

1. **Зазор `n` вместо `n + 1`** → `slow` встаёт на сам удаляемый узел, а удалить узел, не зная предшественника, нельзя.
2. **Без заглушки** → при `n = sz` нет предшественника, нужен особый случай; без него — ошибка доступа к `null`.
3. **Возвращать `head`** вместо `dummy.next` → при удалении головы возвращается удалённый узел.
4. **Условие `while (fast.next !== null)`** при старте с заглушки и зазоре `n + 1` → сдвиг на одну позицию; условие и зазор должны быть согласованы.
5. **Нумерация «с конца» с нуля** → удаляется соседний узел.

## Как узнать такую задачу

- Нужен элемент на заданной позиции **от конца** односвязного списка, а длина неизвестна или просят один проход.
- Ключевые слова: «`k`-й с конца», «последние `k` узлов», «повернуть на `k`».
- Удаление, при котором может пострадать голова, — сигнал к заглушке. Родственные задачи: Middle of the Linked List и Linked List Cycle (fast/slow с разной скоростью), Rotate List, Swapping Nodes in a Linked List.
