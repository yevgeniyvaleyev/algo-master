## Задача простыми словами

Даны два непустых связных списка, каждый из которых хранит неотрицательное число **по цифрам в обратном порядке**: голова — это разряд единиц, следующий узел — десятки и так далее. Нужно сложить числа и вернуть сумму в таком же виде — новым списком с цифрами от младшей к старшей.

Пример: `l1 = [2, 4, 3]` — это число `342`, `l2 = [5, 6, 4]` — число `465`. Сумма `807`, в обратном порядке — `[7, 0, 8]`.

## Наивный подход

Первое, что приходит в голову: «собрать» оба числа, сложить их обычным `+` и разложить результат обратно в список.

```ts naive
function toNumber(l: ListNode | null): number {
  let x = 0, mul = 1;
  for (; l !== null; l = l.next, mul *= 10) x += l.val * mul;
  return x;
}
let s = toNumber(l1) + toNumber(l2);
// ...разложить s по цифрам в новый список
```

По времени это `O(n + m)`, но решение **неверно**: в списке может быть до 100 узлов, то есть число до `10¹⁰⁰`, а `number` в JS точно хранит только целые до `2⁵³ ≈ 9·10¹⁵`. Уже на 17-й цифре начнутся потери. Можно перейти на `BigInt`, но это лишняя работа: мы превращаем цифры в число, чтобы потом снова разобрать число на цифры. Список **уже** разложен по разрядам — ровно так, как удобно складывать.

## Ключевое наблюдение

Цифры лежат от младшей к старшей — в том же порядке, в котором мы складываем числа «в столбик» на бумаге. Значит, можно идти по двум спискам одновременно, складывать текущие цифры плюс перенос из предыдущего разряда, записывать в ответ `sum % 10`, а перенос `Math.floor(sum / 10)` отдавать дальше. Никаких больших чисел: каждая сумма не превышает `9 + 9 + 1 = 19`.

## Техники

### Сложение в столбик с переносом

**Что это.** Классический школьный алгоритм: разряды обрабатываются от младшего к старшему, в каждом разряде `сумма = a + b + перенос`, в ответ идёт `сумма % 10`, новый перенос — `сумма / 10` (целая часть). Перенос при сложении двух чисел — всегда `0` или `1`.

**Когда применять.** Любая «длинная арифметика»: сложение чисел-строк (Add Strings), двоичных строк (Add Binary), прибавление единицы к массиву цифр (Plus One). Сигнал — числа заданы цифрами и могут не помещаться в машинный тип.

**Как применяется здесь.** Обратный порядок цифр означает, что разряды идут ровно в порядке обхода списка — разворачивать ничего не надо.

### Фиктивная голова (dummy)

**Что это.** Узел-заглушка перед началом строящегося списка. К нему пристраиваем узлы через указатель `tail`, а в конце возвращаем `dummy.next`.

**Типичный шаблон.**

```ts naive
const dummy = new ListNode(0);
let tail = dummy;
// ... tail.next = новыйУзел; tail = tail.next;
return dummy.next;
```

**Как применяется здесь.** Без заглушки первый узел ответа пришлось бы создавать отдельной веткой (`if (head === null) head = ...`). С ней все узлы добавляются одинаково. Подробнее о базовых приёмах со связными списками — во вкладке «Теория».

### Обработка списков разной длины через «нулевую цифру»

Вместо трёх циклов (пока есть оба списка / остаток первого / остаток второго) — один цикл, где закончившийся список просто «выдаёт» цифру `0`. В TypeScript это коротко записывается через `?.` и `??`.

## Разбор кода

```ts
function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
  // Фиктивная голова — не нужно отдельно создавать первый узел ответа
  const dummy = new ListNode(0);
  let tail = dummy;
  let carry = 0; // перенос в следующий разряд (0 или 1)
```

Подготовка. `dummy` — заглушка, её значение `0` ни на что не влияет и в ответ не попадёт. `tail` всегда указывает на последний узел ответа — туда пристраиваем следующую цифру. `carry` — перенос из предыдущего разряда; для разряда единиц он равен `0`.

```ts
  // Идём, пока есть цифры хотя бы в одном списке или остался перенос
  while (l1 !== null || l2 !== null || carry > 0) {
```

Условие цикла — самая важная строка. Три причины продолжать:

- в `l1` ещё есть цифры;
- в `l2` ещё есть цифры;
- оба списка закончились, но остался перенос — например, `5 + 5 = 10`: после единиц нужно дописать старшую `1`.

Если забыть третью часть, ответ для `[5] + [5]` будет `[0]` вместо `[0, 1]`.

```ts
    // Отсутствующая цифра более короткого числа считается нулём
    const sum = (l1?.val ?? 0) + (l2?.val ?? 0) + carry;
```

`l1?.val` — если `l1` равен `null`, выражение даёт `undefined`, и `?? 0` превращает его в `0`. Так короткое число как бы дополняется ведущими нулями: `342 + 5` считается как `342 + 005`. Сумма лежит в диапазоне `0..19`.

```ts
    carry = Math.floor(sum / 10);
    tail.next = new ListNode(sum % 10); // в разряд идёт последняя цифра суммы
    tail = tail.next;
```

Разбиваем сумму на две части: `sum % 10` — цифра текущего разряда, `Math.floor(sum / 10)` — перенос (`0` или `1`). Создаём новый узел, пристраиваем его к хвосту и сдвигаем `tail`. Новые узлы создаются, а не переиспользуются узлы входа — входные списки остаются нетронутыми.

```ts
    l1 = l1?.next ?? null;
    l2 = l2?.next ?? null;
  }
```

Переходим к следующему разряду в обоих списках. Если список уже закончился (`l1 === null`), `l1?.next` даёт `undefined`, а `?? null` возвращает аккуратный `null` — тип переменной остаётся `ListNode | null`.

```ts
  return dummy.next;
}
```

Настоящий ответ начинается после заглушки. Список гарантированно непуст: входы непустые, значит, цикл выполнится хотя бы раз.

## Трассировка

`l1 = [2, 4, 3]` (342), `l2 = [5, 6, 4]` (465):

```
шаг  l1.val l2.val carry  sum  цифра  новый carry  ответ
1    2      5      0      7    7      0            7
2    4      6      0      10   0      1            7 -> 0
3    3      4      1      8    8      0            7 -> 0 -> 8
```

После шага 3 оба списка `null`, `carry = 0` — цикл завершается. Ответ `[7, 0, 8]`, то есть `807`.

Пример с переносом за пределы обоих списков: `l1 = [9, 9]` (99), `l2 = [1]` (1):

1. `sum = 9 + 1 + 0 = 10` → цифра `0`, `carry = 1`. `l1` → второй узел, `l2` → `null`.
2. `sum = 9 + 0 + 1 = 10` → цифра `0`, `carry = 1`. Оба списка `null`.
3. Списков нет, но `carry > 0`: `sum = 0 + 0 + 1 = 1` → цифра `1`, `carry = 0`.
4. Условие ложно — выход. Ответ `[0, 0, 1]`, то есть `100`.

## Почему это работает

Инвариант цикла: после обработки `k` разрядов список ответа содержит ровно `k` младших цифр суммы, а `carry` равен переносу в разряд `k`. Это прямо следует из правил сложения в столбик: цифра `k`-го разряда суммы равна `(a_k + b_k + перенос) mod 10`, а новый перенос — целой части от деления на 10.

Цикл завершается, когда у обоих чисел не осталось цифр **и** нет переноса — значит, все старшие разряды суммы нулевые, и записывать больше нечего. Ведущих нулей в ответе не появится: последний записанный разряд — либо цифра одного из чисел в старшем разряде (ненулевая, кроме случая самого числа `0`), либо перенос `1`.

## Пограничные случаи

- **Разная длина** (`[1, 8] + [0]`): короткое число дополняется нулями через `?? 0`.
- **Перенос в новый разряд** (`[9, 9] + [1]`): ответ длиннее обоих входов на один узел — обеспечивает `carry > 0` в условии.
- **Оба числа — ноль** (`[0] + [0]`): один шаг, ответ `[0]`.
- **Длинные числа** (100 цифр): никаких переполнений — работаем только с цифрами.

## Сложность

- **Время `O(max(n, m))`**: каждая итерация обрабатывает один разряд, разрядов не больше `max(n, m) + 1`; тело цикла — `O(1)`.
- **Память `O(1)` дополнительно**: только `dummy`, `tail`, `carry`. Сам ответ занимает `O(max(n, m))` узлов, но это выходные данные, их обычно не считают.

## Типичные ошибки

1. **Собирать числа в `number`** → потеря точности после ~15–16 цифр.
2. **Забыть `carry > 0` в условии цикла** → теряется старшая единица (`[5] + [5]` даёт `[0]`).
3. **Отдельные циклы для «хвостов»** длинного списка, где забывают продолжать учитывать перенос (`[9, 9, 9] + [1]`).
4. **Возвращать `dummy` вместо `dummy.next`** → в ответе лишний ведущий узел `0`.
5. **Писать `l1 = l1.next` без проверки на `null`** → ошибка доступа к свойству `null`, когда короткий список закончился.

## Как узнать такую задачу

- Числа заданы **поразрядно** (списком, строкой, массивом) и могут быть **длиннее машинного типа**.
- Цифры уже идут от младшего разряда — можно складывать на лету; если от старшего (Add Two Numbers II), их сначала разворачивают или кладут в стек.
- Нужно построить новый список из вычисленных значений — сигнал к заглушке `dummy` и указателю `tail`. Похожие задачи: Add Binary, Add Strings, Plus One, Multiply Strings, Merge Two Sorted Lists (тот же шаблон сборки ответа).
