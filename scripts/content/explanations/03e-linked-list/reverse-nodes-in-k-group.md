## Задача простыми словами

Дан связный список и число `k`. Нужно разбить список на группы по `k` узлов подряд и **развернуть каждую группу**. Если в конце осталось меньше `k` узлов, они остаются в исходном порядке. Значения менять нельзя — только связи.

Пример: `head = [1, 2, 3, 4, 5]`, `k = 2`. Группы `[1, 2]`, `[3, 4]` и неполный остаток `[5]`. Ответ `[2, 1, 4, 3, 5]`. При `k = 3` получится `[3, 2, 1, 4, 5]`.

## Наивный подход

Можно сложить узлы в массив, развернуть в нём каждый отрезок длины `k` и заново перевесить `next` по массиву:

```ts naive
const nodes: ListNode[] = [];
for (let c = head; c !== null; c = c.next) nodes.push(c);
for (let s = 0; s + k <= nodes.length; s += k) {
  // развернуть nodes[s .. s + k - 1]
}
for (let i = 0; i < nodes.length; i++) nodes[i].next = nodes[i + 1] ?? null;
return nodes[0];
```

Время `O(n)`, но память `O(n)` — а follow-up задачи прямо просит `O(1)`. Массив нужен лишь для того, чтобы знать, где кончается группа и что идёт после неё. Эти два узла можно найти прямо в списке, пройдя `k` шагов.

## Ключевое наблюдение

Каждую группу можно обрабатывать независимо, если знать **четыре узла**:

```
groupPrev -> [first -> ... -> kth] -> groupNext
```

- `groupPrev` — последний узел уже готовой части;
- `first` и `kth` — первый и последний узлы группы;
- `groupNext` — начало следующей группы.

Группа разворачивается обычным разворотом списка, после чего `kth` становится её началом, а `first` — концом. Пришиваем: `groupPrev.next = kth`, а `first.next = groupNext`. Затем `first` становится новым `groupPrev`. Прежде чем разворачивать, проверяем, что `kth` существует, — так неполный остаток не трогаем.

## Техники

### Разворот связного списка тремя указателями

**Что это.** Базовая операция: идём по узлам, держа `prev`, `curr` и `next`, и каждый `curr.next` перенаправляем на `prev`.

```ts naive
let prev = null, curr = head;
while (curr !== null) {
  const next = curr.next;
  curr.next = prev;
  prev = curr;
  curr = next;
}
// prev — новая голова
```

**Как применяется здесь.** Разворачиваем не до `null`, а до `groupNext`, и начинаем не с `prev = null`, а с `prev = groupNext`. Тогда бывший первый узел группы сразу указывает на следующую группу — один стык пришит «бесплатно».

### Фиктивная голова (dummy)

Первая группа меняет голову списка. Заглушка перед головой даёт ей предшественника, поэтому первая группа обрабатывается так же, как остальные, а ответ — `dummy.next`.

### Обработка «по кускам» с якорем

Указатель `groupPrev` — это якорь: всё до него уже готово, всё после — ещё исходное. Каждая итерация внешнего цикла обрабатывает одну группу и сдвигает якорь на её конец. Подробнее о приёмах работы со связными списками — во вкладке «Теория».

## Разбор кода

```ts
function reverseKGroup(head: ListNode | null, k: number): ListNode | null {
  const dummy = new ListNode(0, head);
  // groupPrev — последний узел уже обработанной части (перед текущей группой)
  let groupPrev: ListNode = dummy;
```

Заглушка и якорь. В начале обработанной части нет, поэтому якорь — сама заглушка.

```ts
  while (true) {
    // Ищем k-й узел группы; если узлов меньше k — остаток не трогаем
    let kth: ListNode | null = groupPrev;
    for (let i = 0; i < k && kth !== null; i++) kth = kth.next;
    if (kth === null) break;
```

От якоря делаем `k` шагов: после них `kth` стоит на `k`-м узле группы. Проверка `kth !== null` в условии цикла не даёт обратиться к `null.next`, если узлы кончились раньше. Если `kth` оказался `null`, в группе меньше `k` узлов — выходим, остаток не трогаем. Выход из `while (true)` — только здесь.

```ts
    const groupNext = kth.next; // первый узел следующей группы
```

Запоминаем, что идёт после группы, пока связи не поменялись.

```ts
    // Разворачиваем группу. Начинаем с prev = groupNext,
    // чтобы бывший первый узел сразу указал на следующую группу
    let prev: ListNode | null = groupNext;
    let curr: ListNode | null = groupPrev.next;
    while (curr !== groupNext) {
      const next: ListNode | null = curr!.next;
      curr!.next = prev;
      prev = curr;
      curr = next;
    }
```

Стандартный разворот трёх указателей, но с двумя отличиями:

- `prev` стартует с `groupNext`: первый узел группы после разворота укажет на начало следующей группы — правый стык готов;
- цикл идёт до `groupNext`, а не до `null`: разворачиваем ровно `k` узлов.

`curr!` — `curr` не может быть `null` внутри цикла: группа полная, и до `groupNext` мы дойдём раньше конца списка.

```ts
    // Бывший первый узел группы теперь её хвост
    const groupTail = groupPrev.next!;
    groupPrev.next = kth; // k-й узел стал началом группы
    groupPrev = groupTail; // следующая группа пришивается к хвосту
  }
```

Левый стык. `groupPrev.next` всё ещё указывает на **бывший первый** узел группы (мы не трогали `groupPrev`), а он теперь последний — сохраняем его как `groupTail`. Затем `groupPrev.next = kth`: якорь указывает на новое начало группы. Наконец, якорь переезжает на хвост группы — перед следующей группой.

```ts
  return dummy.next;
}
```

Голова результата — после заглушки (после первой группы это бывший `k`-й узел).

## Трассировка

`head = [1, 2, 3, 4, 5]`, `k = 2`.

**Группа 1.** `groupPrev = dummy`. Шаги: `kth = 1`, `kth = 2`. `groupNext = 3`.

Разворот, `prev = 3`, `curr = 1`:

1. `next = 2`, `1.next = 3`, `prev = 1`, `curr = 2`.
2. `next = 3`, `2.next = 1`, `prev = 2`, `curr = 3` — равен `groupNext`, стоп.

`groupTail = dummy.next = 1`, `dummy.next = 2`, `groupPrev = 1`.

```
dummy -> 2 -> 1 -> 3 -> 4 -> 5
```

**Группа 2.** `groupPrev = 1`. Шаги: `kth = 3`, `kth = 4`. `groupNext = 5`.

Разворот: `3.next = 5`, затем `4.next = 3`. `groupTail = 1.next = 3`, `1.next = 4`, `groupPrev = 3`.

```
dummy -> 2 -> 1 -> 4 -> 3 -> 5
```

**Группа 3.** `groupPrev = 3`. Шаги: `kth = 5`, затем `kth = 5.next = null`. Цикл поиска останавливается, `kth === null` → `break`.

Ответ `[2, 1, 4, 3, 5]`. Узел `5` остался на месте.

## Почему это работает

Инвариант внешнего цикла: от `dummy` до `groupPrev` включительно стоят все уже обработанные группы в правильном (развёрнутом) виде, а `groupPrev.next` указывает на первый ещё не обработанный узел, после которого остаток списка не тронут.

Итерация либо обнаруживает, что до конца меньше `k` узлов, и выходит — тогда остаток по условию и должен остаться как есть; либо разворачивает ровно `k` узлов. После разворота правый стык верен (первый узел указывает на `groupNext` за счёт стартового `prev`), левый — благодаря `groupPrev.next = kth`. Якорь переходит на хвост группы, и инвариант снова выполнен. Каждая итерация продвигает якорь на `k` узлов, поэтому цикл конечен.

## Пограничные случаи

- **`k = 1`**: каждая «группа» из одного узла, разворот ничего не меняет — список возвращается как есть.
- **`k = n`**: весь список разворачивается одной группой.
- **`n` кратно `k`**: последняя группа полная, затем поиск `kth` упирается в `null`, выход.
- **Остаток меньше `k`**: не трогается, связи сохраняются благодаря тому, что поиск `kth` ничего не меняет.

## Сложность

- **Время `O(n)`**: каждый узел посещается константное число раз — один раз при поиске `kth` и один раз при развороте (плюс последний неполный поиск, не длиннее `k`).
- **Память `O(1)`**: несколько указателей, без рекурсии и массивов. Рекурсивное решение выглядит короче, но тратит `O(n / k)` памяти на стек.

## Типичные ошибки

1. **Разворачивать, не проверив, что в группе `k` узлов** → неполный остаток тоже развернётся.
2. **Начинать разворот с `prev = null`** → бывший первый узел указывает в никуда, хвост списка теряется (если не пришить отдельно).
3. **Взять `groupTail` после `groupPrev.next = kth`** → получите `kth`, а не хвост; следующая группа пришьётся не туда.
4. **Не сдвигать `groupPrev`** → бесконечный цикл, одна и та же группа разворачивается туда-обратно.
5. **Забыть заглушку** → после первой группы `head` указывает на бывший первый узел, а он уже не голова.

## Как узнать такую задачу

- Нужно преобразовать список **кусками фиксированного размера** (развернуть, переставить пары).
- Неполный кусок в конце обрабатывается особо.
- Ограничение `O(1)` памяти при работе с подсписками — сигнал к якорю `groupPrev` и пришиванию двух стыков. Родственные задачи: Swap Nodes in Pairs (это `k = 2`), Reverse Linked List II, Reverse Linked List.
