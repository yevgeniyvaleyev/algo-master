## Задача простыми словами

Дан связный список и число `k`. Нужно **повернуть список вправо на `k` позиций**: каждый шаг последний узел переезжает в начало. Вернуть новую голову.

Пример: `head = [1, 2, 3, 4, 5]`, `k = 2`. После одного шага `[5, 1, 2, 3, 4]`, после второго — `[4, 5, 1, 2, 3]`. По сути, последние `k` узлов переносятся в начало целиком.

`k` может быть огромным (до `2·10⁹`), а длина — до 500.

## Наивный подход

Повторить `k` раз «перенести последний узел в начало»:

```ts naive
for (let step = 0; step < k; step++) {
  let prev = head!;
  while (prev.next!.next !== null) prev = prev.next!; // предпоследний
  const last = prev.next!;
  prev.next = null;
  last.next = head;
  head = last;
}
```

Каждый шаг — проход до предпоследнего узла, `O(n)`, итого `O(n · k)`. При `k = 2·10⁹` это безнадёжно. Лишняя работа двойная: во-первых, **каждые `n` поворотов** список возвращается в исходное состояние, так что почти все шаги бессмысленны; во-вторых, даже нужные `k mod n` шагов не надо делать по одному — их результат известен сразу.

## Ключевое наблюдение

1. Поворот на `n` позиций — тождественный, поэтому достаточно `k % n`.
2. Результат поворота на `k` — это тот же циклический порядок узлов, только **разрезанный в другом месте**: новый хвост — `(n - k)`-й узел с начала, новая голова — следующий за ним.

Значит, можно мысленно замкнуть список в кольцо (`tail.next = head`) и разорвать его после `(n - k)`-го узла. Две операции перевешивания указателей вместо `k` перестановок.

```
1 -> 2 -> 3 | 4 -> 5        n = 5, k = 2, разрез после 3-го узла
4 -> 5 -> 1 -> 2 -> 3
```

## Техники

### Сведение по модулю

**Что это.** Если операция периодична (повторение `n` раз возвращает исходное состояние), то `k` применений эквивалентны `k mod n`. Это первый шаг в любой задаче с «поворотом», «сдвигом» или «циклом» при больших `k`.

**Как применяется здесь.** `k %= n` — после этого `0 <= k < n`, а `k = 0` означает, что список менять не нужно.

### Кольцо и разрез

**Что это.** Поворот последовательности — это выбор новой точки начала в её циклическом порядке. Для связного списка это особенно дёшево: замыкание и разрыв — по одному присваиванию.

**Как применяется здесь.** Сначала находим длину и хвост (один проход), затем доходим до нового хвоста (второй, неполный проход), разрываем после него и пришиваем старый хвост к старой голове. Подробнее о связных списках — во вкладке «Теория».

### Длина + хвост за один проход

Типичный приём: при подсчёте длины держать ссылку на последний узел — она понадобится для пришивания, и второй раз искать конец не придётся.

## Разбор кода

```ts
function rotateRight(head: ListNode | null, k: number): ListNode | null {
  // Пустой список и список из одного узла не меняются
  if (head === null || head.next === null) return head;
```

Базовый случай: при `0` или `1` узле любой поворот ничего не меняет. Заодно дальше гарантировано `n >= 2`, и деление по модулю безопасно.

```ts
  // Считаем длину и заодно находим хвост
  let n = 1;
  let tail: ListNode = head;
  while (tail.next !== null) {
    tail = tail.next;
    n++;
  }
```

Стартуем с `n = 1` на голове и идём, пока у `tail` есть следующий узел. После цикла `tail` — последний узел, `n` — длина списка. Условие `tail.next !== null` (а не `tail !== null`) нужно, чтобы остановиться **на** последнем узле, а не за ним.

```ts
  // Поворот на n позиций возвращает список в исходное состояние
  k %= n;
  if (k === 0) return head;
```

Сводим `k` к диапазону `0..n-1`. Если поворачивать нечего, возвращаем список как есть — без этой проверки дальше получилось бы `newTail = tail`, `newHead = null`, и ответ сломался бы.

```ts
  // Новый хвост — (n - k)-й узел с начала, новая голова — следующий за ним
  let newTail: ListNode = head;
  for (let i = 1; i < n - k; i++) newTail = newTail.next!;
  const newHead = newTail.next;
```

Последние `k` узлов уходят в начало, значит, первые `n - k` узлов становятся концом, и последний из них — `newTail`. От головы (позиция 1) делаем `n - k - 1` шагов — цикл `i = 1 .. n - k - 1`. `newHead` — узел сразу после нового хвоста; при `1 <= k < n` он гарантированно существует.

```ts
  // Разрываем список после newTail и пришиваем старую голову к старому хвосту
  newTail.next = null;
  tail.next = head;

  return newHead;
}
```

Два присваивания: `newTail` становится концом списка, а бывший хвост указывает на бывшую голову — кусок `[newHead .. tail]` теперь стоит перед `[head .. newTail]`. Возвращаем `newHead`.

## Трассировка

`head = [1, 2, 3, 4, 5]`, `k = 2`:

1. Подсчёт: `tail` проходит `1 → 2 → 3 → 4 → 5`, `n = 5`, `tail = 5`.
2. `k = 2 % 5 = 2`, не ноль.
3. Поиск нового хвоста, `n - k = 3`: `i = 1` → `newTail = 2`; `i = 2` → `newTail = 3`; `i = 3` — стоп. `newHead = 4`.
4. `3.next = null`, `5.next = 1`.

```
до:     1 -> 2 -> 3 -> 4 -> 5 -> null
после:  4 -> 5 -> 1 -> 2 -> 3 -> null
```

Ответ `[4, 5, 1, 2, 3]`.

Большое `k`: `head = [0, 1, 2]`, `k = 4`. `n = 3`, `tail = 2`. `k = 4 % 3 = 1`. `n - k = 2`: `i = 1` → `newTail = 1`, стоп. `newHead = 2`. `1.next = null`, `2.next = 0`. Ответ `[2, 0, 1]` — то же, что после одного поворота.

## Почему это работает

Поворот вправо на `k` (при `0 < k < n`) переводит последовательность `a₁ … aₙ` в `aₙ₋ₖ₊₁ … aₙ a₁ … aₙ₋ₖ`. Код строит ровно это: узел `aₙ₋ₖ₊₁` (`newHead`) становится головой, цепочка от него до `aₙ` (`tail`) не тронута, `aₙ` указывает на `a₁` (`tail.next = head`), цепочка `a₁ … aₙ₋ₖ` не тронута, а `aₙ₋ₖ` (`newTail`) завершает список. Сведение `k %= n` корректно, потому что поворот на `n` — тождественное преобразование.

## Пограничные случаи

- **Пустой список или один узел**: возвращается как есть.
- **`k = 0`** или **`k` кратно `n`**: после `k %= n` получается `0`, список не меняется.
- **`k > n`**: работает через модуль, без лишних кругов.
- **`k = n - 1`**: новый хвост — голова, `newHead` — второй узел; цикл поиска не выполняется ни разу.

## Сложность

- **Время `O(n)`**: первый проход — ровно `n - 1` шагов, второй — меньше `n`. От `k` время не зависит.
- **Память `O(1)`**: несколько указателей, узлы не создаются и не копируются.

## Типичные ошибки

1. **Крутить по одному `k` раз** → `O(n · k)`, превышение времени при больших `k`.
2. **Забыть `k %= n`** → цикл поиска `newTail` уходит за конец списка.
3. **Не обработать `k % n === 0`** → `newHead` равен `null`, а `tail.next = head` создаёт кольцо.
4. **Ошибка на единицу** в поиске нового хвоста (`n - k` шагов вместо `n - k - 1`) → поворот на `k - 1`.
5. **Забыть `newTail.next = null`** → список зацикливается.

## Как узнать такую задачу

- «Повернуть», «сдвинуть циклически», «переставить последние `k` в начало».
- `k` может быть **больше длины** — почти наверняка нужно `k % n`.
- Решение — найти точку разреза, а не двигать элементы по одному. Родственные задачи: Rotate Array (тот же модуль, разворот трёх отрезков), Remove Nth Node From End of List (найти узел на расстоянии от конца), Split Linked List in Parts.
