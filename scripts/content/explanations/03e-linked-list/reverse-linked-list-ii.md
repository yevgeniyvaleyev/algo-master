## Задача простыми словами

Дан односвязный список и две позиции `left <= right` (нумерация с 1). Нужно развернуть **только участок** с `left`-го по `right`-й узел, остальные узлы оставить на месте, и вернуть голову списка.

Пример: `head = [1, 2, 3, 4, 5]`, `left = 2`, `right = 4`. Участок `2 → 3 → 4` разворачивается в `4 → 3 → 2`, ответ `[1, 4, 3, 2, 5]`.

## Наивный подход

Самое простое — выписать значения в массив, развернуть нужный кусок и записать значения обратно:

```ts naive
const vals: number[] = [];
for (let c = head; c !== null; c = c.next) vals.push(c.val);
// развернуть vals[left - 1 .. right - 1]
let i = 0;
for (let c = head; c !== null; c = c.next) c.val = vals[i++];
```

Это `O(n)` по времени, но `O(n)` по памяти и два полных прохода. Кроме того, это «обман»: меняются значения, а не связи — на собеседовании ждут перестановки узлов.

## Ключевое наблюдение

Участок — это обычный кусок списка, и развернуть его можно **тем же стандартным разворотом** `prev/curr/next`, что и весь список, только остановиться ровно через `right - left + 1` шагов. После такого разворота все нужные для стыковки узлы уже под рукой:

```
before -> [2 -> 3 -> 4] -> 5          до
before -> 2 (-> null),  4 -> 3 -> 2,  curr = 5     после разворота
```

- `prev` — новое начало участка (`4`);
- `curr` — первый узел после участка (`5`);
- `before.next` всё ещё указывает на бывшее начало (`2`), которое стало хвостом.

Остаётся пришить два конца: `before.next.next = curr` и `before.next = prev`.

## Техники

### Фиктивная голова (dummy)

**Что это.** Узел-заглушка перед настоящей головой: `new ListNode(0, head)`. У любого узла появляется предшественник, включая первый.

**Как применяется здесь.** Если `left = 1`, участок начинается с головы, и узла «перед участком» в самом списке нет. С заглушкой `before = dummy`, и случай не особый. Новая голова — всегда `dummy.next`. Подробнее о заглушках и перевешивании указателей — во вкладке «Теория».

### Разворот связного списка тремя указателями

**Что это.** Базовая операция: идём по узлам, держа `prev`, `curr` и `next`, и каждый `curr.next` перенаправляем на `prev`.

```ts naive
let prev = null, curr = head;
while (curr !== null) {
  const next = curr.next; // запомнили, куда идти дальше
  curr.next = prev;       // развернули стрелку
  prev = curr;            // сдвинулись
  curr = next;
}
// prev — новая голова
```

**Как применяется здесь.** Вместо «до `null`» делаем фиксированное число шагов — длину участка. После цикла `prev` и `curr` — ровно два конца, которые нужно пришить.

## Разбор кода

```ts
function reverseBetween(head: ListNode | null, left: number, right: number): ListNode | null {
  // Заглушка нужна, если разворот начинается с первого узла (left = 1)
  const dummy = new ListNode(0, head);
```

Создаём заглушку, которая указывает на голову. Всю работу делаем относительно неё.

```ts
  // before — узел прямо перед отрезком [left, right]
  let before: ListNode = dummy;
  for (let i = 1; i < left; i++) before = before.next!;
```

Делаем `left - 1` шагов от заглушки. Заглушка стоит на позиции 0, значит, `before` окажется на позиции `left - 1` — прямо перед участком. При `left = 1` цикл не выполняется, и `before = dummy`. `!` безопасен: по условию `left <= n`.

```ts
  // Обычный разворот (right - left + 1) узлов отрезка
  let prev: ListNode | null = null;
  let curr: ListNode | null = before.next;
  for (let i = 0; i < right - left + 1; i++) {
    const next: ListNode | null = curr!.next;
    curr!.next = prev;
    prev = curr;
    curr = next;
  }
```

Стандартный разворот, начиная с первого узла участка. Длина участка — `right - left + 1`, ровно столько стрелок и разворачиваем. `curr!` безопасен: участок целиком лежит в списке, `curr` не станет `null` раньше времени. Бывшее начало участка получает `next = null` (стартовое `prev`) — временно участок «оторван» от хвоста, это исправим при стыковке.

```ts
  // Теперь prev — новое начало отрезка, curr — первый узел после отрезка,
  // а before.next — бывшее начало, ставшее хвостом отрезка
  before.next!.next = curr; // хвост отрезка -> остаток списка
  before.next = prev; // узел перед отрезком -> новое начало
```

Две стыковки. Связь `before.next` в цикле не менялась, поэтому через неё мы достаём бывшее начало участка — теперь это его хвост — и пришиваем к нему остаток списка `curr` (может быть `null`, если участок шёл до конца). Затем `before` указывает на новое начало `prev`. Порядок строк важен: если сначала выполнить `before.next = prev`, ссылка на хвост потеряется.

```ts
  return dummy.next;
}
```

Если `left = 1`, голова сменилась, и `dummy.next` — новая голова. Иначе это прежний `head`. Оба случая без ветвлений.

## Трассировка

`head = [1, 2, 3, 4, 5]`, `left = 2`, `right = 4`.

Поиск `before`: один шаг → `before = 1`. Длина участка `4 - 2 + 1 = 3`. `prev = null`, `curr = 2`.

1. `i = 0`: `next = 3`, `2.next = null`, `prev = 2`, `curr = 3`.
2. `i = 1`: `next = 4`, `3.next = 2`, `prev = 3`, `curr = 4`.
3. `i = 2`: `next = 5`, `4.next = 3`, `prev = 4`, `curr = 5`.

```
dummy -> 1 -> 2 -> null      4 -> 3 -> 2      curr = 5
```

Стыковка: `before.next` — это `2`, `2.next = 5`. Затем `1.next = 4`.

```
dummy -> 1 -> 4 -> 3 -> 2 -> 5
```

Ответ `[1, 4, 3, 2, 5]`.

Случай `left = 1`: `head = [3, 5]`, `left = 1`, `right = 2`. `before = dummy`, разворот двух узлов: `3.next = null`, `5.next = 3`, `prev = 5`, `curr = null`. Стыковка: `3.next = null`, `dummy.next = 5`. Ответ `[5, 3]` — голова сменилась, и это учтено автоматически.

## Почему это работает

До цикла: `before` — узел на позиции `left - 1`, `before.next` — узел `left`. Инвариант разворота после `t` итераций: `prev` — голова цепочки из первых `t` узлов участка в обратном порядке (её последний узел — узел `left`, указывающий на `null`), `curr` — узел `left + t` исходного списка, а всё от `curr` и дальше не тронуто. После `right - left + 1` итераций развёрнут весь участок, `curr` — узел `right + 1` (или `null`). Связь `before.next` цикл не трогает, она по-прежнему ведёт на узел `left`, ставший хвостом. Стыковки восстанавливают оба разрыва: хвост → `right + 1`, `before` → новое начало. Остальные узлы не менялись.

## Пограничные случаи

- **`left = right`**: разворот одного узла (его `next` временно `null`), стыковка возвращает всё как было.
- **`left = 1`**: `before = dummy`, новая голова возвращается через `dummy.next`.
- **`right = n`** (участок до конца): после цикла `curr = null`, хвост участка становится последним узлом.
- **Список из одного узла**: `left = right = 1`, результат совпадает с входом.

## Сложность

- **Время `O(n)`**: `left - 1` шагов до участка и `right - left + 1` шагов разворота — не больше `n`, один проход.
- **Память `O(1)`**: несколько указателей и заглушка.
- **Вариант для собеседования**: «вставка в голову» — держать первый узел участка на месте и `right - left` раз переносить следующий за ним узел сразу после `before`. Тоже один проход и `O(1)`, без отдельной стыковки, но четыре присваивания на шаг легче перепутать.

## Типичные ошибки

1. **Без заглушки** → отдельная ветка для `left = 1` и риск вернуть старый `head`, который уже не голова.
2. **Неверный счёт шагов**: `i <= left` при поиске `before` или `right - left` итераций разворота → разворачивается не тот кусок.
3. **Поменять порядок стыковки** (`before.next = prev` первым) → ссылка на хвост участка теряется, остаток списка отваливается.
4. **Забыть стыковку хвоста** → после разворота бывшее начало указывает на `null`, всё после `right` пропадает.
5. **Начать разворот с `before`, а не с `before.next`** → в участок попадает лишний узел.

## Как узнать такую задачу

- Нужно развернуть **часть** списка, а не весь — по позициям или группами.
- Решение — «дойти, развернуть стандартным разворотом, пришить концы»: запомнить узел перед участком и после цикла использовать `prev` и `curr`.
- Участок может начинаться с головы — сигнал к заглушке `dummy`. Родственные задачи: Reverse Linked List (весь список), Reverse Nodes in k-Group (участки по `k`), Swap Nodes in Pairs, Palindrome Linked List (разворот второй половины).
