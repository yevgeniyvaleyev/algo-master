## Задача простыми словами

Дан односвязный список и две позиции `left <= right` (нумерация с 1). Нужно развернуть **только участок** с `left`-го по `right`-й узел, остальные узлы оставить на месте, и вернуть голову списка.

Пример: `head = [1, 2, 3, 4, 5]`, `left = 2`, `right = 4`. Участок `2 → 3 → 4` разворачивается в `4 → 3 → 2`, ответ `[1, 4, 3, 2, 5]`.

## Наивный подход

Самое простое — выписать значения в массив, развернуть нужный кусок и записать значения обратно:

```ts naive
const vals: number[] = [];
for (let c = head; c !== null; c = c.next) vals.push(c.val);
// развернуть vals[left - 1 .. right - 1]
let i = 0;
for (let c = head; c !== null; c = c.next) c.val = vals[i++];
```

Это `O(n)` по времени, но `O(n)` по памяти и два полных прохода. Кроме того, это «обман»: меняются значения, а не связи — на собеседовании обычно ждут перестановки узлов. Другой вариант — вырезать участок, развернуть его стандартным разворотом и пришить обратно; это `O(1)` памяти, но нужно аккуратно запомнить четыре узла на стыках, и легко ошибиться.

## Ключевое наблюдение

Участок можно развернуть **на месте за один проход**, не отрезая его: держим узел `prev` прямо перед участком и по одному переносим следующие узлы участка **в его начало** (сразу после `prev`). Первый узел участка `start` при этом сам «сползает» в конец, а стыки с остальным списком всё время остаются корректными.

```
prev -> 2 -> 3 -> 4 -> 5        переносим 3 в начало
prev -> 3 -> 2 -> 4 -> 5        переносим 4 в начало
prev -> 4 -> 3 -> 2 -> 5        готово
```

## Техники

### Фиктивная голова (dummy)

**Что это.** Узел-заглушка перед настоящей головой: `new ListNode(0, head)`. У любого узла появляется предшественник, включая первый.

**Как применяется здесь.** Если `left = 1`, участок начинается с головы, и узла «перед участком» в самом списке нет. С заглушкой `prev = dummy`, и случай не особый. Новая голова — всегда `dummy.next`. Подробнее о заглушках и перевешивании указателей — во вкладке «Теория».

### Вставка в голову (head insertion)

**Что это.** Способ развернуть последовательность: берём элементы по очереди и вставляем каждый **в начало** результата. Последний вставленный окажется первым — порядок обратится.

**Типичный шаблон** для участка после `prev` с первым узлом `start`:

```ts naive
const moved = start.next;   // кого переносим
start.next = moved.next;    // вынимаем его
moved.next = prev.next;     // ставим перед текущим началом
prev.next = moved;          // объявляем новым началом
```

**Как применяется здесь.** Повторяем `right - left` раз: участок длины `right - left + 1`, и все узлы, кроме `start`, нужно перенести.

## Разбор кода

```ts
function reverseBetween(head: ListNode | null, left: number, right: number): ListNode | null {
  // Заглушка нужна, если разворот начинается с первого узла (left = 1)
  const dummy = new ListNode(0, head);
```

Создаём заглушку, которая указывает на голову. Всю работу делаем относительно неё.

```ts
  // prev — узел прямо перед отрезком [left, right]
  let prev: ListNode = dummy;
  for (let i = 1; i < left; i++) prev = prev.next!;
```

Делаем `left - 1` шагов от заглушки. Заглушка стоит на позиции 0, значит, после `left - 1` шагов `prev` окажется на позиции `left - 1` — прямо перед участком. При `left = 1` цикл не выполняется, и `prev = dummy`. `!` безопасен: по условию `left <= n`.

```ts
  // start — первый узел отрезка; после разворота он окажется в его конце
  const start: ListNode = prev.next!;
```

`start` — фиксированная ссылка на первый узел участка. Сам узел будет сдвигаться к концу участка, но ссылка на него не меняется, и `start.next` всегда указывает на **следующий узел, который нужно перенести**.

```ts
  // Вставка в голову: (right - left) раз берём узел сразу после start
  // и переносим его в начало отрезка (сразу после prev)
  for (let i = 0; i < right - left; i++) {
    const moved = start.next!;
    start.next = moved.next; // вынимаем moved из цепочки
    moved.next = prev.next; // moved указывает на текущее начало отрезка
    prev.next = moved; // moved становится новым началом
  }
```

Сердце решения — четыре строки:

1. `moved` — узел сразу после `start`, его переносим.
2. `start.next = moved.next` — `start` «перешагивает» через `moved`, тем самым вынимая его. Заодно `start` всегда остаётся связан с хвостом списка за участком.
3. `moved.next = prev.next` — `moved` теперь указывает на текущее начало участка (это не обязательно `start`: после первой итерации там уже другой узел).
4. `prev.next = moved` — `moved` становится новым началом участка.

Порядок присваиваний важен: каждое использует значение, которое следующее перезапишет. Например, если сделать `prev.next = moved` раньше `moved.next = prev.next`, то `moved` укажет сам на себя.

```ts
  return dummy.next;
}
```

Если `left = 1`, голова списка поменялась, и `dummy.next` — это новая голова. Иначе `dummy.next` — прежний `head`. В обоих случаях ответ правильный без ветвлений.

## Трассировка

`head = [1, 2, 3, 4, 5]`, `left = 2`, `right = 4`.

Поиск `prev`: цикл `i = 1` (один шаг) → `prev = 1`. `start = 2`. Итераций `right - left = 2`.

```
старт:  dummy -> 1 -> 2 -> 3 -> 4 -> 5
         prev start
```

1. `i = 0`: `moved = 3`. `start.next = 4` (2 → 4). `3.next = prev.next = 2`. `prev.next = 3`.

```
dummy -> 1 -> 3 -> 2 -> 4 -> 5
```

2. `i = 1`: `moved = start.next = 4`. `start.next = 5` (2 → 5). `4.next = prev.next = 3`. `prev.next = 4`.

```
dummy -> 1 -> 4 -> 3 -> 2 -> 5
```

Ответ `dummy.next` → `[1, 4, 3, 2, 5]`.

Случай `left = 1`: `head = [3, 5]`, `left = 1`, `right = 2`. `prev = dummy`, `start = 3`. Одна итерация: `moved = 5`, `3.next = null`, `5.next = dummy.next = 3`, `dummy.next = 5`. Ответ `[5, 3]` — голова сменилась, и это учтено автоматически.

## Почему это работает

Инвариант перед каждой итерацией цикла (после `t` итераций):

- `prev.next` указывает на начало участка, в котором первые `t + 1` исходных узлов участка стоят **в обратном порядке**, и последний из них — `start`;
- `start.next` указывает на `(t + 2)`-й исходный узел участка (или на хвост за участком, если узлы закончились);
- всё, что после него, не тронуто.

Итерация берёт `(t + 2)`-й узел и ставит его в начало — теперь развёрнуто `t + 2` узлов, инвариант сохранён. После `right - left` итераций развёрнут весь участок длины `right - left + 1`, а `start.next` указывает на узел `right + 1` — стык с хвостом корректен. Стык с головой обеспечивает `prev.next`.

## Пограничные случаи

- **`left = right`**: цикл не выполняется, список не меняется.
- **`left = 1`**: `prev = dummy`, новая голова возвращается через `dummy.next`.
- **`right = n`** (участок до конца): последний `moved.next` равен `null`, и `start.next` становится `null` — `start` становится последним узлом.
- **Список из одного узла**: `left = right = 1`, ничего не происходит.

## Сложность

- **Время `O(n)`**: до участка `left - 1` шагов, затем `right - left` итераций по `O(1)` — итого не больше `n`, один проход.
- **Память `O(1)`**: три указателя (`prev`, `start`, `moved`) и заглушка.

## Типичные ошибки

1. **Без заглушки** → отдельная ветка для `left = 1` и риск вернуть старый `head`, который уже не голова.
2. **Неверный счёт шагов до `prev`** (`i <= left` вместо `i < left`) → `prev` встаёт на первый узел участка, разворачивается не то.
3. **Перепутать порядок четырёх присваиваний** → потеря хвоста или цикл.
4. **`moved.next = start`** вместо `prev.next` → верно только на первой итерации, дальше узлы теряются.
5. **Вырезать и развернуть участок, забыв пришить хвост** (если выбрать подход «отрезать–развернуть–пришить»).

## Как узнать такую задачу

- Нужно развернуть **часть** списка, а не весь — либо по позициям, либо группами.
- Требуется один проход и `O(1)` памяти.
- Участок может начинаться с головы — сигнал к заглушке `dummy`. Родственные задачи: Reverse Linked List (весь список), Reverse Nodes in k-Group (участки по `k`), Swap Nodes in Pairs, Palindrome Linked List (разворот второй половины).
