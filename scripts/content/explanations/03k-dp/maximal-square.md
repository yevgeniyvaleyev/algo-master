## Задача простыми словами

Дана матрица `m × n` из символов `'0'` и `'1'`. Нужно найти самый большой **квадрат**, целиком состоящий из `'1'`, и вернуть его **площадь** (сторону в квадрате).

Пример:

```
1 1 1
1 1 1
0 1 1
```

Квадрат `3 × 3` мешает ноль в левом нижнем углу, но квадратов `2 × 2` из единиц несколько. Ответ — площадь `4`.

## Наивный подход

Перебрать каждую клетку как левый верхний угол и наращивать сторону, пока квадрат состоит из единиц:

```ts naive
let best = 0;
for (let i = 0; i < m; i++) {
  for (let j = 0; j < n; j++) {
    let side = 0;
    while (i + side < m && j + side < n && allOnes(i, j, side + 1)) side++;
    best = Math.max(best, side);
  }
}
```

Если `allOnes` проверяет квадрат целиком, получаем порядка `O(m · n · min(m, n)³)`; даже с проверкой только новой «каймы» — `O(m · n · min(m, n)²)`. Лишняя работа: квадраты соседних клеток почти совпадают, но для каждого угла все единицы перепроверяются заново. Информация «здесь большой квадрат» никак не переиспользуется соседями.

## Ключевое наблюдение

Будем описывать квадрат его **правым нижним углом**. Пусть `dp[i][j]` — сторона наибольшего квадрата из единиц с углом в `(i, j)`. Если в клетке `'1'`, то

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

Квадрат со стороной `s` и углом в `(i, j)` — это клетка `(i, j)` плюс три перекрывающихся квадрата со стороной `s − 1` с углами **сверху**, **слева** и **по диагонали**. Самый слабый из трёх соседей и ограничивает рост. Каждая клетка считается за `O(1)` — всего `O(m · n)`.

## Техники

### ДП на сетке по «правому нижнему углу»

**Что это.** Двумерное ДП, где состояние привязано к клетке, а переход смотрит на уже посчитанных соседей сверху, слева и по диагонали. Выбор «угла», за который мы описываем фигуру, — главный приём: правый нижний угол удобен потому, что все нужные соседи посчитаны при обходе сверху вниз и слева направо.

- **Состояние**: `dp[i][j]` — сторона наибольшего квадрата из единиц с правым нижним углом в `(i, j)`.
- **База**: клетки за границей — `0` (квадрата нет).
- **Переход**: `'0'` → `0`; `'1'` → `min(сверху, слева, диагональ) + 1`.
- **Ответ**: квадрат максимального `dp`.

Подробнее о многомерном ДП — во вкладке «Теория».

### Одна строка + переменная для диагонали

Строка `i` зависит только от строки `i − 1` и самой себя. В одномерном массиве до перезаписи ячейка хранит значение «сверху», левая ячейка уже обновлена — это «слева». А вот «диагональ» (сверху-слева) к моменту обработки клетки уже затёрта значением текущей строки. Поэтому её сохраняют в отдельной переменной `prev` — прошлое «верхнее» значение.

### Фиктивный столбец

Массив длины `n + 1`, где `dp[0]` всегда `0`, а клетка `(i, j)` хранится в `dp[j + 1]`. Тогда для первого столбца «слева» — это `dp[0] = 0`, и отдельная проверка границы не нужна.

## Разбор кода

```ts
function maximalSquare(matrix: string[][]): number {
  const m = matrix.length;
  const n = matrix[0].length;

  // dp[j + 1] — сторона наибольшего квадрата из единиц с правым нижним углом
  // в клетке (i, j). Храним одну строку; dp[0] — фиктивный столбец нулей
  const dp: number[] = new Array(n + 1).fill(0);
  let maxSide = 0;
```

Одна строка длины `n + 1` со сдвигом индекса на единицу. Изначально нули — это и «строка над матрицей», где квадратов нет. `maxSide` — лучшая сторона за всё время.

```ts
  for (let i = 0; i < m; i++) {
    // prev — значение dp «по диагонали» (строка i - 1, столбец j - 1)
    let prev = 0;
```

В начале каждой строки диагональ для `j = 0` — это клетка `(i − 1, −1)`, вне матрицы, поэтому `prev = 0`.

```ts
    for (let j = 0; j < n; j++) {
      // Сохраняем «верхнее» значение: на следующем шаге оно станет диагональю
      const top = dp[j + 1];
```

Прежде чем перезаписать `dp[j + 1]`, запоминаем его старое значение — это `dp[i − 1][j]`, «сверху». Для следующей клетки `(i, j + 1)` эта же клетка `(i − 1, j)` окажется диагональю.

```ts
      if (matrix[i][j] === '1') {
        // Квадрат ограничен самым маленьким из трёх соседних квадратов:
        // сверху (top), слева (dp[j]) и по диагонали (prev)
        dp[j + 1] = Math.min(top, dp[j], prev) + 1;
        maxSide = Math.max(maxSide, dp[j + 1]);
```

Единица: применяем переход. `dp[j]` — уже обновлённая на этой строке клетка `(i, j − 1)`, «слева» (для `j = 0` — фиктивный ноль). Сравнение именно со строкой `'1'`: матрица состоит из символов, а не чисел. Сразу обновляем рекорд.

```ts
      } else {
        // Ноль не может быть углом квадрата из единиц
        dp[j + 1] = 0;
      }
      prev = top;
    }
  }
```

Ноль обнуляет клетку — важно явно записать `0`, иначе в ячейке останется значение из прошлой строки. Затем сдвигаем диагональ: старое «верхнее» становится диагональю для следующей клетки.

```ts
  // Возвращаем площадь, а не сторону
  return maxSide * maxSide;
}
```

Задача просит площадь — возводим сторону в квадрат.

## Трассировка

Матрица:

```
1 1 1
1 1 1
0 1 1
```

Старт: `dp = [0, 0, 0, 0]`, `maxSide = 0`.

```
i=0, prev=0:
  j=0: top=0; '1' → min(0, dp[0]=0, 0)+1 = 1   dp=[0,1,0,0]  max=1  prev=0
  j=1: top=0; '1' → min(0, 1, 0)+1 = 1         dp=[0,1,1,0]         prev=0
  j=2: top=0; '1' → min(0, 1, 0)+1 = 1         dp=[0,1,1,1]         prev=0
i=1, prev=0:
  j=0: top=1; '1' → min(1, 0, 0)+1 = 1         dp=[0,1,1,1]         prev=1
  j=1: top=1; '1' → min(1, 1, 1)+1 = 2         dp=[0,1,2,1]  max=2  prev=1
  j=2: top=1; '1' → min(1, 2, 1)+1 = 2         dp=[0,1,2,2]         prev=1
i=2, prev=0:
  j=0: top=1; '0' → 0                          dp=[0,0,2,2]         prev=1
  j=1: top=2; '1' → min(2, 0, 1)+1 = 1         dp=[0,0,1,2]         prev=2
  j=2: top=2; '1' → min(2, 1, 2)+1 = 2         dp=[0,0,1,2]         prev=2
```

`maxSide = 2`, ответ `4`. В последней клетке сверху и по диагонали стоят двойки, но слева только `1` (из-за нуля в углу) — поэтому квадрат `3 × 3` не получился.

## Почему это работает

Пусть `s = min(top, left, diag) + 1`.

- **Квадрат стороны `s` существует.** Каждый из трёх соседей имеет квадрат стороны не меньше `s − 1`. Квадраты `(s−1) × (s−1)` с углами в `(i−1, j)`, `(i, j−1)` и `(i−1, j−1)` вместе с клеткой `(i, j)` покрывают весь квадрат `s × s` с углом в `(i, j)`.
- **Больше `s` нельзя.** Если бы существовал квадрат стороны `s + 1`, то каждый из трёх соседей был бы углом квадрата стороны `s` — значит, все три значения были бы не меньше `s`, и минимум тоже.

По порядку обхода три соседа к моменту вычисления уже посчитаны и лежат в `top`, `dp[j]`, `prev`. Любой квадрат имеет правый нижний угол, поэтому максимум по всем клеткам — ответ.

## Пограничные случаи

- **Нет единиц**: `maxSide` остаётся `0`, ответ `0`.
- **Матрица `1 × 1`**: ответ `1` или `0`.
- **Одна строка или один столбец**: квадраты не больше `1 × 1`.
- **Вся матрица из единиц**: ответ `min(m, n)²`.
- **Матрица не квадратная**: размеры `m` и `n` учитываются независимо.

## Сложность

- **Время `O(m · n)`**: каждая клетка — несколько сравнений.
- **Память `O(n)`**: одна строка `dp` длины `n + 1` и пара переменных.

## Типичные ошибки

1. **Вернуть сторону** вместо площади.
2. **Сравнивать с числом `1`** вместо строки `'1'` — ни одна клетка не распознается как единица.
3. **Потерять диагональ** при сжатии до одной строки: без `prev` в `dp[j]` уже значение текущей строки.
4. **Не записывать `0` для нулевой клетки** — в одномерном массиве останется значение из прошлой строки.
5. **Брать `max` вместо `min`** соседей или учитывать только двух соседей (без диагонали) — получатся «квадраты» с дырой в углу.

## Как узнать такую задачу

- Найти наибольшую **фигуру фиксированной формы** (квадрат, «плюс», треугольник) из одинаковых клеток бинарной матрицы.
- Размер фигуры в клетке определяется размерами фигур у соседей → ДП по углу фигуры.
- Похожий приём: Count Square Submatrices with All Ones (сумма всех `dp`, а не максимум). Для **прямоугольников** (Maximal Rectangle) нужен другой подход — гистограммы и монотонный стек.
