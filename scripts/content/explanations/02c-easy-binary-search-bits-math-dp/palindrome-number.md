## Задача простыми словами

Дано целое число `x`. Нужно понять, **читается ли оно одинаково слева направо и справа налево**.

Примеры: `121` — палиндром (справа налево тоже `121`). `-121` — нет: справа налево получится `121-`. `10` — нет: справа налево `01`.

## Наивный подход

Самое очевидное — превратить число в строку и сравнить её с развёрнутой:

```ts naive
const str = String(x);
return str === str.split('').reverse().join('');
```

Решение короткое и верное, но условие прямо просит обойтись **без преобразования в строку**. К тому же оно создаёт строку, массив символов и ещё одну строку — `O(число цифр)` лишней памяти. Хочется работать с цифрами самого числа.

## Ключевое наблюдение

Цифры числа легко снимать с конца арифметикой:

- `x % 10` — последняя цифра (`121 % 10 = 1`);
- `Math.floor(x / 10)` — число без последней цифры (`121 → 12`).

Если снимать цифры с конца и **дописывать их в новое число** (`rev = rev * 10 + цифра`), то в итоге получится `x`, записанный задом наперёд. Палиндром — это ровно то число, которое совпадает со своим разворотом. Значит, ответ — `rev === x`.

## Техники

### Разбор числа на цифры через `% 10` и `/ 10`

**Что это.** Базовый приём «математических» задач: остаток от деления на 10 даёт последнюю цифру, а целочисленное деление на 10 её отрезает. Повторяя это, пока число не станет нулём, мы перебираем цифры справа налево.

**Типичный шаблон — разворот числа:**

```ts naive
let rev = 0;
while (n > 0) {
  rev = rev * 10 + (n % 10); // дописать последнюю цифру n
  n = Math.floor(n / 10); // отрезать её
}
```

Умножение `rev * 10` сдвигает уже собранные цифры на разряд влево и освобождает место для новой. Тот же шаблон встречается в Reverse Integer, Add Digits, Happy Number и подсчёте суммы цифр.

**Как применяется здесь.** Разворачиваем копию `x` и сравниваем результат с исходным числом. Подробнее — во вкладке «Теория».

### Целочисленное деление в JavaScript

В JS нет отдельного целого типа: `121 / 10 = 12.1`. Поэтому нужен `Math.floor`, иначе цифры «расплывутся» в дробную часть и цикл не закончится вовремя. Для неотрицательных чисел `Math.floor` и `Math.trunc` дают одно и то же.

## Разбор кода

```ts
function isPalindrome(x: number): boolean {
  // Отрицательные числа — не палиндромы: минус есть только слева
  if (x < 0) {
    return false;
  }
```

Знак минус стоит только в начале записи, справа налево он оказался бы в конце. Поэтому любое отрицательное число сразу не палиндром. Заодно дальше мы работаем только с неотрицательными числами, и `x % 10` всегда даёт обычную цифру `0…9`.

```ts
  // Разворачиваем число целиком, снимая цифры с конца
  let rev = 0;
  let rest = x;
```

`rev` — развёрнутое число, пока пустое (`0`). `rest` — копия `x`, от которой мы будем отрезать цифры. Копия нужна, потому что исходный `x` понадобится для сравнения в конце.

```ts
  while (rest > 0) {
    // Переносим последнюю цифру rest в конец rev
    rev = rev * 10 + (rest % 10);
    rest = Math.floor(rest / 10);
  }
```

Пока у `rest` остались цифры, переносим последнюю из них в конец `rev`. Каждая итерация укорачивает `rest` на одну цифру и удлиняет `rev` на одну. Когда `rest` стал нулём, все цифры перенесены в обратном порядке.

```ts
  // Палиндром читается одинаково в обе стороны.
  // В JS number хранит такие числа точно, переполнения нет
  return rev === x;
}
```

Сравниваем разворот с оригиналом. В Java или C++ разворот 32-битного числа мог бы не поместиться в `int` (например, `2147483647 → 7463847412`), но в JS `number` точно хранит целые до `2^53`, поэтому здесь это не проблема.

## Трассировка

`x = 121`:

1. `rest = 121`: цифра `1`, `rev = 0 * 10 + 1 = 1`, `rest = 12`.
2. `rest = 12`: цифра `2`, `rev = 1 * 10 + 2 = 12`, `rest = 1`.
3. `rest = 1`: цифра `1`, `rev = 12 * 10 + 1 = 121`, `rest = 0`.
4. Цикл закончился. `rev = 121 === x` → `true`.

`x = 10`:

1. `rest = 10`: цифра `0`, `rev = 0`, `rest = 1`.
2. `rest = 1`: цифра `1`, `rev = 1`, `rest = 0`.
3. `rev = 1 !== 10` → `false`.

`x = -121`: сразу `false` по первой проверке.

## Почему это работает

Каждая итерация берёт **последнюю** оставшуюся цифру `rest` и ставит её **в конец** `rev`. Первой в `rev` попадает последняя цифра `x`, второй — предпоследняя и так далее. Значит, после цикла `rev` состоит из цифр `x` в обратном порядке, то есть это `x`, прочитанный справа налево.

Число — палиндром ровно тогда, когда прочтение справа налево совпадает с исходным. Это и проверяет `rev === x`. Ведущие нули не мешают: если `x` оканчивается на `0`, этот ноль становится ведущим в `rev` и просто исчезает, поэтому `rev` получается короче и честно не равен `x` (кроме случая `x = 0`).

## Пограничные случаи

- **`x = 0`**: цикл не выполняется, `rev = 0 === 0` → `true`.
- **Однозначные числа** (`7`): одна итерация, `rev = 7` → `true`.
- **Числа с нулём в конце** (`10`, `110`): ноль теряется как ведущий, ответ `false`.
- **Отрицательные числа**: `false` сразу.
- **Большие числа** (`2147447412`): разворот `2147447412` — палиндром; в JS переполнения нет.

## Сложность

- **Время `O(log₁₀ x)`**: одна итерация на каждую цифру, а цифр в числе около `log₁₀ x` (не больше 10).
- **Память `O(1)`**: две переменные, никаких строк.

**Follow-up на собеседовании:** в языках с 32-битным `int` разворачивают только **правую половину** цифр — цикл `while (x > rev)`, затем `x === rev || x === Math.floor(rev / 10)`. Так разворот никогда не переполняется, а работы вдвое меньше. Но тогда числа, оканчивающиеся на `0` (кроме самого `0`), нужно отсечь заранее.

## Типичные ошибки

1. **Делить `rest / 10` без `Math.floor`** → в JS получаются дроби, цикл крутится лишние сотни итераций, `rev` превращается в мусор.
2. **Разворачивать сам `x`, а не копию** → после цикла `x = 0`, и сравнивать уже не с чем.
3. **Забыть про отрицательные числа** → для `-121` цикл `while (rest > 0)` не выполнится, `rev = 0 !== -121`; ответ случайно верный, но `x % 10` для отрицательных в JS тоже отрицательный, и любая правка логики сломается.
4. **В Java/C++ разворачивать всё число в `int`** → переполнение; там нужен `long` или разворот половины.
5. **Решать через строку**, когда условие просит без неё.

## Как узнать такую задачу

- Нужно что-то сделать с **цифрами числа** без строк: развернуть, сложить, сравнить — шаблон `% 10` и `Math.floor(/ 10)`.
- Слово «палиндром» для числа — разворот и сравнение (для строки — два указателя с концов).
- Родственные задачи: Reverse Integer (тот же разворот, но с проверкой на переполнение), Add Digits, Happy Number, Plus One.
