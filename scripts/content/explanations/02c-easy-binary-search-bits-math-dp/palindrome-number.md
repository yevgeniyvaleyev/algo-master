## Задача простыми словами

Дано целое число `x`. Нужно вернуть `true`, если оно **палиндром** — читается одинаково слева направо и справа налево, и `false` иначе. Follow-up: решить **без перевода в строку**.

Пример: `121` — палиндром. `-121` — нет: справа налево читается `121-`. `10` — нет: справа налево `01`.

## Наивный подход

Перевести в строку и сравнить с перевёрнутой:

```ts naive
const s = String(x);
return s === s.split('').reverse().join('');
```

Работает за `O(d)`, где `d` — число цифр, но follow-up запрещает строки. Второй очевидный вариант — **развернуть всё число** арифметикой и сравнить с исходным:

```ts naive
let rev = 0, t = x;
while (t > 0) { rev = rev * 10 + (t % 10); t = Math.floor(t / 10); }
return rev === x;
```

Здесь две проблемы. Во-первых, в языках с 32-битным `int` разворот может **переполниться** (`2147483647` → `7463847412` не помещается). Во-вторых, это лишняя работа: вторую половину цифр мы разворачиваем, хотя после середины уже всё известно — достаточно сравнить левую половину с перевёрнутой правой.

## Ключевое наблюдение

Палиндром — это когда **левая половина цифр равна перевёрнутой правой**. Будем снимать цифры с конца `x` и дописывать их в `reversed`. После каждого шага `x` теряет цифру, а `reversed` её получает. Как только `x <= reversed`, мы дошли до середины:

- при чётном числе цифр должно быть `x === reversed` (`1221` → `12` и `12`);
- при нечётном средняя цифра уехала в `reversed`, её отбрасываем: `x === Math.floor(reversed / 10)` (`12321` → `12` и `123`).

`reversed` никогда не превышает половину цифр — переполнения нет, и работы вдвое меньше.

## Техники

### Разбор числа на цифры арифметикой

**Что это.** Без строк к цифрам числа добираются двумя операциями:

- `x % 10` — последняя цифра;
- `Math.floor(x / 10)` — число без последней цифры;
- `r * 10 + d` — дописать цифру `d` в конец числа `r`.

**Типичный шаблон** «развернуть число»:

```ts naive
let r = 0;
while (x > 0) {
  r = r * 10 + (x % 10);
  x = Math.floor(x / 10);
}
```

Тот же каркас в двоичном виде (`& 1`, `>>> 1`, `<< 1 |`) разворачивает биты (Reverse Bits). В JS обязательно `Math.floor` (или `Math.trunc`): `/` даёт дробь, и цикл никогда не дойдёт до нуля как целого.

**Как применяется здесь.** Шаблон разворота, но с другим условием остановки — `x > reversed` вместо `x > 0`, чтобы остановиться на середине. Подробнее о работе с цифрами — во вкладке «Теория».

### Сравнение половин (вместо двух указателей)

Для строк палиндром проверяют двумя указателями с концов. С числом удобнее «переложить» правую половину в отдельное число — получаем то же сравнение «первая цифра с последней, вторая с предпоследней», но одним равенством.

## Разбор кода

```ts
function isPalindrome(x: number): boolean {
  // Отрицательные числа — не палиндромы (минус только слева).
  // Число, оканчивающееся на 0, — палиндром, только если это сам 0:
  // иначе первая цифра тоже должна быть 0, а ведущих нулей не бывает
  if (x < 0 || (x % 10 === 0 && x !== 0)) {
    return false;
  }
```

Две ранние проверки:

- **`x < 0`**: у отрицательного числа минус стоит слева, а справа его нет — палиндромом оно быть не может.
- **`x % 10 === 0 && x !== 0`**: если последняя цифра `0`, то и первая должна быть `0`, а ведущих нулей у чисел нет. Исключение — сам `0`.

Вторая проверка не только ускоряет — без неё алгоритм **ошибается**. Для `x = 10` цикл снимет `0`: `reversed = 0`, `x = 1`; затем `1 > 0` → `reversed = 1`, `x = 0`; итоговое сравнение `0 === Math.floor(1 / 10)` даст ложный `true`. Ведущий ноль «перевёрнутой половины» неотличим от отсутствия цифры.

```ts
  // Разворачиваем только правую половину цифр
  let reversed = 0;
  while (x > reversed) {
```

Пока в `x` осталось «больше», чем в `reversed`, середина ещё не пройдена. Как только `x <= reversed`, в `reversed` лежит половина цифр (или половина плюс средняя). Сравнение по величине здесь работает как сравнение по длине: число с большим количеством цифр больше.

```ts
    // Переносим последнюю цифру x в конец reversed
    reversed = reversed * 10 + (x % 10);
    x = Math.floor(x / 10);
  }
```

Стандартный шаг разворота: `x % 10` — последняя цифра `x`, она дописывается в конец `reversed` (сдвиг на разряд влево через `* 10`). `Math.floor(x / 10)` отбрасывает эту цифру у `x`.

```ts
  // Чётное число цифр: половины равны (1221 → x = 12, reversed = 12).
  // Нечётное: средняя цифра оказалась в reversed, отбрасываем её
  // (12321 → x = 12, reversed = 123)
  return x === reversed || x === Math.floor(reversed / 10);
}
```

Финальное сравнение. Нам не нужно знать заранее, чётное ли число цифр: проверяем оба варианта. Средняя цифра палиндрома нечётной длины совпадает «сама с собой», поэтому её просто отбрасываем делением `reversed` на 10. Ложного срабатывания второй ветки для непалиндрома не бывает: если `x === Math.floor(reversed / 10)`, то левая половина действительно равна перевёрнутой правой без средней цифры.

## Трассировка

`x = 12321` (нечётная длина):

1. `12321 > 0`: `reversed = 0·10 + 1 = 1`, `x = 1232`.
2. `1232 > 1`: `reversed = 1·10 + 2 = 12`, `x = 123`.
3. `123 > 12`: `reversed = 12·10 + 3 = 123`, `x = 12`.
4. `12 > 123`? Нет → выход. `x === reversed`? `12 ≠ 123`. `x === Math.floor(123 / 10) = 12`? Да → `true`.

`x = 1221` (чётная длина):

1. `reversed = 1`, `x = 122`.
2. `122 > 1`: `reversed = 12`, `x = 12`.
3. `12 > 12`? Нет → выход. `12 === 12` → `true`.

`x = 123` (не палиндром):

1. `reversed = 3`, `x = 12`.
2. `12 > 3`: `reversed = 32`, `x = 1`.
3. `1 > 32`? Нет. `1 === 32`? Нет. `1 === Math.floor(32 / 10) = 3`? Нет → `false`.

## Почему это работает

Инвариант цикла: `reversed` — это последние `k` цифр исходного числа в обратном порядке, а `x` — первые `d − k` цифр (где `d` — длина числа). Последняя цифра не ноль (проверка в начале), поэтому у `reversed` нет ведущих нулей, и пока у `x` цифр больше, `x > reversed` — до середины цикл точно не остановится. При нечётном `d` после `k = (d+1)/2` шагов у `reversed` цифр больше — остановка ровно там. При чётном `d` после `k = d/2` длины равны, и цикл остановится, если `x <= reversed`.

Число — палиндром ⇔ первые `⌊d/2⌋` цифр равны перевёрнутым последним `⌊d/2⌋`. При чётном `d` это ровно `x === reversed`. При нечётном в `reversed` лишняя средняя цифра (последняя добавленная, младший разряд), и `Math.floor(reversed / 10)` её убирает.

Тонкость: при чётном `d` может оказаться `x > reversed` на середине — тогда половины заведомо не равны, цикл сделает лишний шаг, и обе проверки вернут `false`, потому что длины уже не совпадают. Например, `x = 91`: после шага `reversed = 1`, `x = 9`, `9 > 1` → ещё шаг: `reversed = 19`, `x = 0`; `0 ≠ 19`, `0 ≠ 1` → `false`.

## Пограничные случаи

- **`x = 0`**: проходит проверки, цикл не выполняется (`0 > 0` ложно), `0 === 0` → `true`.
- **Одна цифра** (`7`): один шаг, `x = 0`, `reversed = 7`; `0 === Math.floor(7 / 10) = 0` → `true`.
- **Оканчивается на 0** (`10`, `100`, `120`): отсекается в начале.
- **Отрицательные**: сразу `false`.
- **Большие числа** (`2^31 − 1`): `reversed` растёт только до половины цифр, переполнения нет даже в языках с 32-битным `int`.

## Сложность

- **Время `O(log₁₀ x)`**: цикл обрабатывает около половины цифр, а цифр в `x` — `⌊log₁₀ x⌋ + 1`. Для `2^31 − 1` это 5 итераций.
- **Память `O(1)`**: две числовые переменные, никаких строк и массивов.

## Типичные ошибки

1. **Нет проверки «оканчивается на 0»** → `10` и `100` ошибочно признаются палиндромами.
2. **`x / 10` без `Math.floor`** → в JS получаются дроби, `x % 10` перестаёт быть цифрой, цикл ведёт себя непредсказуемо.
3. **Разворот всего числа** в Java/C++ → переполнение `int`; здесь именно поэтому разворачивают половину.
4. **Проверять только `x === reversed`** → все палиндромы нечётной длины (`121`, `12321`) дают `false`.
5. **Считать `-121` палиндромом**, разворачивая модуль, → по условию это `false`.

## Как узнать такую задачу

- Требуют работать с **цифрами числа**, «не переводя в строку».
- Нужно развернуть число, проверить симметрию, сложить цифры, найти цифру на позиции.
- Подсказка про переполнение при развороте — сигнал развернуть только половину. Родственные задачи: Reverse Integer, Valid Palindrome (строки, два указателя), Palindrome Linked List (тоже «развернуть половину»), Add Digits, Happy Number.
