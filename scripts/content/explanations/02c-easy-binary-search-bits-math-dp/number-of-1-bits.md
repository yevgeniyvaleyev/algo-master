## Задача простыми словами

Дано положительное целое число `n`. Нужно посчитать, **сколько единиц в его двоичной записи** (это число называют весом Хэмминга).

Пример: `n = 11`, в двоичной записи `1011` — три единицы, ответ `3`. Для `n = 128` (`10000000`) ответ `1`.

## Наивный подход

Самое первое, что приходит в голову, — перевести число в двоичную строку и посчитать символы `'1'`:

```ts naive
let count = 0;
for (const ch of n.toString(2)) {
  if (ch === '1') count++;
}
return count;
```

Это работает, но на собеседовании такой ответ считается обходом задачи: она проверяет, умеете ли вы работать **с битами напрямую**. Кроме того, мы создаём строку (лишняя память и время на преобразование), а для отрицательных чисел `toString(2)` выдаёт строку с минусом (`"-101"`), а не биты дополнительного кода. Хочется смотреть на биты самого числа, без промежуточных строк.

## Ключевое наблюдение

Любой бит числа можно «достать» двумя простыми операциями:

- `n & 1` — значение **младшего** бита (`1`, если число нечётное, иначе `0`);
- `n >>> 1` — сдвиг вправо на одну позицию: младший бит выпадает, а следующий бит становится младшим.

В числе 32 бита. Значит, 32 раза подряд берём младший бит, прибавляем его к счётчику и сдвигаем число — и пересчитаем все единицы.

## Техники

### Проверка младшего бита и сдвиг

**Что это.** Побитовое И с единицей обнуляет все биты, кроме младшего: `1011 & 0001 = 0001`, `1010 & 0001 = 0000`. Сдвиг вправо `>>> 1` делит число на 2 с отбрасыванием остатка, то есть «убирает» младший бит. Вместе они дают способ обойти биты числа справа налево.

**Типичный шаблон:**

```ts naive
for (let i = 0; i < 32; i++) {
  const bit = n & 1; // текущий бит
  // ... обработать bit ...
  n >>>= 1; // перейти к следующему
}
```

Тот же шаблон используется в Reverse Bits, при переводе числа в двоичную систему и в любой задаче, где нужно обработать каждый разряд.

**Как применяется здесь.** Обработка бита — просто `count += bit`. Подробнее о битовых операциях — во вкладке «Теория».

### Беззнаковый сдвиг `>>>` в JavaScript

В JS есть два сдвига вправо. `>>` — знаковый: он копирует старший (знаковый) бит, и для отрицательного 32-битного значения слева заезжают единицы. `>>>` — беззнаковый: слева всегда приходят нули. Для счёта битов нужен именно `>>>`, тогда каждый бит будет посчитан ровно один раз.

## Разбор кода

```ts
function hammingWeight(n: number): number {
  let count = 0;
```

Счётчик единиц. Больше нам ничего не нужно — само `n` мы будем «съедать» сдвигами.

```ts
  // Проверяем все 32 бита по очереди, начиная с младшего
  for (let i = 0; i < 32; i++) {
```

Ровно 32 итерации — по одной на каждый бит 32-битного числа. Переменная `i` нужна только для счёта шагов: номер бита мы не используем, потому что всегда смотрим на младший.

```ts
    // n & 1 — это младший бит: 1, если число нечётное, иначе 0
    count += n & 1;
```

`n & 1` равно `0` или `1`, поэтому его можно прибавлять к счётчику без `if`. Если младший бит — единица, счётчик растёт на 1, иначе не меняется.

```ts
    // Сдвигаем вправо на один бит: следующий бит становится младшим.
    // >>> — беззнаковый сдвиг, слева всегда приходят нули
    n >>>= 1;
  }
```

Сдвиг «выталкивает» только что посчитанный бит. На следующей итерации `n & 1` покажет уже следующий разряд. Через 32 сдвига число станет нулём — все биты просмотрены.

```ts
  return count;
}
```

Возвращаем накопленное количество единиц.

## Трассировка

`n = 11` (`1011`). Покажем первые итерации, дальше `n = 0` и счётчик не меняется:

1. `i = 0`: `n = 1011`, `n & 1 = 1` → `count = 1`, `n = 101`.
2. `i = 1`: `n = 101`, `n & 1 = 1` → `count = 2`, `n = 10`.
3. `i = 2`: `n = 10`, `n & 1 = 0` → `count = 2`, `n = 1`.
4. `i = 3`: `n = 1`, `n & 1 = 1` → `count = 3`, `n = 0`.
5. `i = 4 … 31`: `n = 0`, `n & 1 = 0`, счётчик остаётся `3`.

Ответ `3`.

`n = 128` (`10000000`): первые 7 итераций младший бит — `0`, на `i = 7` он становится `1`, `count = 1`, дальше нули. Ответ `1`.

## Почему это работает

После `i` сдвигов младшим битом `n` становится бит, который изначально стоял в разряде `i`: каждый `>>> 1` смещает все биты на одну позицию вправо. Значит, на итерации `i` выражение `n & 1` равно исходному биту номер `i`. Цикл перебирает `i = 0 … 31`, то есть все 32 разряда, и каждый из них прибавляется к `count` ровно один раз. Сумма битов — это и есть количество единиц.

Беззнаковый сдвиг гарантирует, что слева приходят только нули, поэтому лишних единиц в подсчёт не попадёт.

## Пограничные случаи

- **`n = 1`**: единица только в младшем бите, ответ `1`.
- **Степень двойки** (`128`, `2^30`): ровно одна единица, ответ `1`.
- **Все биты единицы** (`2^31 - 1`): ответ `31`.
- **Число с единицей в бите 31** (за пределами ограничений, например `0xFFFFFFFF`): `&` и `>>>` работают с 32-битным представлением, поэтому ответ `32` — благодаря `>>>`, а не `>>`.

## Сложность

- **Время `O(32) = O(1)`**: всегда ровно 32 итерации с парой простых операций.
- **Память `O(1)`**: одна переменная-счётчик.

**Follow-up на собеседовании — алгоритм Кернигана.** Выражение `n & (n - 1)` сбрасывает младшую единицу числа, поэтому цикл делает ровно столько шагов, сколько в числе единиц, а не 32:

```ts naive
while (n !== 0) {
  n &= n - 1; // убрать младшую единицу
  count++;
}
```

**Follow-up «функцию вызывают много раз»:** заранее посчитать число единиц для всех 256 байтов (`table[i] = table[i >> 1] + (i & 1)`) и складывать значения таблицы для 4 байтов числа.

## Типичные ошибки

1. **`n >> 1` вместо `n >>> 1`** → для числа с единицей в бите 31 слева заезжают единицы, и они будут посчитаны лишний раз.
2. **Цикл `while (n > 0)` со сдвигом** → для «отрицательного» 32-битного значения не выполнится ни разу и вернёт `0`.
3. **Деление `n / 2` вместо сдвига** → в JS получаются дроби, и `n & 1` перестаёт показывать нужный бит.
4. **Проверка `if (n & 1 === 1)`** → приоритет `===` выше, чем `&`, получается `n & (1 === 1)`; нужны скобки или просто `count += n & 1`.
5. **Подсчёт через `toString(2)`** → для отрицательных чисел строка с минусом, а не биты.

## Как узнать такую задачу

- «Количество единичных битов», «вес Хэмминга», «сколько бит различается» (тогда сначала `a ^ b`, потом считаем единицы — это Hamming Distance).
- Нужно обработать **каждый разряд** числа — шаблон «`n & 1` + сдвиг» (Reverse Bits, перевод в двоичную систему).
- Нужно быстрее, чем по всем разрядам, или проверить степень двойки — трюк `n & (n - 1)`.
- Родственные задачи: Counting Bits, Power of Two, Hamming Distance, Reverse Bits.
