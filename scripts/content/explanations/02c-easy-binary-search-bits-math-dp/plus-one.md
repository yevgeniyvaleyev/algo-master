## Задача простыми словами

Большое неотрицательное число записано **массивом цифр** `digits` — от старшей к младшей, без ведущих нулей. Нужно **прибавить к нему единицу** и вернуть новый массив цифр.

Пример: `[1, 2, 3]` — это `123`, плюс один — `124`, ответ `[1, 2, 4]`. Интереснее `[9, 9]`: `99 + 1 = 100`, ответ `[1, 0, 0]` — массив стал длиннее.

## Наивный подход

Собрать число из цифр, прибавить единицу и разобрать обратно:

```ts naive
const num = Number(digits.join('')) + 1;
return String(num).split('').map(Number);
```

Для коротких массивов это работает, но цифр может быть **до 100**, а `Number` точно хранит целые только до `2^53` — около 16 цифр. Дальше младшие разряды теряются: `Number('12345678901234567891')` уже не равно исходному числу. (`BigInt` решил бы проблему, но задача проверяет ручное сложение.)

Кроме того, это лишняя работа: мы перестраиваем **все** цифры, хотя прибавление единицы обычно меняет только **последнюю**. Цифры левее меняются лишь при переносе, а перенос идёт только через девятки.

## Ключевое наблюдение

Прибавляем единицу как в столбике, с последней цифры:

- если цифра меньше `9` — она просто увеличивается, переноса нет, **остальные цифры не меняются** — можно сразу вернуть ответ;
- если цифра `9` — она становится `0`, единица переносится в разряд левее, повторяем.

Цикл дойдёт до начала массива, только если **все цифры — девятки**. Тогда они все стали нулями, и нужно добавить новый старший разряд `1`.

## Техники

### Сложение с переносом (длинная арифметика)

**Что это.** Числа, не помещающиеся в стандартный тип, хранят как последовательность цифр и складывают поразрядно, от младшего разряда к старшему, передавая **перенос**. Общий шаблон: `sum = a + b + carry`, цифра — `sum % 10`, перенос — `Math.floor(sum / 10)`.

**Типичный шаблон:**

```ts naive
let carry = 1; // прибавляем единицу
for (let i = digits.length - 1; i >= 0; i--) {
  const sum = digits[i] + carry;
  digits[i] = sum % 10;
  carry = Math.floor(sum / 10);
}
if (carry) digits.unshift(carry);
```

Это прямой обобщённый вариант. Решение задачи упрощает его, пользуясь тем, что прибавляем **ровно единицу**: перенос либо `1` (если цифра была `9`), либо его нет — и тогда можно выйти досрочно.

Когда использовать: Add Binary, Add Strings, Add Two Numbers (на связных списках), Multiply Strings. Подробнее о длинной арифметике — во вкладке «Теория».

### Ранний выход

Как только перенос исчез, старшие разряды уже не изменятся, — значит, ответ готов, и цикл можно прервать `return`. Это превращает типичный случай в `O(1)`: в случайном числе последняя цифра равна `9` лишь с вероятностью 1/10.

## Трассировка

`digits = [1, 2, 9]` (129 + 1 = 130):

1. `i = 2`: `digits[2] = 9` — не меньше `9`, пишем `0`. Массив `[1, 2, 0]`, идём дальше.
2. `i = 1`: `digits[1] = 2 < 9` → `digits[1] = 3`, возвращаем `[1, 3, 0]`.

Цифра `1` в позиции `0` даже не просматривалась.

`digits = [9, 9, 9]` (999 + 1 = 1000):

1. `i = 2`: `9` → `0`, массив `[9, 9, 0]`.
2. `i = 1`: `9` → `0`, массив `[9, 0, 0]`.
3. `i = 0`: `9` → `0`, массив `[0, 0, 0]`.
4. Цикл закончился → возвращаем `[1, 0, 0, 0]`.

`digits = [4, 3, 2, 1]`: на первом же шаге `1 < 9` → `[4, 3, 2, 2]`.

## Почему это работает

Пусть в конце массива стоит `t` девяток (`t ≥ 0`), а перед ними цифра `d < 9` (или массив закончился). Тогда при прибавлении единицы по правилам столбика:

- каждая из `t` девяток даёт `9 + 1 = 10` → цифра `0`, перенос `1`;
- цифра `d` получает перенос: `d + 1 ≤ 9` — перенос гасится;
- все цифры левее `d` не получают переноса и не меняются.

Код делает ровно это: обнуляет хвостовые девятки, увеличивает первую не-девятку и выходит. Если не-девятки нет (`t = длина массива`), число равно `10^t − 1`, а `10^t − 1 + 1 = 10^t` — единица и `t` нулей, что и возвращает `[1, ...digits]`.

## Пограничные случаи

- **`[0]`**: `0 < 9` → `[1]`.
- **`[9]`**: цикл обнуляет → `[1, 0]`.
- **Все девятки любой длины**: массив вырастает на один элемент.
- **Девятки в середине, но не в конце** (`[9, 9, 1]`): затрагивается только последняя цифра → `[9, 9, 2]`.
- **100 цифр**: никаких проблем с точностью — мы не строим число целиком.

## Сложность

- **Время `O(n)` в худшем случае** (все девятки: цикл проходит весь массив, плюс копирование в новый массив). В среднем — `O(1)`: цикл останавливается на первой цифре, которая не `9`.
- **Память `O(1)` дополнительной**, если не считать ответ: изменяем вход на месте. В случае «все девятки» создаётся новый массив длины `n + 1` — это `O(n)`, но это и есть ответ.

## Типичные ошибки

1. **Перевод в `Number`** → потеря точности для длинных массивов (больше ~16 цифр).
2. **Забыть случай «все девятки»** → для `[9, 9]` вернётся `[0, 0]` вместо `[1, 0, 0]`.
3. **Идти слева направо** → прибавление начинается со старшего разряда, переносы не работают.
4. **Не выйти после увеличения цифры** → цикл продолжает и, например, обнуляет или увеличивает старшие цифры.
5. **Возвращать `[1, ...digits]` внутри цикла** или писать `1` в `digits[0]` без добавления разряда → для `[9, 9]` получится `[1, 0]` (= 10), а не 100.

## Как узнать такую задачу

- Число дано **массивом цифр, строкой или списком** и может быть длиннее 15–16 цифр.
- Нужно прибавить/сложить/умножить «вручную».
- Ключевое слово «перенос» и операция «+1» — сигнал к раннему выходу, как только перенос исчез. Родственные задачи: Add Binary, Add Strings, Add Two Numbers, Multiply Strings, Plus One Linked List.
