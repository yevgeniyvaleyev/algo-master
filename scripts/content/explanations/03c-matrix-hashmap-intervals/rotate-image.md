## Задача простыми словами

Дана квадратная матрица `n x n` — «картинка». Нужно повернуть её на **90° по часовой стрелке**, причём **на месте**: менять саму матрицу, не создавая вторую.

Пример:

```
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

Первая строка `1 2 3` стала последним столбцом, первый столбец `1 4 7` (снизу вверх: `7 4 1`) — первой строкой.

## Наивный подход

Если бы копия была разрешена, всё решалось бы одной формулой. При повороте по часовой элемент из строки `i`, столбца `j` переезжает в строку `j`, столбец `n - 1 - i`:

```ts naive
const copy = matrix.map((row) => [...row]);
for (let i = 0; i < n; i++)
  for (let j = 0; j < n; j++)
    matrix[j][n - 1 - i] = copy[i][j];
```

Время `O(n²)` — оптимально, но памяти тоже `O(n²)`, а условие это запрещает. Без копии та же формула не работает: записав `matrix[j][n - 1 - i]`, мы **затираем** значение, которое ещё не успели перенести. Проблема не в количестве работы, а в том, что одна «сложная» перестановка ломает данные, если делать её прямолинейно.

## Ключевое наблюдение

Поворот можно **разложить на две простые перестановки**, каждая из которых делается на месте обменами пар:

1. **Транспонирование** `(i, j) → (j, i)` — отражение относительно главной диагонали. Элементы меняются **парами**, никто не затирается.
2. **Разворот каждой строки** `(j, i) → (j, n - 1 - i)` — отражение слева направо. Тоже обмены пар.

Композиция: `(i, j) → (j, i) → (j, n - 1 - i)` — ровно формула поворота. Два отражения дают поворот — это верно и в геометрии.

## Техники

### Разложение преобразования на простые шаги

**Что это.** Сложную перестановку элементов заменяют последовательностью простых, у которых есть удобная реализация «на месте». Отражения (транспонирование, разворот строк или столбцов) — идеальные кандидаты: каждое — набор независимых обменов пар, поэтому ничего не теряется.

**Типичные комбинации:**

- по часовой на 90° — транспонировать, затем развернуть каждую строку;
- против часовой на 90° — транспонировать, затем развернуть порядок строк (или развернуть строки, затем транспонировать);
- на 180° — развернуть порядок строк и каждую строку.

**Как применяется здесь.** Шаг 1 — транспонирование с обменами через деструктуризацию, шаг 2 — `row.reverse()`. Подробнее о приёмах работы с матрицами — во вкладке «Теория».

### Обмен через деструктуризацию

`[a, b] = [b, a]` — идиома JS/TS для обмена двух значений без временной переменной. Справа создаётся временный массив из старых значений, затем они раскладываются по местам слева.

## Разбор кода

```ts
function rotate(matrix: number[][]): void {
  const n = matrix.length;
```

Функция ничего не возвращает — меняет `matrix` на месте. `n` — сторона квадрата.

```ts
  // 1. Транспонируем: меняем местами элементы относительно главной диагонали.
  //    Берём только j > i, иначе каждая пара поменялась бы дважды
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
    }
  }
```

Перебираем только клетки **над** главной диагональю (`j > i`). Каждая такая клетка `(i, j)` меняется со своим зеркальным отражением `(j, i)` под диагональю. Почему не все `j`? Если бы внутренний цикл шёл от `0`, пара `(0, 1)`–`(1, 0)` поменялась бы при `i = 0, j = 1`, а потом **обратно** при `i = 1, j = 0` — матрица осталась бы прежней. Диагональные клетки (`j = i`) переходят сами в себя, их пропускаем.

```ts
  // 2. Разворачиваем каждую строку — получаем поворот на 90° по часовой
  for (const row of matrix) {
    row.reverse();
  }
}
```

`Array.prototype.reverse` разворачивает массив **на месте**, и `row` — ссылка на настоящую строку матрицы, а не копия. Поэтому изменения видны в `matrix`. После транспонирования строка `j` содержит бывший столбец `j` сверху вниз; разворот превращает его в «снизу вверх» — именно так столбец выглядит после поворота по часовой.

## Трассировка

`matrix = [[1,2,3],[4,5,6],[7,8,9]]`, `n = 3`.

Шаг 1, транспонирование:

1. `i = 0, j = 1`: меняем `(0,1)=2` и `(1,0)=4` → `[[1,4,3],[2,5,6],[7,8,9]]`.
2. `i = 0, j = 2`: меняем `(0,2)=3` и `(2,0)=7` → `[[1,4,7],[2,5,6],[3,8,9]]`.
3. `i = 1, j = 2`: меняем `(1,2)=6` и `(2,1)=8` → `[[1,4,7],[2,5,8],[3,6,9]]`.
4. `i = 2`: внутренний цикл пуст.

```
1 4 7
2 5 8
3 6 9
```

Шаг 2, разворот строк: `[1,4,7] → [7,4,1]`, `[2,5,8] → [8,5,2]`, `[3,6,9] → [9,6,3]`.

```
7 4 1
8 5 2
9 6 3
```

Совпадает с ожидаемым ответом. Проверим один элемент по формуле: `1` был в `(0, 0)` и должен попасть в `(0, n - 1 - 0) = (0, 2)` — так и есть.

## Почему это работает

Проследим за элементом, исходно стоявшим в `(i, j)`:

- после транспонирования он в `(j, i)` — каждая пара обменивается ровно один раз, диагональ на месте;
- после разворота строки `j` позиция `i` переходит в `n - 1 - i`, то есть элемент оказывается в `(j, n - 1 - i)`.

А `(i, j) → (j, n - 1 - i)` — это определение поворота на 90° по часовой стрелке: строка `i` становится столбцом `n - 1 - i` (первая строка — последним столбцом), столбец `j` — строкой `j`. Оба шага — биекции, реализованные обменами, поэтому ни одно значение не теряется и не дублируется.

## Пограничные случаи

- **`n = 1`**: транспонирование ничего не делает, разворот строки из одного элемента — тоже. Матрица не меняется, что и есть поворот.
- **`n = 2`**: один обмен при транспонировании, затем развороты строк.
- **Чётное и нечётное `n`**: разницы нет; у нечётной матрицы центр остаётся на месте.
- **Отрицательные и повторяющиеся значения**: алгоритм переставляет позиции и не смотрит на значения.

## Сложность

- **Время `O(n²)`**: транспонирование — `n(n - 1) / 2` обменов, разворот — `n / 2` обменов в каждой из `n` строк. Каждый элемент перемещается константное число раз.
- **Память `O(1)`**: всё на месте. Временный двухэлементный массив при деструктуризации — константа.

## Типичные ошибки

1. **Внутренний цикл от `0`, а не от `i + 1`** → каждая пара меняется дважды, транспонирование «отменяет само себя».
2. **Перепутать направление**: разворот порядка **строк** вместо разворота каждой строки даёт поворот **против** часовой.
3. **`matrix = copy`** или возврат новой матрицы → проверяется исходный объект, а он не изменился.
4. **Пытаться применить формулу `(i, j) → (j, n - 1 - i)` напрямую на месте** → значения затираются до переноса.
5. **Применять трюк к прямоугольной матрице**: транспонирование на месте работает только для квадрата (здесь это гарантировано).

## Как узнать такую задачу

- Нужно повернуть или отразить квадратную матрицу **на месте**, без копии.
- Сложная перестановка элементов разлагается на **отражения** — их легко сделать обменами пар.
- Альтернатива того же класса — поворот «кольцами»: циклическая перестановка четвёрок элементов через одну временную переменную.
- Родственные задачи: Transpose Matrix, Flip an Image, Determine Whether Matrix Can Be Obtained By Rotation, Spiral Matrix (обход слоями).
