## Задача простыми словами

Дана доска судоку `9 x 9`, частично заполненная цифрами `'1'`–`'9'`, пустые клетки — `'.'`. Нужно ответить, **нет ли повторов**: ни в одной строке, ни в одном столбце и ни в одном из девяти блоков `3 x 3` одна и та же цифра не должна встречаться дважды. Решать судоку не нужно — доска может быть «корректной», но нерешаемой.

Пример: если в левом верхнем блоке стоят две восьмёрки (в клетках `(0, 0)` и `(2, 2)`), ответ `false`, даже если в строках и столбцах повторов нет.

## Наивный подход

Самое прямолинейное — проверить каждое правило отдельно: 9 строк, 9 столбцов, 9 блоков, и для каждой группы из 9 клеток сравнить все пары:

```ts naive
function hasDup(cells: string[]): boolean {
  for (let i = 0; i < cells.length; i++)
    for (let j = i + 1; j < cells.length; j++)
      if (cells[i] !== '.' && cells[i] === cells[j]) return true;
  return false;
}
// собрать 27 групп по 9 клеток и вызвать hasDup для каждой
```

Доска маленькая, поэтому это тоже `O(1)`, но работа лишняя: каждая клетка просматривается три раза (в своей строке, столбце и блоке), а внутри группы — попарные сравнения `36` на группу. Плюс отдельный код, чтобы собрать клетки блока. Если обобщить на доску `n x n`, попарные сравнения дадут `O(n³)`.

## Ключевое наблюдение

Вопрос «встречалась ли уже эта цифра в группе?» — это вопрос к **множеству увиденного**. Если для каждой из 27 групп держать свой `Set`, то каждую клетку достаточно посмотреть **один раз**: проверить три множества (строки, столбца и блока) и добавить в них цифру.

Остаётся одна тонкость — понять, в каком блоке лежит клетка `(r, c)`. Это делается формулой без условий: `b = Math.floor(r / 3) * 3 + Math.floor(c / 3)`.

## Техники

### Хеш-множество «увиденного»

**Что это.** `Set` хранит уникальные значения и проверяет наличие (`has`) и добавляет (`add`) за `O(1)` в среднем. Шаблон «детектор повторов»: идём по элементам, для каждого спрашиваем `has`; если да — повтор найден, иначе `add`.

**Когда применять.** Любая задача вида «есть ли дубликат?», «все ли элементы различны?» — особенно когда групп несколько и каждому элементу нужно «отметиться» в нескольких группах одновременно.

**Как применяется здесь.** Три массива по 9 множеств: `rows`, `cols`, `boxes`. Каждая цифра проверяется и регистрируется сразу в трёх. Подробнее о хеш-таблицах и о работе с матрицами — во вкладке «Теория».

### Индексация блоков матрицы

Доска делится на полосы по 3 строки и по 3 столбца. `Math.floor(r / 3)` — номер полосы блоков сверху (`0..2`), `Math.floor(c / 3)` — номер блока в полосе слева (`0..2`). Склеиваем их как двузначное число в системе по основанию 3: `полоса * 3 + блок_в_полосе`. Блоки нумеруются так:

```
0 1 2
3 4 5
6 7 8
```

Например, клетка `(4, 7)`: `Math.floor(4 / 3) = 1`, `Math.floor(7 / 3) = 2`, `b = 1 * 3 + 2 = 5` — средний ряд, правый блок.

## Разбор кода

```ts
function isValidSudoku(board: string[][]): boolean {
  // По одному набору увиденных цифр на каждую строку, столбец и блок 3x3
  const rows = Array.from({ length: 9 }, () => new Set<string>());
  const cols = Array.from({ length: 9 }, () => new Set<string>());
  const boxes = Array.from({ length: 9 }, () => new Set<string>());
```

Создаём 27 пустых множеств. Важно именно `Array.from` с функцией-фабрикой: она вызывается 9 раз и создаёт **9 разных** `Set`. Вариант `new Array(9).fill(new Set())` положил бы во все ячейки **один и тот же** объект, и все строки делили бы общее множество. Цифры храним строками (`'5'`), как они лежат на доске, — конвертировать в числа незачем.

```ts
  for (let r = 0; r < 9; r++) {
    for (let c = 0; c < 9; c++) {
      const d = board[r][c];
      // Пустые клетки не проверяем
      if (d === '.') continue;
```

Обходим все 81 клетку построчно. Пустые пропускаем — иначе множество запомнило бы `'.'`, и вторая пустая клетка в строке «оказалась бы повтором».

```ts
      // Номер блока: 3 блока в ряду, блоки нумеруются слева направо, сверху вниз
      const b = Math.floor(r / 3) * 3 + Math.floor(c / 3);
```

Номер блока `0..8` по формуле из раздела «Техники». `Math.floor` нужен потому, что в JS деление `/` дробное: `4 / 3 = 1.33…`.

```ts
      // Цифра уже встречалась в этой строке, столбце или блоке — доска некорректна
      if (rows[r].has(d) || cols[c].has(d) || boxes[b].has(d)) {
        return false;
      }
```

Главная проверка: если цифра `d` уже есть хотя бы в одной из трёх групп клетки, найден повтор — можно сразу выходить. Дальше проверять нет смысла.

```ts
      rows[r].add(d);
      cols[c].add(d);
      boxes[b].add(d);
    }
  }

  return true;
}
```

Регистрируем цифру во всех трёх группах — **после** проверки, чтобы клетка не конфликтовала сама с собой. Если весь обход прошёл без повторов, доска корректна.

## Трассировка

Пример 2 из условия: в клетке `(0, 0)` стоит `'8'` вместо `'5'`. Первые строки доски:

```
r=0: 8 3 . . 7 . . . .
r=1: 6 . . 1 9 5 . . .
r=2: . 9 8 . . . . 6 .
```

1. `(0, 0) = '8'`, `b = 0`. Все множества пусты → добавляем: `rows[0] = {8}`, `cols[0] = {8}`, `boxes[0] = {8}`.
2. `(0, 1) = '3'`, `b = 0` → `rows[0] = {8, 3}`, `cols[1] = {3}`, `boxes[0] = {8, 3}`.
3. `(0, 4) = '7'`, `b = 1` → `rows[0] = {8, 3, 7}`, `boxes[1] = {7}`.
4. Строка 1: `'6'` в `(1, 0)` (блок 0), `'1'`, `'9'`, `'5'` в столбцах 3–5 (блок 1). Повторов нет; `boxes[0] = {8, 3, 6}`.
5. `(2, 1) = '9'`, `b = 0`. В `rows[2]` пусто, в `cols[1] = {3}` нет `'9'`, в `boxes[0] = {8, 3, 6}` нет → добавляем, `boxes[0] = {8, 3, 6, 9}`.
6. `(2, 2) = '8'`, `b = Math.floor(2/3) * 3 + Math.floor(2/3) = 0`. `rows[2] = {9}` — нет, `cols[2]` пуст — нет, `boxes[0]` **содержит** `'8'` → `return false`.

Повтор пойман через множество блока; до восьмёрки в `(3, 0)` (повтор по столбцу) обход даже не дошёл. На примере 1 (там в углу `'5'`) ни одна проверка не срабатывает, и функция возвращает `true`.

## Почему это работает

Инвариант: перед обработкой клетки `(r, c)` множества `rows[r]`, `cols[c]` и `boxes[b]` содержат **ровно** цифры из уже просмотренных клеток соответствующей строки, столбца и блока. Он верен в начале (всё пусто) и сохраняется, потому что каждую непустую клетку после проверки добавляем во все три её группы.

Если в какой-то группе есть повтор — две клетки с цифрой `d`, — то при обработке второй из них первая уже просмотрена, значит, `d` лежит в множестве этой группы, и проверка вернёт `false`. Обратно: `false` возвращается только при реальном повторе, ведь множества содержат только настоящие цифры этой группы. Значит, `true` ровно тогда, когда повторов нет.

## Пограничные случаи

- **Пустая доска** (все `'.'`): ни одна клетка не проверяется, ответ `true`.
- **Корректная, но нерешаемая доска**: ответ `true` — по условию решаемость не проверяем.
- **Повтор только в блоке** (не в строке и не в столбце) — как в примере 2: ловится благодаря `boxes`.
- **Повтор в последней клетке**: обход дойдёт до неё и вернёт `false`, раннего выхода нет, но и не нужно.

## Сложность

- **Время `O(1)`**: доска всегда `9 x 9`, то есть 81 клетка, на каждую — три `has` и три `add` за `O(1)`. В обобщении на `n x n` — `O(n²)`, по разу на клетку.
- **Память `O(1)`**: 27 множеств, в каждом не больше 9 цифр — максимум 243 элемента. Для `n x n` — `O(n²)`.

## Типичные ошибки

1. **`new Array(9).fill(new Set())`** → все 9 ячеек ссылаются на одно множество, и цифры из разных строк «конфликтуют» друг с другом.
2. **Неверная формула блока**, например `r / 3 + c / 3` или `Math.floor(r / 3) + Math.floor(c / 3)` → разные блоки получают одинаковые номера (блоки `1` и `3` слипаются).
3. **Не пропускать `'.'`** → вторая пустая клетка в строке считается повтором.
4. **Пытаться решить судоку** (бэктрекинг) — условие требует только проверить повторы.
5. **Забыть одну из трёх проверок** — чаще всего блоки.

## Как узнать такую задачу

- Вопрос «**нет ли повторов** / все ли элементы различны» внутри нескольких **групп одновременно** → по множеству (или битовой маске) на группу.
- Двумерная сетка, разбитая на **подблоки** → формула номера блока `Math.floor(r / k) * (n / k) + Math.floor(c / k)`.
- Связанные задачи: Sudoku Solver (те же множества, плюс бэктрекинг), Contains Duplicate, N-Queens (множества для столбцов и диагоналей).
