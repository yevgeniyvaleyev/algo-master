## Задача простыми словами

Дан массив строк `strs` из строчных латинских букв. Нужно разбить строки на группы **анаграмм** — слов, составленных из одного и того же набора букв (с учётом количества). Порядок групп и строк внутри групп не важен.

Пример: `["eat","tea","tan","ate","nat","bat"]` → `[["eat","tea","ate"],["tan","nat"],["bat"]]`. У `eat`, `tea`, `ate` буквы одинаковые: по одной `a`, `e`, `t`.

## Наивный подход

Сравнивать каждую строку с представителем каждой уже найденной группы: «является ли она анаграммой?».

```ts naive
const groups: string[][] = [];
for (const s of strs) {
  const g = groups.find((grp) => isAnagram(grp[0], s));
  if (g) g.push(s);
  else groups.push([s]);
}
```

Проверка `isAnagram` стоит `O(k)` (подсчёт букв), но для каждой строки мы перебираем **все группы** — до `n` штук. Итого `O(n² · k)`: при `n = 10⁴` это сотни миллионов операций. Лишняя работа — **линейный поиск группы**: мы снова и снова сравниваем строку с чужими группами, хотя по самой строке можно сразу сказать, в какую группу она попадёт.

## Ключевое наблюдение

У всех анаграмм есть общая «подпись» — **канонический ключ**, одинаковый для анаграмм и разный для остальных строк. Например, вектор частот 26 букв: у `eat` и `tea` он один и тот же — по единице на позициях `a`, `e`, `t`.

Если вычислить ключ для каждой строки, группировка превращается в раскладку по корзинам: `Map<ключ, строки>`. Поиск корзины — `O(1)`, а не перебор всех групп.

## Техники

### Группировка по каноническому ключу

**Что это.** Шаблон для задач «разбить объекты на классы эквивалентности»: придумываем функцию `key(x)`, такую что `key(a) === key(b)` ⇔ `a` и `b` эквивалентны, и раскладываем объекты в `Map<ключ, список>`. Хеш-таблица делает поиск нужной группы за `O(1)`.

**Типичные ключи:** отсортированная строка (анаграммы), вектор частот (анаграммы, быстрее), разности соседних символов (Group Shifted Strings), нормализованная форма фигуры (Number of Distinct Islands).

**Как применяется здесь.** Ключ — вектор частот 26 букв, склеенный в строку. Подробнее о хеш-таблицах — во вкладке «Теория».

### Подсчёт частот массивом на 26 букв

Когда алфавит маленький и известен (строчные латинские буквы), вместо `Map<char, number>` удобнее массив длины 26: индекс буквы — `charCodeAt(i) - 97` (`97` — код `'a'`). Это быстрее и даёт упорядоченный вектор, который легко превратить в ключ.

## Разбор кода

```ts
function groupAnagrams(strs: string[]): string[][] {
  // Канонический ключ → все строки с этим ключом
  const groups = new Map<string, string[]>();
```

`groups` — корзины: ключ (подпись анаграммы) → массив строк с этой подписью. `Map` сохраняет порядок вставки, поэтому группы в ответе пойдут в порядке первого появления.

```ts
  for (const s of strs) {
    // Ключ — вектор частот 26 букв: у анаграмм он одинаковый
    const count = new Array<number>(26).fill(0);
    for (let i = 0; i < s.length; i++) {
      count[s.charCodeAt(i) - 97]++;
    }
```

Для каждой строки заводим свежий массив счётчиков из 26 нулей и проходим по символам. `s.charCodeAt(i) - 97` превращает `'a'` в `0`, `'b'` в `1`, …, `'z'` в `25`. После цикла `count[j]` — сколько раз в строке встречается `j`-я буква. Порядок букв в строке на вектор не влияет — именно поэтому анаграммы получают одинаковый вектор.

```ts
    // Разделитель нужен, чтобы [1,11] и [11,1] дали разные ключи
    const key = count.join('#');
```

Массив нельзя использовать как ключ `Map` напрямую: ключи-объекты сравниваются по ссылке, и два одинаковых массива — разные ключи. Поэтому превращаем вектор в строку. Разделитель `#` обязателен: без него частоты `[1, 11, …]` и `[11, 1, …]` дали бы одинаковое начало `"111…"`. Пример ключа для `"eat"`: `"1#0#0#0#1#0#…#1#…"` (единицы на позициях `a`, `e`, `t`).

```ts
    const group = groups.get(key);
    if (group) {
      group.push(s);
    } else {
      groups.set(key, [s]);
    }
  }
```

Ищем корзину по ключу. Есть — дописываем строку в неё (массив изменяется по ссылке, `set` повторно не нужен). Нет — создаём новую группу из одной строки. Проверка `if (group)` корректна: в `Map` лежат только непустые массивы, а массив — всегда истинное значение.

```ts
  return [...groups.values()];
}
```

`groups.values()` — итератор по массивам-группам; спред превращает его в обычный массив, который и требуется вернуть.

## Трассировка

`strs = ["eat","tea","tan","ate","nat","bat"]`. Ключи для краткости записаны как набор ненулевых частот:

1. `"eat"` → ключ `{a:1, e:1, t:1}`. Корзины нет → `groups = { aet: ["eat"] }`.
2. `"tea"` → тот же ключ `{a:1, e:1, t:1}` → `aet: ["eat","tea"]`.
3. `"tan"` → `{a:1, n:1, t:1}`, новая корзина → `ant: ["tan"]`.
4. `"ate"` → `{a:1, e:1, t:1}` → `aet: ["eat","tea","ate"]`.
5. `"nat"` → `{a:1, n:1, t:1}` → `ant: ["tan","nat"]`.
6. `"bat"` → `{a:1, b:1, t:1}`, новая корзина → `abt: ["bat"]`.

```
groups.values() → [["eat","tea","ate"], ["tan","nat"], ["bat"]]
```

Порядок отличается от примера в условии, но по условию любой порядок допустим.

Пример 2, `strs = [""]`: цикл по символам не выполняется, ключ — 26 нулей через `#`. Одна корзина `[""]`, ответ `[[""]]`.

## Почему это работает

Две строки — анаграммы тогда и только тогда, когда каждая буква встречается в них одинаковое число раз, то есть когда совпадают их векторы частот. Строковое представление `count.join('#')` взаимно однозначно с вектором: разделитель не даёт двум разным векторам склеиться в одинаковую строку (каждое число отделено, позиции фиксированы — ровно 26 чисел).

Значит, `key(a) === key(b)` ⇔ `a` и `b` анаграммы. Каждая строка попадает ровно в одну корзину — по своему ключу, — поэтому корзины и есть искомые группы: в одной корзине только анаграммы, и все анаграммы — в одной корзине.

## Пограничные случаи

- **Пустая строка** `""`: ключ из 26 нулей; все пустые строки попадают в одну группу.
- **Одна строка**: одна группа из неё самой.
- **Повторяющиеся строки** (`["a","a"]`): обе в одной группе — это ожидаемо.
- **Буквы с частотой ≥ 10**: благодаря `#` ключ однозначен.
- **Строки разной длины**: векторы точно разные, группы не смешиваются.

## Сложность

- **Время `O(n · k)`**, где `n` — число строк, `k` — максимальная длина: подсчёт букв `O(k)` на строку, построение ключа `O(26)` и операции с `Map` по ключу длины `O(26)` — константа. Вариант с сортировкой букв дал бы `O(n · k log k)`.
- **Память `O(n · k)`**: все строки лежат в группах, плюс `n` ключей по `O(26)` символов.

## Типичные ошибки

1. **Массив как ключ `Map`** (`groups.get(count)`) → ключи сравниваются по ссылке, каждая строка образует свою группу.
2. **`count.join('')` без разделителя** → разные векторы частот склеиваются в одинаковый ключ.
3. **Один `count` на все строки**, созданный вне цикла → частоты накапливаются от строки к строке.
4. **Сравнивать строку с каждой группой** → `O(n² · k)`, тайм-аут.
5. **`charCodeAt(i) - 65`** (код `'A'`) → индекс выходит за пределы массива для строчных букв.

## Как узнать такую задачу

- Нужно **сгруппировать** объекты по отношению эквивалентности («одинаковые с точностью до перестановки / сдвига / поворота»).
- Эквивалентность можно выразить **каноническим представлением** — отсортированной формой, вектором частот, нормализацией.
- Слова «анаграмма», «перестановка букв» — сигнал к подсчёту частот на 26 букв.
- Родственные задачи: Valid Anagram, Find All Anagrams in a String, Group Shifted Strings, Ransom Note.
