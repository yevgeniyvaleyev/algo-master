## Задача простыми словами

Дан массив строк `strs` из строчных латинских букв. Нужно разбить строки на группы **анаграмм** — слов, составленных из одного и того же набора букв (с учётом количества). Порядок групп и строк внутри групп не важен.

Пример: `["eat","tea","tan","ate","nat","bat"]` → `[["eat","tea","ate"],["tan","nat"],["bat"]]`. У `eat`, `tea`, `ate` буквы одинаковые: по одной `a`, `e`, `t`.

## Наивный подход

Сравнивать каждую строку с представителем каждой уже найденной группы: «является ли она анаграммой?».

```ts naive
const groups: string[][] = [];
for (const s of strs) {
  const g = groups.find((grp) => isAnagram(grp[0], s));
  if (g) g.push(s);
  else groups.push([s]);
}
```

Проверка `isAnagram` стоит `O(k)` (подсчёт букв), но для каждой строки мы перебираем **все группы** — до `n` штук. Итого `O(n² · k)`: при `n = 10⁴` это сотни миллионов операций. Лишняя работа — **линейный поиск группы**: мы снова и снова сравниваем строку с чужими группами, хотя по самой строке можно сразу сказать, в какую группу она попадёт.

## Ключевое наблюдение

У всех анаграмм есть общая «подпись» — **канонический ключ**, одинаковый для анаграмм и разный для остальных строк. Самый простой такой ключ — **буквы строки, отсортированные по алфавиту**: `"eat"`, `"tea"` и `"ate"` все превращаются в `"aet"`. Перестановка букв не меняет отсортированный вид, а другой набор букв даёт другую строку.

Если вычислить ключ для каждой строки, группировка превращается в раскладку по корзинам: `Map<ключ, строки>`. Поиск корзины — `O(1)`, а не перебор всех групп.

## Техники

### Группировка по каноническому ключу

**Что это.** Шаблон для задач «разбить объекты на классы эквивалентности»: придумываем функцию `key(x)`, такую что `key(a) === key(b)` ⇔ `a` и `b` эквивалентны, и раскладываем объекты в `Map<ключ, список>`. Хеш-таблица делает поиск нужной группы за `O(1)`.

**Типичные ключи:** отсортированная строка (анаграммы), вектор частот (анаграммы, быстрее), разности соседних символов (Group Shifted Strings), нормализованная форма фигуры (Number of Distinct Islands).

**Как применяется здесь.** Ключ — отсортированные буквы строки. Подробнее о хеш-таблицах — во вкладке «Теория».

### Сортировка символов строки

Строки в JavaScript неизменяемы и не имеют метода `sort`. Поэтому строку разбивают на массив символов (`[...s]` или `s.split('')`), сортируют массив и склеивают обратно `join('')`. `sort()` без компаратора сравнивает строки посимвольно — для одиночных строчных латинских букв это ровно алфавитный порядок.

## Разбор кода

```ts
function groupAnagrams(strs: string[]): string[][] {
  // Канонический ключ → все строки с этим ключом
  const groups = new Map<string, string[]>();
```

`groups` — корзины: ключ (подпись анаграммы) → массив строк с этой подписью. `Map` сохраняет порядок вставки, поэтому группы в ответе пойдут в порядке первого появления.

```ts
  for (const s of strs) {
    // Ключ — буквы строки по алфавиту: у всех анаграмм он одинаковый
    // ("eat", "tea", "ate" → "aet")
    const key = [...s].sort().join('');
```

Для каждой строки строим ключ: `[...s]` превращает `"tea"` в `['t','e','a']`, `sort()` упорядочивает — `['a','e','t']`, `join('')` склеивает в `"aet"`. Исходная строка `s` при этом не меняется — сортируется только временный массив.

```ts
    // Нет группы — создаём пустую, затем дописываем строку
    if (!groups.has(key)) {
      groups.set(key, []);
    }
    groups.get(key)!.push(s);
  }
```

Если корзины с таким ключом ещё нет, кладём пустой массив. После этого корзина гарантированно существует, и мы дописываем в неё строку. Восклицательный знак `!` говорит TypeScript, что `get` здесь не вернёт `undefined`. Массив меняется по ссылке, поэтому повторный `set` не нужен.

```ts
  return [...groups.values()];
}
```

`groups.values()` — итератор по массивам-группам; спред превращает его в обычный массив, который и требуется вернуть.

## Трассировка

`strs = ["eat","tea","tan","ate","nat","bat"]`:

1. `"eat"` → ключ `"aet"`. Корзины нет → `groups = { aet: ["eat"] }`.
2. `"tea"` → `"aet"` → `aet: ["eat","tea"]`.
3. `"tan"` → `"ant"`, новая корзина → `ant: ["tan"]`.
4. `"ate"` → `"aet"` → `aet: ["eat","tea","ate"]`.
5. `"nat"` → `"ant"` → `ant: ["tan","nat"]`.
6. `"bat"` → `"abt"`, новая корзина → `abt: ["bat"]`.

```
groups.values() → [["eat","tea","ate"], ["tan","nat"], ["bat"]]
```

Порядок отличается от примера в условии, но по условию любой порядок допустим.

Пример 2, `strs = [""]`: `[...""]` — пустой массив, ключ — пустая строка `""`. Одна корзина `[""]`, ответ `[[""]]`.

## Почему это работает

Две строки — анаграммы тогда и только тогда, когда они состоят из одних и тех же букв в одних и тех же количествах. Сортировка расставляет эти буквы в единственно возможном порядке, поэтому у анаграмм отсортированные строки совпадают. И наоборот: если отсортированные строки совпали, то и мультимножества букв совпадают — строки анаграммы.

Значит, `key(a) === key(b)` ⇔ `a` и `b` анаграммы. Каждая строка попадает ровно в одну корзину — по своему ключу, — поэтому корзины и есть искомые группы: в одной корзине только анаграммы, и все анаграммы — в одной корзине.

## Пограничные случаи

- **Пустая строка** `""`: ключ — пустая строка; все пустые строки попадают в одну группу.
- **Одна строка**: одна группа из неё самой.
- **Повторяющиеся строки** (`["a","a"]`): обе в одной группе — это ожидаемо.
- **Повторяющиеся буквы** (`"abb"`, `"bab"`): ключ `"abb"` учитывает количество, `"ab"` в эту группу не попадёт.
- **Строки разной длины**: ключи разной длины, группы не смешиваются.

## Сложность

- **Время `O(n · k log k)`**, где `n` — число строк, `k` — максимальная длина: сортировка букв стоит `O(k log k)` на строку, операции с `Map` по ключу длины `k` — `O(k)`.
- **Память `O(n · k)`**: все строки лежат в группах, плюс `n` ключей длиной до `k`.

**Follow-up на собеседовании: ключ за `O(k)`.** Вместо сортировки можно посчитать частоты 26 букв и склеить их через разделитель:

```ts naive
const count = new Array<number>(26).fill(0);
for (let i = 0; i < s.length; i++) count[s.charCodeAt(i) - 97]++;
const key = count.join('#'); // "#" нужен, чтобы [1,11] и [11,1] дали разные ключи
```

Тогда время — `O(n · k)`. При `k ≤ 100` разница невелика, поэтому основным решением удобнее рассказывать сортировку, а вектор частот предлагать как улучшение.

## Типичные ошибки

1. **Массив как ключ `Map`** (`groups.get([...s].sort())`) → ключи-объекты сравниваются по ссылке, каждая строка образует свою группу. Нужен `join('')`.
2. **`s.sort()`** → у строк нет метода `sort`, сначала нужно превратить строку в массив.
3. **Перезаписывать группу**: `groups.set(key, [s])` без проверки `has` → в каждой группе остаётся только последняя строка.
4. **Сравнивать строку с каждой группой** → `O(n² · k)`, тайм-аут.
5. **В векторе частот — `count.join('')` без разделителя** → разные векторы склеиваются в одинаковый ключ.

## Как узнать такую задачу

- Нужно **сгруппировать** объекты по отношению эквивалентности («одинаковые с точностью до перестановки / сдвига / поворота»).
- Эквивалентность можно выразить **каноническим представлением** — отсортированной формой, вектором частот, нормализацией.
- Слова «анаграмма», «перестановка букв» — сигнал к сортировке букв или подсчёту частот на 26 букв.
- Родственные задачи: Valid Anagram, Find All Anagrams in a String, Group Shifted Strings, Ransom Note.
