## Задача простыми словами

Дана строка `s` — корректное арифметическое выражение из неотрицательных целых чисел, операторов `+` и `-`, скобок `(` `)` и пробелов. Минус может быть **унарным** (`-1`, `-(2 + 3)`). Нужно вычислить значение, не используя `eval`.

Пример: `s = "2 - (5 - 6)"` → `3`. Внутри скобки `5 - 6 = -1`, а `2 - (-1) = 3`.

Умножения и деления нет — только сложение и вычитание, но скобки могут быть вложены сколь угодно глубоко.

## Наивный подход

Очевидная идея — раскрывать скобки «изнутри наружу»: найти самую внутреннюю пару `(...)` (без скобок внутри), посчитать её как простую сумму, подставить результат в строку и повторять.

```ts naive
while (s.includes('(')) {
  s = s.replace(/\(([^()]*)\)/, (_, inner) => String(evalFlat(inner)));
}
return evalFlat(s);
```

Проблемы: каждая подстановка пересобирает строку за `O(n)`, а скобок может быть `O(n)` — итого `O(n²)`. Кроме того, подстановка отрицательного результата порождает конструкции вроде `2 - -1`, которые `evalFlat` тоже должна уметь разбирать. Лишняя работа — многократное пересканирование одних и тех же символов строки.

Альтернатива — полноценный парсер: перевод в RPN алгоритмом «сортировочной станции» и вычисление стеком. Это `O(n)`, но для выражения только с `+` и `-` избыточно.

## Ключевое наблюдение

Когда есть только `+` и `-`, выражение — это **сумма чисел со знаками**. Каждое число входит в ответ со знаком `+1` или `-1`, и этот знак — произведение знака прямо перед числом и знаков перед всеми скобками, которые его охватывают.

Значит, можно идти по строке один раз и накапливать `result` текущего уровня скобок. Когда встречаем `(`, внешнее состояние (`result` и знак перед скобкой) нужно **отложить**, посчитать скобку с нуля, а на `)` — достать отложенное и объединить: `outer + signBefore * inner`. Отложить и потом достать в обратном порядке вложенности — это стек.

## Техники

### Стек для сохранения контекста при вложенности

**Что это.** Стек (LIFO) — массив с `push`/`pop` за `O(1)`. Подробнее — во вкладке «Теория».

**Типичный шаблон.** При входе во вложенную конструкцию (скобку, блок, вызов функции) сохраняем «внешний контекст» на стек и начинаем считать внутреннюю часть с чистого листа. При выходе — снимаем контекст и комбинируем его с результатом внутренней части. Так работает стек вызовов в любом языке программирования.

**Как применяется здесь.** Контекст — пара `[result, sign]`: сумма внешнего уровня до скобки и знак перед скобкой. Кладём оба числа в один плоский стек, снимаем в обратном порядке.

### Однопроходный разбор чисел по цифрам

Число может быть многозначным. Его собирают по цифрам: `num = num * 10 + digit`. Число считается законченным, когда встречается не-цифра, влияющая на вычисление (`+`, `-`, `)`) или конец строки.

## Разбор кода

```ts
function calculate(s: string): number {
  let result = 0; // сумма уже разобранных слагаемых на текущем уровне скобок
  let sign = 1; // знак перед следующим числом или скобкой: +1 или -1
  let num = 0; // число, которое сейчас читаем по цифрам
  // При входе в скобку сохраняем состояние внешнего уровня: [result, sign]
  const stack: number[] = [];
```

Три переменные описывают текущий уровень скобок: накопленная сумма, знак следующего слагаемого и число «в процессе чтения». Начальный `sign = 1`: первое число без знака считается положительным.

```ts
  for (let i = 0; i < s.length; i++) {
    const c = s[i];

    if (c >= '0' && c <= '9') {
      // Число может состоять из нескольких цифр
      num = num * 10 + (c.charCodeAt(0) - 48);
```

Цифра дописывается к `num` справа. `charCodeAt(0) - 48` превращает символ в цифру (`'0'` имеет код 48). Сравнение строк `c >= '0' && c <= '9'` работает посимвольно по кодам.

```ts
    } else if (c === '+' || c === '-') {
      // Число закончилось — добавляем его с его знаком
      result += sign * num;
      num = 0;
      // Знак для следующего слагаемого (унарный минус работает так же: result = 0)
      sign = c === '+' ? 1 : -1;
```

Оператор означает, что предыдущее число закончилось: прибавляем его со своим знаком и сбрасываем `num`. Затем запоминаем знак **следующего** слагаемого.

Почему унарный минус не требует особой обработки: в начале строки или сразу после `(` у нас `num = 0`, и `result += sign * 0` ничего не меняет. Выражение `-3` превращается в `0 - 3`. Также после `)` значение `num` уже сброшено в `0`, поэтому `result += sign * num` тоже ничего не портит.

```ts
    } else if (c === '(') {
      // Запоминаем внешний результат и знак перед скобкой,
      // а внутри скобки начинаем считать с нуля
      stack.push(result, sign);
      result = 0;
      sign = 1;
```

Входим в скобку. На стек кладём два числа: сначала внешний `result`, потом `sign` — знак, который стоит **перед** скобкой. Внутри скобки считаем с нуля: `result = 0`, первое слагаемое положительное. `num` здесь уже `0`: перед `(` всегда стоит оператор или начало строки, а не цифра.

```ts
    } else if (c === ')') {
      // Завершаем последнее число внутри скобки
      result += sign * num;
      num = 0;
```

Выходим из скобки. Сначала добавляем последнее число внутри неё — его не завершил никакой оператор. Теперь `result` — значение всей скобки.

```ts
      // Значение скобки умножаем на знак перед ней и прибавляем к внешнему результату
      const signBefore = stack.pop()!;
      const outer = stack.pop()!;
      result = outer + signBefore * result;
    }
    // Пробелы просто пропускаем
  }
```

Снимаем контекст в обратном порядке: сначала знак (положен последним), затем внешний результат. Внешний уровень продолжается так, будто вся скобка была одним числом со знаком `signBefore`. Пробелы не попадают ни в одну ветку — они просто игнорируются.

```ts
  // Последнее число в строке
  return result + sign * num;
}
```

Если строка закончилась числом, оно ещё не добавлено — добавляем. Если строка закончилась `)`, то `num = 0`, и прибавляется ноль.

## Трассировка

`s = "2-(5-6)"`. Начало: `result = 0`, `sign = 1`, `num = 0`, стек `[]`.

1. `'2'` → `num = 2`.
2. `'-'` → `result = 0 + 1·2 = 2`, `num = 0`, `sign = -1`.
3. `'('` → стек `[2, -1]`, `result = 0`, `sign = 1`.
4. `'5'` → `num = 5`.
5. `'-'` → `result = 0 + 1·5 = 5`, `num = 0`, `sign = -1`.
6. `'6'` → `num = 6`.
7. `')'` → `result = 5 + (-1)·6 = -1`, `num = 0`. Снимаем `signBefore = -1`, `outer = 2`. `result = 2 + (-1)·(-1) = 3`. Стек `[]`.
8. Конец строки: `3 + sign·0 = 3` (здесь `sign = -1` остался изнутри скобки, но `num = 0`, так что это не важно).

Ответ: `3`.

Унарный минус, `s = "-(2+3)"`:

1. `'-'` → `result = 0 + 1·0 = 0`, `sign = -1`.
2. `'('` → стек `[0, -1]`, `result = 0`, `sign = 1`.
3. `'2'`, `'+'` → `result = 2`, `sign = 1`; `'3'` → `num = 3`.
4. `')'` → `result = 2 + 3 = 5`; `result = 0 + (-1)·5 = -5`.

Ответ: `-5`.

## Почему это работает

Инвариант: в любой момент значение всего прочитанного префикса равно

```
outer_k + sign_k · ( … ( outer_1 + sign_1 · (result + sign · num) ) … )
```

то есть текущий уровень `result + sign · num`, «завёрнутый» в сохранённые на стеке уровни.

- Цифра и оператор меняют только текущий уровень, причём сумма `result + sign · num` при переходе через оператор не теряет слагаемых.
- `(` открывает новый уровень с нулевой суммой, сохраняя внешний — значение префикса не меняется.
- `)` сворачивает верхний уровень в число и подставляет его во внешний — ровно по формуле `outer + signBefore · inner`.

Скобки сбалансированы, поэтому к концу строки стек пуст и ответ — `result + sign · num`.

## Пограничные случаи

- **Число без операций** (`"42"`): цифры копятся в `num`, ответ `0 + 1·42`.
- **Унарный минус в начале или после `(`**: работает как `0 - x`.
- **Глубоко вложенные скобки** (`"((((1))))"`): стек растёт до двух чисел на уровень.
- **Пробелы где угодно** (`" 2- 1 "`): игнорируются.
- **Строка заканчивается `)`**: `num = 0`, финальная строка ничего не добавляет.
- **Большие числа**: по условию результат помещается в 32 бита, в JS это безопасно.

## Сложность

- **Время `O(n)`**: каждый символ обрабатывается один раз за `O(1)`.
- **Память `O(n)`**: стек хранит два числа на каждую открытую скобку; при глубине вложенности `O(n)` — `O(n)` памяти.

## Типичные ошибки

1. **Не добавить последнее число** перед `return` или перед закрытием скобки → теряется последнее слагаемое.
2. **Снимать со стека в неправильном порядке** (`outer` раньше `signBefore`) → значения перепутаны.
3. **Не сбрасывать `sign = 1` при `(`** → первое слагаемое внутри скобки получит знак перед скобкой дважды.
4. **Считать только одну цифру** (`num = digit` вместо `num * 10 + digit`) → `"12"` читается как `2`.
5. **Отдельная сложная обработка унарного минуса** → лишний код и ошибки; при `result = 0` он работает сам.

## Как узнать такую задачу

- Строковое выражение со **вложенными скобками**, нужно вычислить без `eval`.
- Вложенность произвольной глубины → стек для сохранения внешнего контекста.
- Только `+` и `-` → выражение как сумма чисел со знаками; если есть `*` и `/`, используется стек слагаемых (Basic Calculator II) или полный парсер.
- Похожие задачи: Basic Calculator II/III, Decode String (`3[a2[c]]`), Evaluate Reverse Polish Notation, Score of Parentheses.
