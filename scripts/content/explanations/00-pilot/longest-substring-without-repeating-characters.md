## Задача простыми словами

Дана строка `s`. Нужно найти длину самого длинного **непрерывного куска** строки (подстроки), в котором ни один символ не повторяется.

Пример: `s = "abcabcbb"`. Подстрока `"abc"` подходит (все символы разные), а `"abca"` — уже нет (`a` дважды). Длиннее 3 ничего не найти — ответ `3`.

Важно: именно **подстрока** (подряд идущие символы), а не подпоследовательность. В `"pwwkew"` ответ `3` (`"wke"`), а не `4` (`"pwke"` — символы не подряд).

## Наивный подход

Перебрать все начала подстроки и от каждого расширяться вправо, пока не встретится повтор:

```ts naive
let best = 0;
for (let i = 0; i < s.length; i++) {
  const seen = new Set<string>();
  for (let j = i; j < s.length; j++) {
    if (seen.has(s[j])) break; // дальше от i расширять бессмысленно
    seen.add(s[j]);
    best = Math.max(best, j - i + 1);
  }
}
```

В худшем случае это `O(n²)`. Где лишняя работа? Когда от начала `i` мы дошли до повтора и начинаем заново с `i + 1`, мы **выбрасываем множество** и заново проверяем почти те же символы, про которые уже всё знаем: они различны. Вместо того чтобы строить множество с нуля, достаточно убрать из него один символ слева.

## Ключевое наблюдение

Если подстрока `s[left..right]` не содержит повторов, то и любая её часть тоже. Поэтому не нужно начинать каждый раз заново: достаточно поддерживать **окно** `[left, right]` без повторов и двигать его границы только вперёд.

- Новый символ `s[right]` пробуем добавить справа.
- Если он уже есть в окне, окно стало бы плохим. Тогда выкидываем символы **слева по одному**, пока его повтор не уйдёт из окна.
- Теперь окно снова без повторов — добавляем `s[right]` и сравниваем длину с лучшей.

Чтобы за `O(1)` отвечать на вопрос «есть ли символ в окне?», символы окна храним в `Set`.

## Техники

### Скользящее окно (sliding window)

**Что это.** Две границы `left` и `right` задают текущий отрезок массива/строки. `right` идёт вперёд и «добавляет» элементы, `left` идёт вперёд и «убирает» их, когда окно перестаёт удовлетворять условию. Каждая граница проходит путь не больше `n`, поэтому весь алгоритм линейный.

**Типичный шаблон («самое длинное окно с условием»):**

```ts naive
for (let right = 0; right < n; right++) {
  while (/* окно с a[right] невалидно */) {
    // убрать a[left] из окна
    left++;
  }
  // добавить a[right] в окно
  best = Math.max(best, right - left + 1);
}
```

**Когда применять.** Задача про **непрерывный** подмассив/подстроку, условие «монотонно»: если окно хорошее, то и все вложенные в него окна хорошие. Здесь условие — «нет повторов» — как раз такое.

**Как применяется здесь.** Окно `[left, right]` всегда без повторов. Подробнее — во вкладке «Теория» (скользящее окно).

### Множество (Set) символов окна

**Что это.** `Set` хранит уникальные значения и за амортизированное `O(1)` умеет `has`, `add` и `delete`. Здесь в нём лежат **ровно символы текущего окна**: добавляем, когда `right` включает символ, удаляем, когда `left` его исключает. Поэтому `window.has(c)` — это ровно вопрос «есть ли `c` в окне?».

## Разбор кода

```ts
function lengthOfLongestSubstring(s: string): number {
  // Символы текущего окна [left, right] — все различны
  const window = new Set<string>();
  let left = 0;
  let best = 0;
```

- `window` — символы текущего окна. Изначально окно пустое.
- `left` — левая граница окна. Правая граница будет переменной цикла.
- `best` — лучший найденный ответ; для пустой строки останется `0`.

```ts
  for (let right = 0; right < s.length; right++) {
    // Новый символ уже есть в окне — сжимаем окно слева, пока повтор не уйдёт
    while (window.has(s[right])) {
      window.delete(s[left]);
      left++;
    }
```

Сердце алгоритма. Правая граница обходит строку один раз. Перед тем как добавить `s[right]`, проверяем, нет ли его уже в окне. Если есть — удаляем символ на левой границе и сдвигаем `left`. Повторяем, **пока** повтор не исчезнет: копия `s[right]` может стоять не на самой левой позиции, и тогда уйдут все символы до неё включительно.

Именно `while`, а не `if`: при `s = "abcb"` на `right = 3` первым удаляется `'a'`, но `'b'` всё ещё в окне — нужно удалить и его.

```ts
    // Теперь s[right] уникален — добавляем его и обновляем ответ
    window.add(s[right]);
    best = Math.max(best, right - left + 1);
  }

  return best;
}
```

После `while` символа `s[right]` в окне нет, значит его можно добавить, и окно `[left, right]` снова без повторов. Его длина `right - left + 1` — кандидат на ответ.

## Трассировка

`s = "abcabcbb"`:

```
right=0 'a': нет в окне              add a  окно "a"    best=1
right=1 'b': нет в окне              add b  окно "ab"   best=2
right=2 'c': нет в окне              add c  окно "abc"  best=3
right=3 'a': есть → delete a, left=1 add a  окно "bca"  best=3
right=4 'b': есть → delete b, left=2 add b  окно "cab"  best=3
right=5 'c': есть → delete c, left=3 add c  окно "abc"  best=3
right=6 'b': есть → delete a, left=4
             есть → delete b, left=5 add b  окно "cb"   best=3
right=7 'b': есть → delete c, left=6
             есть → delete b, left=7 add b  окно "b"    best=3
```

Ответ `3`. На `right = 6` видно, зачем нужен `while`: повтор `'b'` стоял не на левой границе, и окну пришлось сжаться на два символа.

`s = "abba"`:

```
right=0 'a': add a                          окно "a"   best=1
right=1 'b': add b                          окно "ab"  best=2
right=2 'b': delete a, left=1; delete b, left=2; add b  окно "b"   best=2
right=3 'a': нет в окне (a уже удалён)  add a  окно "ba"  best=2
```

Устаревшее вхождение `'a'` на позиции `0` уже удалено из множества, поэтому оно не мешает.

## Почему это работает

**Инвариант:** после каждой итерации `window` содержит ровно символы `s[left..right]`, все они различны, и это **самое длинное** окно без повторов, заканчивающееся в `right`.

- Ровно символы окна: каждый `left++` сопровождается `delete(s[left])`, каждое включение `right` — `add(s[right])`. Так как в окне нет повторов, удаление символа не теряет другую его копию.
- Без повторов: `while` останавливается, только когда `s[right]` нет в окне, а остальные символы были различны до шага.
- Самое длинное: `left` сдвигается лишь до тех пор, пока в окне есть копия `s[right]`. Любое начало левее нового `left` включало бы эту копию — значит, было бы плохим.

Ответ — максимум по всем `right` из самого длинного окна, заканчивающегося в `right`, то есть общий максимум.

## Пограничные случаи

- **Пустая строка** `""`: цикл не выполнится, ответ `0`.
- **Все символы одинаковые** `"bbbbb"`: на каждом шаге `while` удаляет предыдущую `b`, окно длины 1, ответ `1`.
- **Все символы разные**: `while` не срабатывает ни разу, `left = 0`, ответ — длина строки.
- **Повтор не на левой границе** (`"dvdf"`): на `right = 2` удаляются `'d'`, затем окно `"vd"`, потом `"vdf"` — ответ `3`.
- **Пробелы, цифры и знаки** (`" "`): обычные символы, `Set` работает с любыми, ответ `1`.

## Сложность

- **Время `O(n)`**: хоть внутри `for` и есть `while`, каждый символ **добавляется** в окно один раз и **удаляется** не больше одного раза. `left` и `right` вместе делают не больше `2n` шагов, каждый — `O(1)` операция с `Set`.
- **Память `O(min(n, k))`**, где `k` — размер алфавита: в окне не больше одного экземпляра каждого различного символа.

**Follow-up на собеседовании:** «а можно без пошагового сжатия?». Храним в `Map` **последний индекс** каждого символа и, встретив повтор внутри окна, сразу перепрыгиваем левой границей за него:

```ts naive
const prev = lastSeen.get(ch);
if (prev !== undefined && prev >= left) left = prev + 1;
lastSeen.set(ch, right);
```

Асимптотика та же, но шагов меньше. Ловушка — проверка `prev >= left`: без неё на `"abba"` окно уедет назад.

## Типичные ошибки

1. **`if` вместо `while`** → при повторе не на левой границе (`"abcb"`) окно сжимается на один символ, и повтор остаётся.
2. **Удалить `s[right]` вместо `s[left]`** → множество перестаёт соответствовать окну.
3. **Забыть `window.add(s[right])`** → окно «не видит» текущий символ, повторы не ловятся.
4. **Обновлять `best` до `while`** → в ответ попадает длина невалидного окна.
5. **Путать подстроку с подпоследовательностью** и считать просто число различных символов.

## Как узнать такую задачу

- Речь о **непрерывном** куске массива или строки («подстрока», «подмассив», «отрезок»).
- Нужно найти самый длинный/короткий кусок с условием, которое **не портится при сужении** («без повторов», «не больше k различных», «сумма не больше X» для неотрицательных чисел).
- Перебор всех отрезков даёт `O(n²)`, а ограничение `n` до `10⁵` намекает на линейное решение — почти всегда это скользящее окно с `Set`/`Map` состояния окна.
