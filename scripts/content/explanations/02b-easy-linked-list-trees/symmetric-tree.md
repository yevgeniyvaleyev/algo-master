## Задача простыми словами

Дан корень `root` двоичного дерева. Нужно проверить, **симметрично ли** оно относительно вертикальной оси через корень: совпадает ли левая половина с зеркальным отражением правой.

Пример: `root = [1, 2, 2, 3, 4, 4, 3]`.

```
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

Ответ `true`. А для `[1, 2, 2, null, 3, null, 3]` — `false`:

```
      1
     / \
    2   2
     \   \
      3   3
```

Обе тройки — правые дети, а в зеркале одна из них должна быть левой.

## Наивный подход

Очевидная идея — построить зеркальную копию дерева (как в Invert Binary Tree) и сравнить её с оригиналом (как в Same Tree):

```ts naive
const mirror = (n: TreeNode | null): TreeNode | null =>
  n === null ? null : new TreeNode(n.val, mirror(n.right), mirror(n.left));
return isSameTree(root, mirror(root));
```

Это корректно и работает за `O(n)`, но тратит `O(n)` памяти на целую копию и делает работу дважды: каждая пара сравнивается в обе стороны (левая половина с правой и правая с левой). Ещё один «наивный» путь — сравнивать уровни дерева как палиндромы — требует аккуратно учитывать `null` на каждом уровне и тоже держит в памяти целые уровни.

## Ключевое наблюдение

Дерево симметрично, если его **левое поддерево — зеркало правого**. А два дерева `a` и `b` зеркальны друг другу, когда:

1. оба пусты, или
2. оба непусты, `a.val === b.val`, и при этом зеркальны **внешние** пары `(a.left, b.right)` и **внутренние** `(a.right, b.left)`.

То есть это та же синхронная рекурсия по паре узлов, что и в Same Tree, только детей сравниваем «крест-накрест». Копировать дерево не нужно.

## Техники

### Одновременный DFS по паре узлов «крест-накрест»

**Что это.** Рекурсивная функция принимает два узла, которые должны совпадать по смыслу задачи, проверяет их и спускается в пары детей. Какие именно пары брать — определяется задачей: для равенства деревьев `(left, left)` и `(right, right)`, для зеркальности — `(left, right)` и `(right, left)`.

**Типичный шаблон:**

```ts naive
const check = (a, b) => {
  if (a === null && b === null) return true;
  if (a === null || b === null) return false;
  return a.val === b.val && check(пара 1) && check(пара 2);
};
```

**Когда применять.** Любое сравнение двух деревьев или двух частей одного дерева по позициям: Same Tree, Symmetric Tree, Subtree of Another Tree, Flip Equivalent Binary Trees.

**Как применяется здесь.** Стартовая пара — `(root.left, root.right)`, пары детей — внешняя и внутренняя. Подробнее об обходе дерева в глубину — во вкладке «Теория».

### Итеративный вариант (follow-up)

Вместо рекурсии можно держать очередь или стек **пар** узлов. Достаём пару, делаем те же три проверки и вместо рекурсивных вызовов кладём пары `[a.left, b.right]` и `[a.right, b.left]`. Это снимает риск переполнения стека вызовов на очень глубоких деревьях.

Вспомогательная функция работает с **парой** поддеревьев. Сама `isSymmetric` принимает одно дерево, а симметрия — отношение между двумя половинами, поэтому без помощника с двумя параметрами не обойтись.

```ts
    // Оба пусты — зеркальны
    if (a === null && b === null) {
      return true;
    }
    // Пусто только одно — симметрии нет
    if (a === null || b === null) {
      return false;
    }
```

Две базы, как в Same Tree. Пустое отражается в пустое. Если пусто ровно одно (случай «оба» уже отсечён), то на одной стороне узел есть, а в зеркальной позиции его нет — форма не симметрична. После этих проверок оба узла гарантированно не `null`.

```ts
    // Значения равны, а дети сравниваются «крест-накрест»:
    // внешние (a.left и b.right) и внутренние (a.right и b.left)
    return a.val === b.val && isMirror(a.left, b.right) && isMirror(a.right, b.left);
  };
```

Главное отличие от Same Tree. При отражении левый край одной половины переходит в правый край другой, поэтому сравниваем `a.left` с `b.right` (внешние, дальние от оси) и `a.right` с `b.left` (внутренние, ближние к оси). `&&` обрывает проверку на первом же несовпадении.

```ts
  // Дерево симметрично, если его левое поддерево — зеркало правого
  return root === null || isMirror(root.left, root.right);
}
```

Корень стоит на оси симметрии и сравнивать его не с кем — сразу сравниваем его поддеревья друг с другом. Проверка `root === null` защищает от пустого входа (по ограничениям узлов хотя бы один, но функция принимает `null` по типу), и пустое дерево считается симметричным.

## Трассировка

`root = [1, 2, 2, 3, 4, 4, 3]`. Обозначим левую двойку `2L`, правую `2R`.

```
isMirror(2L, 2R): 2 === 2
  внешняя пара: isMirror(2L.left=3, 2R.right=3): 3 === 3
    isMirror(null, null) → true
    isMirror(null, null) → true
  → true
  внутренняя пара: isMirror(2L.right=4, 2R.left=4): 4 === 4
    isMirror(null, null) → true
    isMirror(null, null) → true
  → true
→ true
ответ: true
```

`root = [1, 2, 2, null, 3, null, 3]`:

```
isMirror(2L, 2R): 2 === 2
  внешняя пара: isMirror(2L.left=null, 2R.right=3)
    пусто только одно → false
→ && обрывается, внутренняя пара не проверяется
ответ: false
```

## Почему это работает

Зеркальность двух деревьев определяется рекурсивно: отражение дерева `b` имеет тот же корень, а его левое поддерево — отражение `b.right`, правое — отражение `b.left`. Значит, `a` совпадает с отражением `b` ровно тогда, когда совпадают корни, `a.left` совпадает с отражением `b.right` (то есть они зеркальны) и `a.right` — с отражением `b.left`. Именно это проверяет `isMirror`; по индукции по числу узлов в паре она верна для всех поддеревьев. Дерево симметрично, когда оно совпадает со своим отражением; корни совпадают тривиально, остаётся условие `isMirror(root.left, root.right)`.

## Пограничные случаи

- **Один узел**: `isMirror(null, null)` → `true`.
- **Пустое дерево**: `root === null` → `true` (по ограничениям не встречается, но обработано).
- **Одинаковые значения, несимметричная форма** (`[1, 2, 2, null, 3, null, 3]`): ловится базой «пусто только одно».
- **Симметричная форма, разные значения** (`[1, 2, 3]`): ловится `a.val === b.val`.
- **Глубокое вырожденное дерево**: несимметрично уже на первом уровне (у корня один ребёнок), рекурсия сразу заканчивается.

## Сложность

- **Время `O(n)`**: каждый узел попадает ровно в одну пару сравнения, работа на пару — `O(1)`.
- **Память `O(h)`**: глубина стека рекурсии не превышает высоты дерева. Для итеративного варианта с очередью — `O(w)`, где `w` — максимальная ширина уровня.

## Типичные ошибки

1. **Сравнивать пары как в Same Tree** `(a.left, b.left)` → проверяется равенство половин, а не зеркальность: `[1, 2, 2, 3, 4, 3, 4]` ошибочно признаётся симметричным.
2. **Проверять только внешнюю пару** или только внутреннюю → половина условий теряется.
3. **Сравнивать in-order обход с его разворотом** → ломается на деревьях вроде `[1, 2, 2, 2, null, 2]`, где обход-палиндром не означает симметрию формы.
4. **Начинать с `isMirror(root, root)`** — это корректно, но каждая пара проверяется дважды; старт с детей корня экономит половину работы.
5. **Перепутать порядок баз** → две пустые позиции считаются несимметричными.

## Как узнать такую задачу

- Слова «mirror», «symmetric», «отражение» — сравнение дерева с самим собой «через ось».
- Нужно сравнить **две части** одной структуры по соответствующим позициям — передавайте в рекурсию пару узлов.
- Follow-up «рекурсивно и итеративно» — значит, очередь пар.
- Похожие задачи: Same Tree, Invert Binary Tree, Subtree of Another Tree, Flip Equivalent Binary Trees, Valid Palindrome (та же идея симметрии на строке).
