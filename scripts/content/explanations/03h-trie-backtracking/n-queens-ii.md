## Задача простыми словами

На доске `n × n` нужно расставить `n` ферзей так, чтобы никакие два не били друг друга: не стояли в одной строке, одном столбце или на одной диагонали. Вернуть нужно **количество** различных расстановок (сами доски не нужны). `1 ≤ n ≤ 9`.

Пример: `n = 4` — ответ `2`:

```
. Q . .      . . Q .
. . . Q      Q . . .
Q . . .      . . . Q
. . Q .      . Q . .
```

## Наивный подход

Перебрать все способы поставить `n` ферзей на `n²` клеток и проверить каждую расстановку:

```ts naive
// все наборы из n клеток среди n² — C(n², n) вариантов
for (const cells of combinations(n * n, n)) {
  if (noTwoAttack(cells)) count++;
}
```

При `n = 8` это `C(64, 8) ≈ 4.4 · 10⁹` расстановок, каждая проверяется за `O(n²)`. Лишняя работа огромная: мы строим расстановки, где два ферзя стоят **в одной строке** (заведомо плохо), и замечаем конфликт только когда все `n` ферзей уже поставлены.

Даже если ставить по одному ферзю в строку (`n^n` вариантов: `8^8 ≈ 1.7 · 10⁷`), без проверки по ходу мы продолжаем достраивать доски, которые сломались уже на втором ферзе.

## Ключевое наблюдение

Два наблюдения убирают почти весь перебор:

1. **В каждой строке ровно один ферзь** (два в одной строке бьют друг друга, а ферзей `n` на `n` строк). Значит, идём по строкам сверху вниз и выбираем только **столбец**.
2. **Проверять конфликт сразу**, при постановке, а не в конце. Если клетка бьётся уже стоящим ферзём — в эту ветку не заходим вовсе.

Чтобы проверка была за `O(1)`, заметим: ферзь занимает столбец и две диагонали, а каждую диагональ можно пронумеровать одним числом:

- на диагонали «\» постоянна **разность** `row - col`;
- на диагонали «/» постоянна **сумма** `row + col`.

```
row - col (сдвиг +3 при n=4)     row + col
  3 2 1 0                        0 1 2 3
  4 3 2 1                        1 2 3 4
  5 4 3 2                        2 3 4 5
  6 5 4 3                        3 4 5 6
```

Три массива флагов — занятые столбцы, «\»-диагонали и «/»-диагонали — отвечают на вопрос «свободна ли клетка?» тремя обращениями по индексу.

## Техники

### Перебор с возвратом (backtracking) с отсечением

**Что это.** Рекурсивное построение решения по шагам с откатом. Сила метода — в **отсечениях**: проверяя ограничения на каждом шаге, мы отбрасываем целые поддеревья недопустимых вариантов.

**Типичный шаблон для задач на расстановку:**

```ts naive
backtrack(row):
  if (row === n) { count++; return; }
  for (col of столбцы)
    if (клетка свободна) { поставить; backtrack(row + 1); убрать; }
```

**Как применяется здесь.** Шаг — строка, вариант — столбец. Ограничения проверяются до постановки ферзя. Подробнее — во вкладке «Теория».

### Нумерация диагоналей и массивы занятости

Приём для любых задач на сетке, где важны диагонали: диагональ «\» задаётся `row - col` (от `-(n-1)` до `n-1`), «/» — `row + col` (от `0` до `2n - 2`). Всего по `2n - 1` диагоналей каждого вида. Разность может быть отрицательной, поэтому к ней прибавляют `n - 1`, чтобы получить индекс массива `0..2n-2`.

Вариант того же приёма — **битовые маски** вместо массивов: те же три множества, но проверки и пометки одной операцией над целым числом.

## Разбор кода

```ts
function totalNQueens(n: number): number {
  // Занятые столбцы и диагонали.
  // На «\»-диагонали постоянна разность row - col (сдвигаем на n - 1, чтобы индекс был >= 0),
  // на «/»-диагонали постоянна сумма row + col.
  const cols: boolean[] = new Array(n).fill(false);
  const diag: boolean[] = new Array(2 * n - 1).fill(false);
  const anti: boolean[] = new Array(2 * n - 1).fill(false);
  let count = 0;
```

Три массива занятости: `cols` на `n` столбцов, `diag` и `anti` — на `2n - 1` диагоналей каждый. Строки отдельно не храним: в каждой строке ставим ровно одного ферзя по построению. `count` — счётчик найденных расстановок.

```ts
  // Ставим ровно одного ферзя в каждую строку, сверху вниз
  const backtrack = (row: number): void => {
    if (row === n) {
      // Все n ферзей расставлены без конфликтов
      count++;
      return;
    }
```

`backtrack(row)` расставляет ферзей в строках `row..n-1`, когда строки выше уже заполнены корректно. Если `row === n`, все `n` ферзей стоят без конфликтов — это одна полная расстановка.

```ts
    for (let col = 0; col < n; col++) {
      const d = row - col + n - 1;
      const a = row + col;
      // Клетка бьётся уже стоящим ферзём — пропускаем
      if (cols[col] || diag[d] || anti[a]) continue;
```

Пробуем каждый столбец текущей строки. Вычисляем номера двух диагоналей, проходящих через клетку `(row, col)`. Если занят столбец или хотя бы одна диагональ — клетка под боем, пропускаем.

```ts
      // Ставим ферзя
      cols[col] = diag[d] = anti[a] = true;
      backtrack(row + 1);
      // Убираем ферзя (откат)
      cols[col] = diag[d] = anti[a] = false;
    }
  };
```

Ставим ферзя — помечаем три линии одним цепным присваиванием. Рекурсивно заполняем следующие строки. После возврата снимаем пометки: следующий столбец этой строки пробуется на доске без этого ферзя. Снимать пометки безопасно — эти линии были свободны до постановки, значит, их занял только этот ферзь (иначе мы бы её сюда не поставили).

```ts
  backtrack(0);
  return count;
}
```

Начинаем с верхней строки на пустой доске.

## Трассировка

`n = 4`. Для каждой клетки `d = row - col + 3`, `a = row + col`.

1. `row 0, col 0`: свободно, ставим (`d = 3`, `a = 0`).
2. `row 1`: `col 0` — столбец занят; `col 1` — `d = 3` занята; `col 2` — `d = 2`, `a = 3` свободны → ставим.
3. `row 2`: `col 0` — столбец; `col 1` — `a = 3` занята; `col 2` — столбец; `col 3` — `d = 2` занята. Тупик, откат.
4. `row 1, col 3`: `d = 1`, `a = 4` → ставим. `row 2`: `col 1` (`d = 4`, `a = 3`) свободна → ставим. `row 3`: `col 0`, `col 1`, `col 3` — столбцы заняты; `col 2` — `d = 4` занята. Тупик. `row 2`: `col 2` — `d = 3` занята, `col 3` — столбец. Тупик.
5. Ферзь в `(0, 0)` решений не даёт, откат. `row 0, col 1`: `d = 2`, `a = 1`.
6. `row 1`: `col 0` — `a = 1` занята; `col 1` — столбец; `col 2` — `d = 2` занята; `col 3` — `d = 1`, `a = 4` → ставим.
7. `row 2, col 0`: `d = 5`, `a = 2` свободны → ставим.
8. `row 3`: `col 2` — `d = 4`, `a = 5`, столбец 2 свободны → ставим, `backtrack(4)`: `count = 1`. Расстановка `(0,1), (1,3), (2,0), (3,2)`.
9. Дальнейший перебор находит зеркальную расстановку `(0,2), (1,0), (2,3), (3,1)` → `count = 2`; старт с `col 3` решений не даёт.

Ответ `2`.

## Почему это работает

Инвариант: при входе в `backtrack(row)` в строках `0..row-1` стоит ровно по одному ферзю, никакие два не бьют друг друга, и флаги `cols`, `diag`, `anti` отмечены ровно для линий этих ферзей.

- Новый ферзь ставится только в клетку, не лежащую ни на одной отмеченной линии, — значит, он не бьёт ни одного уже стоящего; строка у него новая. Инвариант сохраняется.
- Откат снимает ровно три флага, поставленные этим ферзём, — инвариант восстанавливается для следующей итерации.
- Любая корректная расстановка имеет по одному ферзю в строке; перебор по строкам рассматривает её столбцы по очереди, и ни на одном шаге её клетка не окажется под боем. Значит, каждая корректная расстановка посчитается ровно один раз.

## Пограничные случаи

- **`n = 1`**: один ферзь на одной клетке — ответ `1`.
- **`n = 2` и `n = 3`**: решений нет, ответ `0` — все ветки обрываются отсечением.
- **`n = 9`** (максимум): ответ `352`, перебор укладывается в доли секунды благодаря отсечениям.
- **Размер массивов диагоналей** `2n - 1`: при `n = 1` это `1` — индекс `0 - 0 + 0 = 0` корректен.

## Сложность

- **Время `O(n!)`** (грубая верхняя оценка): в первой строке до `n` вариантов, во второй не больше `n - 1` свободных столбцов, и так далее. На каждый узел — цикл на `n` столбцов с проверкой за `O(1)`. Диагональные отсечения уменьшают реальное число узлов на порядки.
- **Память `O(n)`**: три массива флагов (`n + 2 · (2n − 1)`) и глубина рекурсии `n`. Доску не храним вообще.

## Типичные ошибки

1. **Проверять конфликт перебором всех поставленных ферзей** → `O(n)` на проверку вместо `O(1)`; работает, но медленнее.
2. **Забыть сдвиг `n - 1` для `row - col`** → отрицательный индекс массива, проверка `diag[-2]` всегда `undefined` (ложь), диагональ «\» не проверяется.
3. **Перепутать, где разность, а где сумма**, или выделить под диагонали массивы длины `n` → выход за границы и пропущенные конфликты.
4. **Не снять пометки при откате** → после первой ветки линии считаются занятыми навсегда, ответ занижен.
5. **Перебирать клетки, а не строки** → одна и та же расстановка считается многократно (в разном порядке постановки).

## Как узнать такую задачу

- Расстановка объектов на доске/сетке с **ограничениями «не бьют друг друга»**, нужно количество или все варианты.
- Есть естественное правило «ровно один объект на строку/позицию» — это превращает перебор клеток в перебор столбцов (по сути, перестановок).
- Маленькое `n` (`≤ 9–12`) — ожидается backtracking с отсечениями. Похожие задачи: N-Queens (вывести доски), Sudoku Solver, Permutations, расстановка ладей/слонов.
