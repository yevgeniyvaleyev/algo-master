## Задача простыми словами

Дана строка цифр `digits` из диапазона `2–9`. На кнопках старого телефона каждой цифре соответствуют буквы (`2 → abc`, `3 → def`, …, `7 → pqrs`, `9 → wxyz`). Нужно вернуть **все строки**, которые можно набрать, выбрав по одной букве на каждую цифру. Порядок ответа не важен.

Пример: `digits = "23"`. Для `2` — `a, b, c`, для `3` — `d, e, f`, всего `3 · 3 = 9` строк: `["ad","ae","af","bd","be","bf","cd","ce","cf"]`.

## Наивный подход

Если бы длина `digits` была известна заранее, хватило бы вложенных циклов — по одному на цифру:

```ts naive
// только для ровно двух цифр
for (const a of letters[digits[0]])
  for (const b of letters[digits[1]])
    result.push(a + b);
```

Но длина `digits` бывает от 1 до 4, и написать «переменное число вложенных циклов» обычным кодом нельзя — пришлось бы плодить отдельные ветки на каждую длину.

Здесь нет «лишней» работы в смысле асимптотики — ответов действительно `O(4^n)`, и все надо выписать. Проблема в **структуре кода**: нужен способ выразить произвольную глубину вложенности.

## Ключевое наблюдение

Каждая цифра — это **уровень дерева решений**, а её буквы — варианты выбора на этом уровне. Любая комбинация — это путь от корня до листа. Значит, «переменное число вложенных циклов» — это **рекурсия**, где один вызов отвечает за одну цифру и внутри себя перебирает её буквы:

```
             (корень)
         /      |      \
        a       b       c        ← цифра 2
      / | \   / | \   / | \
     d  e  f d  e  f d  e  f     ← цифра 3
```

Глубина рекурсии равна длине `digits`, а лист — готовая комбинация.

## Техники

### Перебор с возвратом (backtracking)

**Что это.** Способ обойти все варианты, строя решение по шагам. На каждом шаге делаем **выбор**, рекурсивно строим остаток, а затем **откатываем** выбор, чтобы попробовать следующий. Состояние (текущий путь) одно на всю рекурсию и меняется на месте.

**Типичный шаблон:**

```ts naive
backtrack(шаг):
  if (решение готово) { сохранить; return; }
  for (вариант of варианты(шаг)) {
    сделать выбор;
    backtrack(шаг + 1);
    отменить выбор;
  }
```

**Когда применять.** Нужно перечислить **все** комбинации, перестановки, подмножества, расстановки — то есть ответ сам по себе экспоненциален.

**Как применяется здесь.** Шаг — индекс цифры `i`, варианты — буквы `letters[digits[i]]`, путь — массив выбранных букв `path`. Подробнее — во вкладке «Теория».

### Таблица соответствий

Отображение «цифра → буквы» хранится в объекте `letters`. Это просто справочник; он позволяет одинаково обработать кнопки с тремя и с четырьмя буквами (`7` и `9`).

## Разбор кода

```ts
function letterCombinations(digits: string): string[] {
  // Пустой ввод — нет ни одной комбинации (в старой версии задачи такое было)
  if (digits.length === 0) return [];
```

Особый случай. Без этой проверки рекурсия с `i = 0 === digits.length` сразу положила бы в ответ пустую строку, и результат был бы `[""]`, а ожидается `[]`.

```ts
  // Буквы на кнопках телефона
  const letters: Record<string, string> = {
    '2': 'abc',
    '3': 'def',
    '4': 'ghi',
    '5': 'jkl',
    '6': 'mno',
    '7': 'pqrs',
    '8': 'tuv',
    '9': 'wxyz',
  };
```

Справочник букв. Тип `Record<string, string>` позволяет индексировать объект символом цифры.

```ts
  const result: string[] = [];
  const path: string[] = [];
```

`result` копит ответ, `path` — буквы, выбранные для уже обработанных цифр. Путь хранится массивом, а не строкой: `push`/`pop` — `O(1)`, а склейка в строку делается один раз в листе.

```ts
  // i — индекс цифры, для которой выбираем букву
  const backtrack = (i: number): void => {
    // Выбрали букву для каждой цифры — комбинация готова
    if (i === digits.length) {
      result.push(path.join(''));
      return;
    }
```

Базовый случай: буквы выбраны для всех цифр, в `path` ровно `digits.length` элементов. `path.join('')` создаёт **новую** строку — снимок пути, который дальше уже не изменится, хотя сам `path` продолжит меняться.

```ts
    for (const ch of letters[digits[i]]) {
      path.push(ch); // выбор
      backtrack(i + 1); // следующая цифра
      path.pop(); // откат
    }
  };
```

Сердце перебора. Для цифры `digits[i]` пробуем каждую её букву: кладём в путь, рекурсивно выбираем буквы для оставшихся цифр, затем убираем букву. После `pop` путь снова такой же, как при входе в вызов, — следующая буква начинает с чистого состояния.

```ts
  backtrack(0);
  return result;
}
```

Старт с первой цифры. Когда рекурсия закончится, в `result` будут все комбинации в лексикографическом порядке (буквы в справочнике отсортированы).

## Трассировка

`digits = "23"`:

```
backtrack(0): цифра '2', буквы "abc"
  push a  → path=[a]
    backtrack(1): цифра '3', буквы "def"
      push d → [a,d] → backtrack(2): i=2=длина → result += "ad"; pop → [a]
      push e → [a,e] → "ae"; pop → [a]
      push f → [a,f] → "af"; pop → [a]
  pop     → path=[]
  push b  → path=[b]
    ... → "bd", "be", "bf"
  pop     → path=[]
  push c  → path=[c]
    ... → "cd", "ce", "cf"
  pop     → path=[]
```

Итог: `["ad","ae","af","bd","be","bf","cd","ce","cf"]` — 9 строк. Для `digits = "7"` ответ — 4 строки `["p","q","r","s"]`.

## Почему это работает

Инвариант: при входе в `backtrack(i)` массив `path` содержит по одной букве для каждой из цифр `digits[0..i-1]`, и после выхода из вызова `path` снова такой же (каждый `push` парный с `pop`).

Индукцией по `digits.length - i`: вызов `backtrack(i)` добавляет в ответ ровно все строки вида `path + x`, где `x` — любая комбинация букв для цифр `digits[i..]`. Для `i = digits.length` это одна строка `path`. Для меньших `i` цикл перебирает все буквы цифры `digits[i]` и для каждой по предположению добавляет все продолжения. Значит, `backtrack(0)` добавляет все комбинации, каждую ровно один раз — разные ветки отличаются хотя бы одной буквой.

## Пограничные случаи

- **Пустая строка `digits`**: `[]`, а не `[""]` — отдельная проверка в начале.
- **Одна цифра**: список её букв (3 или 4 строки).
- **Цифры `7` и `9`** с четырьмя буквами: цикл по строке справочника обрабатывает их без особых случаев.
- **Повторяющиеся цифры** (`"22"`): разные позиции независимы, получится 9 строк `aa, ab, …, cc`.

## Сложность

- **Время `O(4^n · n)`**, где `n` — длина `digits`: листьев дерева не больше `4^n` (на кнопке максимум 4 буквы), и в каждом листе `join` строит строку длины `n`. Внутренние узлы дерева добавляют не больше, чем листья, по порядку величины.
- **Память `O(n)`** дополнительно: глубина рекурсии и длина `path` равны `n`. Сам ответ занимает `O(4^n · n)`, но это выходные данные.

## Типичные ошибки

1. **Не обработать пустой ввод** → ответ `[""]` вместо `[]`.
2. **Забыть `path.pop()`** → путь растёт бесконечно, строки получаются длиннее `n`.
3. **Класть в ответ сам массив `path`** (в вариантах, где ответ — массивы) → все элементы ответа ссылаются на один и тот же, в конце пустой, массив. Здесь это спасает `join`, который создаёт новую строку.
4. **Строить строку конкатенацией на каждом уровне** (`backtrack(i + 1, cur + ch)`) — работает, но на каждом шаге создаёт новую строку; при малых `n` не критично, но шаблон с `push`/`pop` универсальнее.
5. **Перепутать справочник** (например, `7 → pqr`) → пропадают комбинации.

## Как узнать такую задачу

- Нужно перечислить **все** варианты, где на каждой позиции независимо выбирается один элемент из своего набора (декартово произведение).
- Число позиций заранее неизвестно — «переменное число вложенных циклов» → рекурсия/backtracking.
- Маленькие ограничения (`n ≤ 4`, `n ≤ 10`) — признак того, что экспоненциальный перебор ожидаем. Похожие задачи: Generate Parentheses, Combinations, Subsets, Letter Case Permutation.
