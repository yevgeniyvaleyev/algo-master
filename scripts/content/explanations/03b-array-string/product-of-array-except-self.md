## Задача простыми словами

Дан массив целых чисел `nums`. Нужно вернуть массив `answer`, где `answer[i]` — произведение **всех элементов, кроме `nums[i]`**. Ограничения: время `O(n)` и **без деления**.

Пример: `nums = [1, 2, 3, 4]` → `answer = [24, 12, 8, 6]`. Например, `answer[1] = 1 · 3 · 4 = 12` — пропущена двойка.

## Наивный подход

Для каждой позиции честно перемножить все остальные элементы:

```ts naive
const answer: number[] = [];
for (let i = 0; i < n; i++) {
  let p = 1;
  for (let j = 0; j < n; j++) if (j !== i) p *= nums[j];
  answer.push(p);
}
```

Это `O(n²)`: при `n = 10⁵` — десять миллиардов умножений. Лишняя работа очевидна: для соседних `i` и `i + 1` произведения почти одинаковые — отличаются одним множителем, а мы каждый раз пересчитываем их с нуля.

Вторая «очевидная» идея — перемножить всё и делить: `answer[i] = total / nums[i]`. Она запрещена условием и к тому же ломается на нулях: при одном нуле `total = 0`, и для самого нуля нужно произведение остальных, которое из `0 / 0` не восстановить.

## Ключевое наблюдение

«Все, кроме `i`» — это **всё левее `i`** и **всё правее `i`**:

```
answer[i] = (nums[0] · … · nums[i-1]) · (nums[i+1] · … · nums[n-1])
             └──────── left[i] ───────┘   └──────── right[i] ──────┘
```

Массив `left` заполняется одним проходом слева направо: каждое следующее значение получается из предыдущего одним умножением, `left[i] = left[i - 1] · nums[i - 1]`. Массив `right` — так же, проходом справа налево. Третьим проходом перемножаем их попарно. Деления нет, а на каждую позицию уходит `O(1)` работы.

## Техники

### Префиксные и суффиксные накопления

**Что это.** Префиксная «сумма» (или произведение, максимум, XOR — любая ассоциативная операция) — это значение операции на отрезке `[0, i)`. Её считают одним проходом: `prefix[i] = prefix[i - 1] ⊕ nums[i - 1]`. Симметрично считается суффикс на `(i, n-1]` проходом справа налево.

**Типичный шаблон.** Когда ответ для позиции `i` зависит от «всего слева» и «всего справа» от неё, считаем оба накопления и комбинируем:

```ts naive
// left[i] — операция над nums[0..i-1], right[i] — над nums[i+1..n-1]
for (let i = 0; i < n; i++) answer[i] = combine(left[i], right[i]);
```

Так решаются задачи «произведение кроме себя», «вода между столбиками» (максимумы слева и справа), «конфеты» (ограничения от соседей с двух сторон).

**Как применяется здесь.** Операция — умножение, «пустой» префикс или суффикс равен `1` (нейтральный элемент умножения). Подробнее о приёмах работы с массивами — во вкладке «Теория».

### Нейтральный элемент на краях

У `nums[0]` нет соседей слева, у `nums[n - 1]` — справа. Произведение пустого набора равно `1`, поэтому `left[0] = 1` и `right[n - 1] = 1`. Это убирает особые случаи: формула `left[i] * right[i]` одинаково работает и на краях, и в середине.

## Разбор кода

```ts
function productExceptSelf(nums: number[]): number[] {
  const n = nums.length;

  // left[i] — произведение всех элементов левее i (для i = 0 это 1)
  const left = new Array<number>(n);
  left[0] = 1;
  for (let i = 1; i < n; i++) {
    left[i] = left[i - 1] * nums[i - 1];
  }
```

Слева от позиции `0` ничего нет — кладём `1`. Дальше каждое значение строим из предыдущего: всё, что левее `i`, — это всё, что левее `i - 1`, плюс сам `nums[i - 1]`. Обратите внимание на индекс: умножаем на `nums[i - 1]`, а не на `nums[i]` — сам элемент `i` в `left[i]` не входит.

```ts
  // right[i] — произведение всех элементов правее i (для i = n - 1 это 1)
  const right = new Array<number>(n);
  right[n - 1] = 1;
  for (let i = n - 2; i >= 0; i--) {
    right[i] = right[i + 1] * nums[i + 1];
  }
```

Зеркальный проход. Справа от последней позиции ничего нет — `1`. Затем идём справа налево: всё правее `i` — это всё правее `i + 1` и сам `nums[i + 1]`.

```ts
  // Произведение всех, кроме nums[i] = то, что левее, × то, что правее
  const answer = new Array<number>(n);
  for (let i = 0; i < n; i++) {
    answer[i] = left[i] * right[i];
  }

  return answer;
}
```

Склеиваем две половины. В `left[i] * right[i]` входят все элементы, кроме `nums[i]`, — ровно то, что нужно.

## Трассировка

`nums = [1, 2, 3, 4]`.

```
i          0    1    2    3
nums       1    2    3    4
left       1    1    2    6      left[i] = left[i-1] · nums[i-1]
right     24   12    4    1      right[i] = right[i+1] · nums[i+1]
answer    24   12    8    6      left[i] · right[i]
```

Подробно для `left`: `left[0] = 1`, `left[1] = 1 · 1 = 1`, `left[2] = 1 · 2 = 2`, `left[3] = 2 · 3 = 6`. Для `right`: `right[3] = 1`, `right[2] = 1 · 4 = 4`, `right[1] = 4 · 3 = 12`, `right[0] = 12 · 2 = 24`.

Пример с нулём, `nums = [-1, 1, 0, -3, 3]`:

```
nums      -1    1    0   -3    3
left       1   -1   -1    0    0
right      0    0   -9    3    1
answer     0    0    9    0    0
```

Ненулевое значение только у самого нуля — `(-1 · 1) · (-3 · 3) = 9`.

## Почему это работает

Инварианты:

- после первого цикла `left[i] = nums[0] · … · nums[i-1]` для каждого `i` (пустое произведение — `1`): для `i = 0` это задано явно, а шаг `left[i] = left[i - 1] · nums[i - 1]` добавляет ровно следующий множитель;
- после второго цикла `right[i] = nums[i+1] · … · nums[n-1]` — симметричное рассуждение.

Тогда `left[i] · right[i]` — произведение элементов с индексами `0..i-1` и `i+1..n-1`, то есть всех, кроме `i`. Умножение коммутативно и ассоциативно, порядок множителей значения не имеет.

## Пограничные случаи

- **Один ноль**: все ответы `0`, кроме позиции нуля, — у неё произведение остальных.
- **Два и больше нулей**: каждое «все, кроме одного» содержит ноль — весь ответ из нулей. Код ничего особого не делает, это получается само.
- **Отрицательные числа**: знак учитывается обычным умножением.
- **`n = 2`**: `left = [1, nums[0]]`, `right = [nums[1], 1]`, `answer = [nums[1], nums[0]]`.
- **`-0` в JavaScript**: при умножении отрицательного числа на ноль получается `-0`. `-0 === 0` истинно, а при выводе он печатается как `0`, так что ответ корректен.

## Сложность

- **Время `O(n)`**: три прохода по массиву, на каждом шаге одно умножение.
- **Память `O(n)`**: массивы `left` и `right` (выходной массив по условию не учитывается).

**Follow-up на собеседовании: `O(1)` дополнительной памяти.** Префиксы можно писать прямо в `answer`, а суффикс держать одной переменной и домножать на неё вторым проходом:

```ts naive
let prefix = 1;
for (let i = 0; i < n; i++) {
  answer[i] = prefix; // сначала записать, потом обновить
  prefix *= nums[i];
}
let suffix = 1;
for (let i = n - 1; i >= 0; i--) {
  answer[i] *= suffix;
  suffix *= nums[i];
}
```

Это та же идея «левее × правее», только без отдельных массивов.

## Типичные ошибки

1. **Сдвиг индекса**: `left[i] = left[i - 1] * nums[i]` → в `left[i]` попадает сам `nums[i]`, и ответ включает лишний множитель.
2. **Использовать деление** → запрещено условием и ломается на нулях (`0 / 0 = NaN`, деление на ноль даёт `Infinity`).
3. **Начинать накопление с `0`** вместо `1` → все произведения обнуляются.
4. **Неверные границы второго цикла**: `right` начинается с `n - 2`, ведь `right[n - 1]` уже задан; старт с `n - 1` обратится к `nums[n]` (`undefined`) и даст `NaN`.
5. **Отдельно обрабатывать нули** через счётчики — работает, но лишний код и лишние ветки; префиксы/суффиксы справляются сами.

## Как узнать такую задачу

- Ответ для позиции `i` — это агрегат «всего, кроме `i`» или комбинация «всего слева» и «всего справа».
- Запрет на деление (или операция, у которой нет обратной, например `max`) — сигнал, что «посчитать всё и вычесть себя» не сработает, нужны префиксы и суффиксы.
- Если просят `O(1)` памяти — используйте выходной массив как буфер для префиксов.
- Родственные задачи: Trapping Rain Water (максимумы слева/справа), Candy, Range Sum Query, Maximum Product Subarray.
