## Задача простыми словами

Дана строка `s` из слов, разделённых пробелами. Нужно вернуть строку, в которой **слова идут в обратном порядке** (сами слова не переворачиваются), разделены **ровно одним пробелом**, без пробелов в начале и в конце. В исходной строке пробелов может быть сколько угодно: в начале, в конце и по несколько между словами.

Пример: `"the sky is blue"` → `"blue is sky the"`. С лишними пробелами: `"  hello world  "` → `"world hello"`, `"a good   example"` → `"example good a"`.

## Наивный подход

В JavaScript задача решается одной строкой:

```ts naive
return s.trim().split(/\s+/).reverse().join(' ');
```

`trim` убирает краевые пробелы, `split(/\s+/)` режет по любым сериям пробелов, `reverse` разворачивает массив, `join` склеивает через один пробел. Это `O(n)`, и на собеседовании его стоит назвать. Но обычно просят показать **ручной разбор** — именно он проверяет умение работать с индексами.

Ручной вариант «в лоб» — пройти слева направо, собрать слова в массив, затем развернуть массив и склеить. Так тоже `O(n)`, но делается лишний проход: сначала собираем в прямом порядке, потом переворачиваем. И приходится аккуратно обрабатывать слово, которое заканчивается в самом конце строки, без пробела после него.

## Ключевое наблюдение

Если читать строку **с конца**, слова встречаются **сразу в нужном порядке** — последним словом вперёд. Остаётся вырезать каждое слово и дописать его в список, а лишние пробелы просто пропускать между словами. Склейка через `' '` автоматически даёт ровно один пробел между словами и ни одного по краям.

Указатель `i` двигается только влево, каждый символ просматривается один раз.

## Техники

### Указатель с конца и вырезание по границам

**Что это.** Разновидность приёма «два указателя»: один индекс сканирует строку, а второй (здесь — `end`) фиксирует границу текущего фрагмента. Когда сканирующий указатель доходит до другой границы, фрагмент вырезается одним `slice`.

**Типичный шаблон разбора на токены:**

```ts naive
while (i в пределах) {
  пропустить разделители;
  if (вышли за пределы) break;
  const start = i;
  пройти до конца токена;
  взять токен [start, i);
}
```

Тот же каркас используется в лексерах, парсерах CSV, задачах про сжатие пробелов. Направление (слева направо или справа налево) выбирают так, чтобы токены выходили в нужном порядке.

**Как применяется здесь.** Сканируем справа налево: сначала пропускаем пробелы, затем запоминаем `end` и идём до начала слова. Подробнее о двух указателях — во вкладке «Теория».

### Сборка строки через массив и `join`

Строки в JavaScript неизменяемы: каждое `result += word` создаёт новую строку. Собирать части в массив и склеивать один раз через `join` — идиоматичный способ, и он сразу решает вопрос разделителей: `join(' ')` ставит пробел **только между** элементами.

## Разбор кода

```ts
function reverseWords(s: string): string {
  const words: string[] = [];
  let i = s.length - 1;
```

`words` — найденные слова в порядке ответа. Указатель `i` стоит на последнем символе строки.

```ts
  // Идём с конца строки и вырезаем слова справа налево
  while (i >= 0) {
    // Пропускаем пробелы
    while (i >= 0 && s[i] === ' ') i--;
    if (i < 0) break;
```

Внешний цикл — одно слово за итерацию. Сначала сдвигаем `i` влево через все пробелы (хвостовые или межсловные). Если после этого вышли за начало строки — значит, слева остались только пробелы, слов больше нет, выходим. Проверка `i >= 0` стоит **первой** в условии: иначе мы бы читали `s[-1]`.

```ts
    // end — индекс за последним символом слова
    const end = i + 1;
    // Ищем начало слова
    while (i >= 0 && s[i] !== ' ') i--;
```

`i` сейчас указывает на последнюю букву слова; `end = i + 1` — граница «за словом» (полуинтервал, как принято у `slice`). Затем идём влево по непробельным символам. Цикл остановится либо на пробеле перед словом, либо на `i = -1`, если слово стоит в самом начале строки.

```ts
    // Слова попадают в массив уже в обратном порядке
    words.push(s.slice(i + 1, end));
  }
```

Слово занимает `[i + 1, end)`: `i` указывает на пробел перед ним (или на `-1`), поэтому начало — `i + 1`. Если слово в начале строки, `i + 1 = 0` — тоже верно, отдельная ветка не нужна. Следующая итерация продолжит с пробела, на котором стоит `i`.

```ts
  return words.join(' ');
}
```

Склеиваем через один пробел. Лишние пробелы исходной строки в `words` не попали, поэтому их нет и в ответе.

## Трассировка

`s = "  hello world  "` (длина 15). Позиции: `0–1` пробелы, `2–6` `hello`, `7` пробел, `8–12` `world`, `13–14` пробелы.

1. `i = 14`. Пропускаем пробелы: `i = 13`, `i = 12` (`'d'`). `end = 13`.
2. Идём по слову: `i = 11, 10, 9, 8, 7` — на `7` пробел, стоп. Вырезаем `s.slice(8, 13) = "world"`. `words = ["world"]`.
3. Новая итерация, `i = 7`. Пропускаем пробел: `i = 6` (`'o'`). `end = 7`.
4. Идём по слову до `i = 1` (пробел). Вырезаем `s.slice(2, 7) = "hello"`. `words = ["world", "hello"]`.
5. Новая итерация, `i = 1`. Пропускаем пробелы: `i = 0`, `i = -1`. `i < 0` → `break`.

Ответ: `"world hello"`.

Слово в самом начале, `s = "a good"`: на последней итерации `i` после поиска начала слова `a` становится `-1`, и `s.slice(0, 1) = "a"`. Ответ `"good a"`.

## Почему это работает

Инвариант внешнего цикла: перед каждой итерацией `words` содержит все слова, лежащие **правее** позиции `i`, в порядке справа налево, а `s[i]` — либо пробел, либо последний символ строки, либо `i = -1`.

Итерация пропускает пробелы, находит ближайшее слово слева от уже обработанной части и целиком вырезает его — это следующее слово в обратном порядке. После итерации `i` снова стоит на пробеле или `-1`, инвариант сохранён. Когда `i < 0`, все слова строки в `words`, и в правильном порядке. Пробелы в `words` не попадают никогда, а `join(' ')` ставит ровно по одному между словами.

## Пограничные случаи

- **Пробелы в начале и в конце**: хвостовые пропускаются первым же внутренним циклом, ведущие — приводят к `break`.
- **Несколько пробелов подряд** между словами: пропускаются одним проходом внутреннего цикла.
- **Одно слово** (`"hello"` или `"  hello  "`): массив из одного элемента, `join` возвращает его без пробелов.
- **Слово в начале строки**: поиск начала останавливается на `i = -1`, `slice(0, end)` — корректно.
- **Регистр и цифры** не важны: словом считается любая последовательность непробельных символов.

## Сложность

- **Время `O(n)`**: указатель `i` только уменьшается — каждый символ просматривается один раз; суммарная длина всех `slice` и `join` тоже `O(n)`.
- **Память `O(n)`**: массив слов и итоговая строка. В JavaScript строки неизменяемы, поэтому `O(1)` дополнительной памяти не добиться. В языках с изменяемыми строками есть вариант на месте: развернуть всю строку, затем каждое слово, затем сжать пробелы.

## Типичные ошибки

1. **`split(' ')` без регулярки** → при нескольких пробелах подряд появляются пустые строки, и в ответе получаются двойные пробелы.
2. **Забыть `trim`** в однострочнике → `split` даёт пустые элементы по краям, ответ начинается или заканчивается пробелом.
3. **Порядок условий `s[i] === ' ' && i >= 0`** → чтение `s[-1]` (в JS это `undefined`, и ошибка маскируется, но в других языках это выход за границы).
4. **Неверные границы `slice`** (`slice(i, end)`) → в слово попадает ведущий пробел.
5. **Склейка через `+=` с пробелом после каждого слова** → лишний пробел в конце.

## Как узнать такую задачу

- Строку нужно **разбить на токены** по разделителям, причём разделители могут повторяться и стоять по краям.
- Нужен **обратный порядок** токенов — читаем с конца, и порядок получается сам.
- Требование «ровно один пробел, без краевых пробелов» — признак, что нужно собирать токены, а не копировать символы.
- Follow-up «на месте за `O(1)`» — приём «развернуть целиком, потом каждую часть» (так же решается Rotate Array).
