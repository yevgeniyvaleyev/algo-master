## Задача простыми словами

Дана строка `s` из слов, разделённых пробелами. Нужно вернуть строку, в которой **слова идут в обратном порядке** (сами слова не переворачиваются), разделены **ровно одним пробелом**, без пробелов в начале и в конце. В исходной строке пробелов может быть сколько угодно: в начале, в конце и по несколько между словами.

Пример: `"the sky is blue"` → `"blue is sky the"`. С лишними пробелами: `"  hello world  "` → `"world hello"`, `"a good   example"` → `"example good a"`.

## Наивный подход

Первое, что приходит в голову, — разрезать строку по пробелу и развернуть:

```ts naive
return s.split(' ').reverse().join(' ');
```

На `"the sky is blue"` это работает, но на `"  hello world  "` ломается. `split(' ')` режет по **каждому** пробелу, и между соседними пробелами получаются пустые строки: `["", "", "hello", "world", "", ""]`. После `reverse` и `join` они превращаются обратно в лишние пробелы: `"  world hello  "`. То же самое происходит с несколькими пробелами между словами.

Можно отфильтровать пустые элементы (`.filter(w => w !== '')`), но есть способ короче и понятнее — сразу резать так, чтобы пустых элементов не было.

## Ключевое наблюдение

Задача распадается на три независимых шага: **выделить слова**, **развернуть их порядок**, **склеить через один пробел**. Все три — стандартные операции над строкой и массивом.

Вся сложность — в выделении слов при «грязных» пробелах. Её снимают две вещи:

1. `trim()` убирает пробелы по краям — тогда в начале и в конце не появится пустых элементов.
2. Разделитель — не один пробел, а **регулярное выражение `\s+`**: «один или больше пробельных символов подряд». Серия из любого числа пробелов считается одним разделителем, поэтому пустых элементов в середине тоже не будет.

После этого массив содержит ровно слова, и `reverse` + `join(' ')` дают ответ.

## Техники

### Разбор строки на токены через `split` с регулярным выражением

**Что это.** `split` принимает не только строку, но и регулярное выражение. Квантификатор `+` означает «один или больше», так что `split(/\s+/)` режет по любой непустой серии пробелов (а также табуляций и переводов строки — `\s` покрывает все пробельные символы).

**Типичный шаблон.**

```ts naive
const tokens = text.trim().split(/\s+/);
```

Так разбирают пользовательский ввод, строки команд, «слова» в тексте. Важно помнить: без `trim` строка, начинающаяся с пробела, даст пустую строку первым элементом (`" a".split(/\s+/)` → `["", "a"]`). Подробнее о работе со строками — во вкладке «Теория».

**Как применяется здесь.** `s.trim().split(/\s+/)` — сразу массив слов без пустых элементов.

### Цепочка методов массива

`reverse()` разворачивает массив на месте и возвращает его же, `join(separator)` склеивает элементы, ставя разделитель **только между** ними. Поэтому цепочка `trim → split → reverse → join` читается сверху вниз как описание алгоритма, и каждый шаг легко проверить отдельно.

## Трассировка

`s = "  hello world  "`:

```
s                 "  hello world  "
.trim()           "hello world"
.split(/\s+/)     ["hello", "world"]
.reverse()        ["world", "hello"]
.join(' ')        "world hello"
```

`s = "a good   example"`:

```
.trim()           "a good   example"      (краевых пробелов нет)
.split(/\s+/)     ["a", "good", "example"] (три пробела — один разделитель)
.reverse()        ["example", "good", "a"]
.join(' ')        "example good a"
```

`s = "  x  "`: `trim` → `"x"`, `split` → `["x"]`, `reverse` → `["x"]`, `join` → `"x"`.

## Почему это работает

По условию **слово** — максимальная последовательность непробельных символов, а слова разделены хотя бы одним пробелом. После `trim` строка начинается и заканчивается непробельным символом (в ней гарантированно есть хотя бы одно слово). Значит, она имеет вид `слово (пробелы слово)*`, и `split(/\s+/)` возвращает ровно список слов в исходном порядке — каждый разделитель `\s+` совпадает с целой серией пробелов между двумя словами.

`reverse` переставляет этот список в обратном порядке, а `join(' ')` по определению вставляет один пробел между соседними элементами и ничего по краям. Получается в точности требуемая строка.

## Пограничные случаи

- **Пробелы в начале и в конце**: убирает `trim`.
- **Несколько пробелов подряд** между словами: `\s+` считает серию одним разделителем.
- **Одно слово** (`"hello"` или `"  hello  "`): массив из одного элемента, `join` возвращает его без пробелов.
- **Регистр и цифры** (`"   A1  b2 "` → `"b2 A1"`): словом считается любая последовательность непробельных символов, они не меняются.
- **Пустая строка или строка из одних пробелов** условием исключена (есть хотя бы одно слово); для неё код вернул бы `""` — тоже разумно.

## Сложность

- **Время `O(n)`**: `trim`, `split`, `reverse` и `join` — каждый проходит строку или массив слов один раз.
- **Память `O(n)`**: массив слов и итоговая строка. В JavaScript строки неизменяемы, поэтому меньше и не получится.

**Follow-up на собеседовании.** Часто просят решить **без встроенных `split`/`reverse`** — тогда указатель идёт с конца строки, пропускает пробелы, находит границы слова и вырезает его:

```ts naive
const words: string[] = [];
let i = s.length - 1;
while (i >= 0) {
  while (i >= 0 && s[i] === ' ') i--; // пропустить пробелы
  if (i < 0) break;
  const end = i + 1;
  while (i >= 0 && s[i] !== ' ') i--; // найти начало слова
  words.push(s.slice(i + 1, end)); // слова идут уже в обратном порядке
}
return words.join(' ');
```

А в языках с изменяемыми строками (C++, Java `char[]`) — **на месте за `O(1)` памяти**: развернуть всю строку, затем каждое слово, затем сжать пробелы двумя указателями (тот же приём «трёх разворотов», что в Rotate Array).

## Типичные ошибки

1. **`split(' ')` без регулярки** → при нескольких пробелах подряд появляются пустые строки, и в ответе получаются двойные пробелы.
2. **Забыть `trim`** → `split(/\s+/)` даёт пустой элемент в начале или в конце, ответ начинается или заканчивается пробелом.
3. **Развернуть строку целиком** (`s.split('').reverse().join('')`) → переворачиваются буквы внутри слов: `"blue"` станет `"eulb"`.
4. **Ждать, что `reverse` вернёт копию** — он меняет исходный массив. Здесь это неважно (массив временный), но в другом коде может удивить.
5. **Склейка через `+=` с пробелом после каждого слова** → лишний пробел в конце; `join` этого избегает.

## Как узнать такую задачу

- Строку нужно **разбить на токены** по разделителям, причём разделители могут повторяться и стоять по краям — `trim().split(/\s+/)`.
- Нужен **обратный порядок** токенов, а не символов — разворачиваем массив слов.
- Требование «ровно один пробел, без краевых пробелов» — признак, что нужно собирать токены и склеивать `join`, а не копировать символы.
- Follow-up «без встроенных функций» — указатель с конца; «на месте за `O(1)`» — развернуть целиком, потом каждое слово.
