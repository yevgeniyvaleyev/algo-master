## Задача простыми словами

Дан массив слов `words` и ширина строки `maxWidth`. Нужно разложить слова по строкам так, чтобы каждая строка имела **ровно `maxWidth` символов** и была выровнена по ширине — как в текстовом редакторе с кнопкой «по ширине». Правила:

- в строку жадно кладём **сколько влезет** слов (минимум один пробел между ними);
- лишние пробелы распределяем между словами **как можно равномернее**, а если поровну не делится — **левые промежутки получают больше**;
- **последняя строка** и строка из **одного слова** выравниваются по левому краю: слова через один пробел, остаток добиваем пробелами справа.

Пример: `words = ["This", "is", "an", "example", "of", "text", "justification."]`, `maxWidth = 16`:

```
"This    is    an"
"example  of text"
"justification.  "
```

## Наивный подход

Хитрого «наивного» алгоритма тут нет — задача вся состоит из правил, и решение — их аккуратная симуляция. Типичный «наивный» путь — **добавлять пробелы по одному**:

```ts naive
// пока строка короче maxWidth — обходим промежутки слева направо
// и добавляем в каждый по пробелу
while (len < maxWidth) {
  for (let g = 0; g < gaps && len < maxWidth; g++) { gapSizes[g]++; len++; }
}
```

Это даёт правильное распределение (левые промежутки получают больше), но делает много мелких шагов и требует отдельной структуры для размеров промежутков. А главная опасность наивного кода — не скорость, а **пропущенные случаи**: строка из одного слова (`gaps = 0`, деление на ноль или вечный цикл), последняя строка, добивка пробелами до `maxWidth`.

## Ключевое наблюдение

Каждую строку можно собрать в **два независимых шага**:

1. **Какие слова войдут.** Жадно: слова `[i, j)` помещаются, если `сумма длин + (число слов − 1) <= maxWidth` — то есть с минимальными одиночными пробелами они ещё влезают.
2. **Как расставить пробелы.** Все пробелы строки — `spaces = maxWidth − lettersLen`, промежутков — `gaps = count − 1`. Распределение считается **арифметикой**, без перебора: каждый промежуток получает `base = floor(spaces / gaps)`, а первые `extra = spaces % gaps` промежутков — ещё по одному.

Отдельная ветка — для последней строки и строки из одного слова: там выравнивание влево. Эта же ветка избавляет от деления на `gaps = 0`.

## Техники

### Жадная упаковка (greedy line breaking)

**Что это.** Жадный алгоритм на каждом шаге берёт максимум из того, что можно взять прямо сейчас, не заглядывая вперёд. Для переноса строк это значит: добавлять слова в текущую строку, пока следующее не перестанет помещаться. Условие задачи прямо требует такую упаковку (в типографике есть и «оптимальные» алгоритмы, минимизирующие неровность, — например, Кнута–Пласса, но здесь они не нужны).

**Типичный шаблон:**

```ts naive
let i = 0;
while (i < items.length) {
  let j = i, used = 0;
  while (j < items.length && used + cost(j) <= limit) { used += cost(j); j++; }
  обработатьГруппу(i, j);
  i = j;
}
```

**Как применяется здесь.** «Стоимость» слова `j` — его длина плюс один обязательный пробел перед ним (кроме первого слова). Подробнее о приёмах работы с массивами и строками — во вкладке «Теория».

### Равномерное распределение с остатком

**Что это.** Разделить `S` единиц на `G` частей «как можно поровну»: каждая часть получает `floor(S / G)`, а остаток `S % G` раздаётся по одной единице первым частям. Разница между любыми двумя частями — не больше `1`.

**Где ещё встречается.** Разбиение массива на `k` почти равных кусков (Split Linked List in Parts), распределение задач по серверам, раскладка элементов по колонкам.

**Как применяется здесь.** `S = spaces`, `G = gaps`; «первым частям» соответствуют левые промежутки — ровно то, что требует условие.

## Разбор кода

```ts
function fullJustify(words: string[], maxWidth: number): string[] {
  const result: string[] = [];
  let i = 0;
```

`result` — готовые строки, `i` — индекс первого слова текущей строки. Внешний цикл строит по одной строке за итерацию.

```ts
  while (i < words.length) {
    // 1. Жадно набираем слова в строку [i, j):
    //    lettersLen — суммарная длина слов без пробелов
    let j = i;
    let lettersLen = 0;
    // Слово j помещается, если буквы + минимум по одному пробелу между словами <= maxWidth
    while (j < words.length && lettersLen + words[j].length + (j - i) <= maxWidth) {
      lettersLen += words[j].length;
      j++;
    }
```

Шаг 1 — выбор слов. Если добавить слово `j`, в строке окажется `j - i + 1` слов и `j - i` промежутков; минимальная ширина — `lettersLen + words[j].length + (j - i)`. Пока она не превышает `maxWidth`, слово берём. Первое слово (`j = i`) всегда помещается: `(j - i) = 0`, а длина любого слова по условию не больше `maxWidth`. Поэтому строка никогда не бывает пустой и цикл не зацикливается.

```ts
    const count = j - i; // слов в строке
    const gaps = count - 1; // промежутков между ними
    let line: string;
```

Число слов и промежутков между ними. `gaps = 0` означает строку из одного слова.

```ts
    if (j === words.length || gaps === 0) {
      // 2a. Последняя строка или одно слово — выравнивание по левому краю
      line = words.slice(i, j).join(' ');
      line += ' '.repeat(maxWidth - line.length);
```

Шаг 2a — выравнивание влево. `j === words.length` значит, что слова закончились — это последняя строка. `gaps === 0` — одно слово, распределять пробелы некуда (и делить на `gaps` нельзя). Слова склеиваются через один пробел, а оставшееся место до `maxWidth` заполняется пробелами справа. `repeat` от `0` даёт пустую строку — случай «строка уже ровно `maxWidth`» обрабатывается сам.

```ts
    } else {
      // 2b. Выравнивание по ширине: делим пробелы между промежутками
      const spaces = maxWidth - lettersLen;
      const base = Math.floor(spaces / gaps); // минимум в каждом промежутке
      const extra = spaces % gaps; // первые extra промежутков получают +1
```

Шаг 2b — выравнивание по ширине. Всё место, не занятое буквами, — пробелы. `base` — сколько получает каждый промежуток, `extra` — сколько промежутков (самых левых) получат на один пробел больше. Проверка: `base · gaps + extra = spaces`, то есть все пробелы распределены. Здесь `gaps >= 1` — ветка 2a отсекла `gaps = 0`.

```ts
      line = '';
      for (let k = 0; k < count; k++) {
        line += words[i + k];
        if (k < gaps) {
          line += ' '.repeat(base + (k < extra ? 1 : 0));
        }
      }
    }
```

Собираем строку: слово, затем промежуток. После последнего слова (`k = gaps`) промежутка нет — условие `k < gaps`. Промежуток с номером `k` получает `base + 1` пробелов, если `k < extra`, иначе `base`. Так «лишние» пробелы достаются левым промежуткам.

```ts
    result.push(line);
    i = j;
  }

  return result;
}
```

Строка готова; следующая начинается со слова `j` — первого, которое не поместилось.

## Трассировка

`words = ["This", "is", "an", "example", "of", "text", "justification."]`, `maxWidth = 16`.

**Строка 1**, `i = 0`:

```
j=0 "This":    0 + 4 + 0 = 4   <= 16 → lettersLen=4,  j=1
j=1 "is":      4 + 2 + 1 = 7   <= 16 → lettersLen=6,  j=2
j=2 "an":      6 + 2 + 2 = 10  <= 16 → lettersLen=8,  j=3
j=3 "example": 8 + 7 + 3 = 18  > 16  → стоп
count=3, gaps=2, не последняя → по ширине
spaces=16-8=8, base=4, extra=0
"This" + 4 + "is" + 4 + "an" = "This    is    an"
```

**Строка 2**, `i = 3`:

```
j=3 "example": 0 + 7 + 0 = 7   → lettersLen=7,  j=4
j=4 "of":      7 + 2 + 1 = 10  → lettersLen=9,  j=5
j=5 "text":    9 + 4 + 2 = 15  → lettersLen=13, j=6
j=6 "justification.": 13 + 14 + 3 = 30 > 16 → стоп
count=3, gaps=2; spaces=3, base=1, extra=1
k=0: "example" + 2 пробела (k < extra)
k=1: "of" + 1 пробел
k=2: "text"
→ "example  of text"
```

**Строка 3**, `i = 6`: берём `"justification."` (длина 14), `j = 7 = words.length` — последняя строка. `line = "justification."`, добиваем `16 − 14 = 2` пробела: `"justification.  "`.

Ответ совпадает с примером из условия.

## Почему это работает

**Выбор слов.** Условие цикла — ровно «слова с одиночными пробелами помещаются в `maxWidth`». Цикл останавливается на первом слове, которое уже не влезает, поэтому строка содержит **максимально возможный** префикс оставшихся слов — это и есть жадная упаковка из условия. Первое слово влезает всегда, значит каждая итерация продвигает `i` хотя бы на одно слово, и внешний цикл завершается.

**Длина строки.** В ветке 2a длина `= maxWidth` по построению (`repeat(maxWidth - line.length)`, а `line.length <= maxWidth` из условия выбора). В ветке 2b длина `= lettersLen + base · gaps + extra = lettersLen + spaces = maxWidth`.

**Равномерность.** Промежутки отличаются не больше чем на `1` (`base` или `base + 1`), и большие стоят левее меньших — ровно требование условия.

## Пограничные случаи

- **Одно слово в строке (не последней)**: `gaps = 0` → ветка выравнивания влево; без этой проверки было бы деление на ноль (`spaces / 0 = Infinity`), а строка осталась бы без добивки пробелами.
- **Последняя строка с несколькими словами**: одиночные пробелы и добивка справа (`"shall be        "`).
- **Слово длиной ровно `maxWidth`**: занимает строку целиком, `repeat(0)` добавляет пустую строку.
- **Один-единственный входной элемент**: одна последняя строка, выровненная влево.
- **Пробелы делятся нацело** (`extra = 0`): все промежутки одинаковые.

## Сложность

- **Время `O(n · maxWidth)`** в худшем случае, где `n` — число слов: строк не больше `n`, каждая собирается за `O(maxWidth)` (её длина фиксирована). Точнее — `O(L + строк · maxWidth)`, где `L` — суммарная длина слов; выбор слов внутренним `while` суммарно проходит каждое слово один раз.
- **Память `O(maxWidth)`** на текущую строку, не считая ответа; ответ занимает `O(строк · maxWidth)`.

## Типичные ошибки

1. **Не обработать строку из одного слова** отдельно → деление на `gaps = 0` (`base = Infinity`, `extra = NaN`), промежутков нет, и слово остаётся без добивки — строка короче `maxWidth`.
2. **Отдавать лишние пробелы правым промежуткам** (`k >= gaps - extra`) → нарушено правило «левые получают больше».
3. **Забыть добить последнюю строку пробелами** до `maxWidth`.
4. **Неверное условие упаковки** — не учитывать обязательные пробелы (`lettersLen + words[j].length <= maxWidth`) → в строку попадает лишнее слово, и `spaces` становится меньше числа промежутков.
5. **Выравнивать по ширине и последнюю строку** → в ней появляются множественные пробелы, а условие требует одиночные.

## Как узнать такую задачу

- Условие состоит из **набора правил форматирования** без явного алгоритмического трюка — нужна аккуратная симуляция; разбейте её на независимые шаги (выбор группы → раскладка внутри группы).
- Есть «ёмкость» строки/контейнера и требование брать **сколько влезет** — жадная упаковка.
- «Распределить как можно равномернее, остаток — левым/первым» — `floor(S / G)` и `S % G`.
- Родственные задачи: Zigzag Conversion (симуляция раскладки), Split Linked List in Parts (равномерное разбиение с остатком), Sentence Screen Fitting, Word Wrap (ДП-вариант с минимизацией неровности).
