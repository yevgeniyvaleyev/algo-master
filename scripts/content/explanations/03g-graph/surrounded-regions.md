## Задача простыми словами

Дана доска из `'X'` и `'O'`. Группа соседних (по стороне) клеток `'O'` образует область. Область **окружена**, если ни одна её клетка не лежит на краю доски. Все окружённые области нужно «захватить» — перекрасить их `'O'` в `'X'` прямо в исходной доске.

Пример:

```
X X X X        X X X X
X O O X   →    X X X X
X X O X        X X X X
X O X X        X O X X
```

Область из трёх `'O'` в центре окружена — она захвачена. Нижняя `'O'` стоит на краю — она остаётся.

## Наивный подход

Прямолинейная идея — для каждой области выяснить, касается ли она края:

```ts naive
for (каждая клетка 'O', ещё не проверенная) {
  обойти её область, собрать все клетки в список;
  если ни одна клетка не на краю — перекрасить список в 'X';
}
```

Это можно сделать за `O(m · n)`, но код получается громоздким: нужно отдельное множество `visited`, временный список клеток области, флаг «коснулись края», а перекраску делать только после **полного** обхода (нельзя красить на ходу — вдруг край найдётся в самом конце).

Ещё хуже вариант «для каждой `'O'` запустить поиск пути до края»: это `O((m · n)²)` — одни и те же клетки обходятся заново для каждой стартовой.

Лишняя работа и сложность здесь в том, что мы проверяем «окружена ли» — свойство, которое выясняется только в самом конце обхода.

## Ключевое наблюдение

Перевернём вопрос. Область **не** захватывается ровно тогда, когда в ней есть клетка на краю. Значит, все «спасённые» `'O'` — это те, что **достижимы из граничных `'O'`**.

Поэтому:

1. запускаем обход из каждой `'O'` на границе и помечаем всё достижимое временной меткой `'#'`;
2. всё, что осталось `'O'`, с краем не связано — красим в `'X'`;
3. метки `'#'` возвращаем в `'O'`.

Никаких флагов и временных списков — каждая клетка обрабатывается константное число раз.

## Техники

### Обход графа в глубину (DFS) на сетке

**Что это.** Доска — неявный граф: вершины — клетки `'O'`, рёбра — соседство по стороне. DFS из стартовой вершины посещает **всю её компоненту связности** — здесь это всю область `'O'`.

**Типичный шаблон.** На сетке соседей получают сдвигами из массива направлений `dirs` с проверкой границ; посещённые помечают прямо в сетке. Подробнее про обход в глубину — во вкладке «Теория».

**Как применяется здесь.** DFS запускается не из всех клеток, а только из граничных. Он находит все клетки, связанные с краем.

### Обход от границы (multi-source, «инверсия задачи»)

Когда спрашивают «какие клетки **не** связаны с чем-то» (с краем, с океаном, с выходом), выгоднее обойти граф **от этого «чего-то»** и пометить связанные. Всё непомеченное — ответ. Тот же приём — в задачах Pacific Atlantic Water Flow и Number of Enclaves.

### Временная метка вместо `visited`

Метка `'#'` одновременно означает «посещено» и «спасено». Она отличается и от `'O'` (обход не зайдёт повторно), и от `'X'` (в конце её легко вернуть в `'O'`). Отдельная матрица не нужна.

### Явный стек вместо рекурсии

Доска до `200 × 200` = 40 000 клеток. Рекурсивный DFS по «змейке» из `'O'` может уйти на такую глубину и переполнить стек вызовов. Явный стек (массив) делает то же самое безопасно.

## Разбор кода

```ts
function solve(board: string[][]): void {
  const m = board.length;
  const n = board[0].length;
  const dirs = [
    [1, 0],
    [-1, 0],
    [0, 1],
    [0, -1],
  ];
```

`m × n` — размеры доски. `dirs` — четыре сдвига к соседям по стороне: вниз, вверх, вправо, влево. Диагоналей нет — по условию соединяют только стороны.

```ts

    board[r][c] = '#';

```

`markSafe` — обход от одной граничной клетки. Если там `'X'` или уже `'#'` (например, угловая клетка, которую вызвали второй раз), выходим сразу. Иначе помечаем старт и кладём его в стек.

```ts

      const [cr, cc] = stack.pop()!;
      for (const [dr, dc] of dirs) {
        const nr = cr + dr;
        const nc = cc + dc;
```

Классический цикл DFS: достаём последнюю клетку стека (`pop` — поведение «в глубину») и перебираем её четырёх соседей. `!` говорит TypeScript, что `pop` здесь не вернёт `undefined` — стек непуст по условию цикла.

```ts
        if (nr >= 0 && nr < m && nc >= 0 && nc < n && board[nr][nc] === 'O') {
          board[nr][nc] = '#';
          stack.push([nr, nc]);
        }
      }
    }
  };
```

Сосед подходит, если он внутри доски и это ещё не помеченная `'O'`. Помечаем **в момент добавления** в стек — так клетка не попадёт в стек дважды от разных соседей.

```ts
  // 1. Обходим только граничные клетки: левый и правый столбцы, верхнюю и нижнюю строки
  for (let i = 0; i < m; i++) {
    markSafe(i, 0);
    markSafe(i, n - 1);
  }
  for (let j = 0; j < n; j++) {
    markSafe(0, j);
    markSafe(m - 1, j);
  }
```

Фаза 1. Первый цикл проходит левый (`0`) и правый (`n - 1`) столбцы, второй — верхнюю (`0`) и нижнюю (`m - 1`) строки. Углы попадают в оба цикла, а при `n = 1` или `m = 1` одна и та же клетка вызывается дважды — это безопасно благодаря проверке `!== 'O'` в начале `markSafe`.

```ts
  // 2. Оставшиеся 'O' не связаны с краем — захватываем их,
  //    а помеченные '#' возвращаем обратно в 'O'
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (board[i][j] === 'O') board[i][j] = 'X';
      else if (board[i][j] === '#') board[i][j] = 'O';
    }
  }
}
```

Фаза 2. Один проход по всей доске. Порядок проверок важен: сначала `'O' → 'X'`, и только в ветке `else` — `'#' → 'O'`. Если бы это были два независимых `if` в обратном порядке (`'#' → 'O'`, потом `'O' → 'X'`), только что восстановленная клетка сразу же была бы захвачена.

## Трассировка

Доска из примера (`m = n = 4`):

```
X X X X
X O O X
X X O X
X O X X
```

1. Цикл по столбцам `0` и `3`: все клетки там — `'X'`, `markSafe` сразу выходит.
2. Цикл по строкам `0` и `3`: в строке `0` всё `'X'`. В строке `3` клетка `(3,1) = 'O'` → помечаем `'#'`, стек `[(3,1)]`.
3. Достаём `(3,1)`: соседи `(4,1)` — вне доски, `(2,1) = 'X'`, `(3,2) = 'X'`, `(3,0) = 'X'`. Стек пуст.

Состояние после фазы 1:

```
X X X X
X O O X
X X O X
X # X X
```

4. Фаза 2: `(1,1)`, `(1,2)`, `(2,2)` — `'O'` → `'X'`; `(3,1)` — `'#'` → `'O'`.

```
X X X X
X X X X
X X X X
X O X X
```

Совпадает с ожидаемым ответом. Обратите внимание: центральная область ни разу не обходилась — она просто «осталась `'O'`».

## Почему это работает

- **Всё, что помечено `'#'`, спасено правильно.** Обход стартует только с граничных `'O'` и идёт только по `'O'`, значит каждая помеченная клетка лежит в одной области с граничной клеткой — такая область не окружена.
- **Всё спасаемое помечено.** Если область касается края, в ней есть граничная `'O'`. Фаза 1 вызывает `markSafe` для каждой граничной клетки, а DFS из неё посещает всю компоненту связности — всю область.
- Значит, после фазы 1 `'O'` остались ровно в окружённых областях, и фаза 2 захватывает именно их.

## Пограничные случаи

- **Доска 1×1, 1×n или m×1**: все клетки граничные, ничего не захватывается; повторные вызовы `markSafe` на той же клетке безопасны.
- **Доска 2×2**: тоже вся — граница.
- **Нет `'O'`**: обе фазы ничего не меняют.
- **Вся доска — `'O'`**: одна граничная клетка помечает всё, ничего не захватывается; стек растёт до `O(m · n)`.
- **Длинная «змейка» `'O'` от края вглубь**: спасается целиком, явный стек не переполнится.

## Сложность

- **Время `O(m · n)`**: каждая `'O'` помечается `'#'` не более одного раза и один раз попадает в стек, у неё 4 соседа. Вызовов `markSafe` — `2(m + n)`, лишние сразу выходят. Фаза 2 — ещё один проход по доске.
- **Память `O(m · n)`** в худшем случае — размер стека. Дополнительных матриц нет: роль `visited` играет метка `'#'`.

## Типичные ошибки

1. **Искать окружённые области напрямую и красить на ходу** — область может коснуться края в самом конце обхода, а часть клеток уже перекрашена.
2. **Забыть вернуть `'#'` в `'O'`** — спасённые клетки остаются с мусорной меткой.
3. **Неправильный порядок в фазе 2** (сначала `'#' → 'O'`, потом независимым `if` `'O' → 'X'`) — спасённые клетки тут же захватываются.
4. **Обходить только две стороны доски** или перепутать `m` и `n` в циклах по границе на неквадратной доске.
5. **Рекурсивный DFS** на доске `200 × 200` — риск `Maximum call stack size exceeded`.

## Как узнать такую задачу

- Сетка, области связанных клеток, и вопрос «какие области **не** касаются края / не связаны с выходом / окружены».
- Слова «захватить», «залить», «окружены», «изолированы» — сигнал запускать обход **от границы** и инвертировать ответ.
- Родственные задачи: Number of Islands (подсчёт компонент), Number of Enclaves, Pacific Atlantic Water Flow, Walls and Gates (multi-source BFS). Альтернатива для этой задачи — Union-Find с фиктивной вершиной «край».
