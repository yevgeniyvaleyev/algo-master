## Задача простыми словами

Дан массив строк `strs`. Нужно вернуть **самый длинный общий префикс** — наибольшее начало, с которого начинаются все строки. Если общего начала нет, вернуть пустую строку `""`.

Пример: `strs = ["flower", "flow", "flight"]`. Все три начинаются на `"fl"`, а дальше расходятся (`o` против `i`). Ответ `"fl"`. Для `["dog", "racecar", "car"]` ответ `""`.

## Наивный подход

Естественная идея — перебирать кандидатов-префиксов и проверять каждый:

```ts naive
let answer = '';
for (let len = 1; len <= strs[0].length; len++) {
  const prefix = strs[0].slice(0, len);
  if (strs.every((s) => s.startsWith(prefix))) answer = prefix;
  else break;
}
return answer;
```

Это верно, но каждый кандидат проверяется **с нуля**: для длины `len` мы снова сравниваем все первые `len - 1` символов, которые уже совпали на прошлом шаге, плюс создаём новую строку `slice`. Для префикса длины `L` выходит `O(n · L²)` сравнений. Лишняя работа — повторная проверка уже подтверждённых символов.

## Ключевое наблюдение

Если первые `i` символов уже совпали у всех строк, для префикса длины `i + 1` нужно проверить **только один новый символ** — `i`-й — во всех строках. Значит, идём по позициям `i = 0, 1, 2, …` и для каждой сверяем один «столбец» символов. Первое же расхождение (или конец какой-то строки) даёт ответ.

Эталоном можно взять первую строку: общий префикс не длиннее любой строки, в том числе её.

## Техники

### Вертикальное сканирование (по столбцам)

**Что это.** Представьте строки друг под другом:

```
f l o w e r
f l o w
f l i g h t
↑ ↑ ↑
0 1 2
```

Вертикальное сканирование идёт по **столбцам**: внешний цикл — позиция символа, внутренний — номер строки. Альтернатива — горизонтальное: взять префикс первой строки и укорачивать его, сравнивая со второй, третьей и так далее.

**Когда применять.** Когда ответ — общая часть нескольких последовательностей с начала, и важно остановиться как можно раньше. Вертикальный обход останавливается на **первом** расхождении и не читает лишних символов длинных строк.

**Как применяется здесь.** Столбец `i` проверяется сравнением `strs[j][i]` с `first[i]`. Подробнее о приёмах для строк — во вкладке «Теория».

### Ранний выход

Как только найдено расхождение, ответ известен окончательно — `return` прямо из вложенного цикла. Не нужны флаги и дополнительные `break`.

## Разбор кода

```ts
function longestCommonPrefix(strs: string[]): string {
  const first = strs[0];
```

Первая строка — эталон. По условию массив непустой, поэтому `strs[0]` существует. Ответ всегда будет префиксом `first`.

```ts
  // Вертикальное сканирование: проверяем i-й символ сразу во всех строках
  for (let i = 0; i < first.length; i++) {
    const ch = first[i];
```

Внешний цикл — по позициям эталона. `ch` — символ, который должен стоять на позиции `i` во всех строках, чтобы префикс удлинился.

```ts
    for (let j = 1; j < strs.length; j++) {
      // Строка закончилась или символ не совпал — префикс найден
      if (i >= strs[j].length || strs[j][i] !== ch) {
        return first.slice(0, i);
      }
    }
  }
```

Внутренний цикл — по остальным строкам (с `j = 1`: эталон с собой не сравниваем). Две причины остановиться:

- `i >= strs[j].length` — строка `j` короче, её символы кончились, префикс длиннее неё быть не может;
- `strs[j][i] !== ch` — в столбце `i` нашлось расхождение.

В обоих случаях общий префикс — ровно первые `i` символов (позиции `0..i-1` совпали у всех), возвращаем `first.slice(0, i)`. Первая проверка формально избыточна в JS (`strs[j][i]` за границей — `undefined`, а `undefined !== ch`), но делает намерение явным.

```ts
  // Первая строка целиком является префиксом всех остальных
  return first;
}

// Время: O(S), где S — суммарная длина строк (в худшем случае)
// Память: O(1) кроме строки-ответа
```

Если цикл прошёл все позиции эталона без расхождений, каждая строка начинается с `first` целиком — это и есть ответ.

## Трассировка

`strs = ["flower", "flow", "flight"]`, `first = "flower"`:

```
i=0, ch='f': "flow"[0]='f' ✓, "flight"[0]='f' ✓
i=1, ch='l': "flow"[1]='l' ✓, "flight"[1]='l' ✓
i=2, ch='o': "flow"[2]='o' ✓, "flight"[2]='i' ✗ → return "flower".slice(0, 2)
```

Ответ `"fl"`.

Конец короткой строки, `strs = ["ab", "a"]`:

```
i=0, ch='a': "a"[0]='a' ✓
i=1, ch='b': i=1 ≥ "a".length=1 → return "ab".slice(0, 1)
```

Ответ `"a"`.

Нет общего префикса, `["dog", "racecar", "car"]`: на `i = 0` символ `'r' !== 'd'`, возвращаем `"dog".slice(0, 0) = ""`.

## Почему это работает

Инвариант перед итерацией `i`: первые `i` символов `first` совпадают с первыми `i` символами каждой строки. Он верен при `i = 0` (пустой префикс общий всегда). Итерация либо подтверждает, что символ `i` у всех строк есть и равен `first[i]` (тогда инвариант верен для `i + 1`), либо находит строку, у которой символа нет или он другой — тогда префикс длины `i + 1` не общий, а длины `i` — общий по инварианту, значит ответ ровно `first.slice(0, i)`. Если дошли до конца `first`, общий префикс длины `first.length`, а длиннее он быть не может.

## Пограничные случаи

- **Одна строка**: внутренний цикл не выполняется ни разу, ответ — сама строка.
- **Пустая строка в массиве**: если это `first`, внешний цикл не выполняется, ответ `""`; если другая — на `i = 0` сработает `i >= strs[j].length`, ответ `""`.
- **Все строки одинаковые**: ответ — строка целиком.
- **Первая строка короче остальных** (`["ab", "abc"]`): цикл заканчивается по длине `first`, ответ `"ab"`.
- **Первая строка длиннее** (`["abc", "ab"]`): останавливаемся по `i >= strs[j].length`.

## Сложность

- **Время `O(S)`** в худшем случае, где `S` — суммарная длина строк: каждый символ каждой строки сравнивается не больше одного раза. Точнее — `O(n · L)`, где `L` — длина ответа плюс один столбец с расхождением.
- **Память `O(1)`**, не считая строки-ответа: только индексы и один символ.

## Типичные ошибки

1. **Возвращать `first.slice(0, i + 1)`** → в ответ попадает несовпавший символ.
2. **Не проверять длину остальных строк** → в других языках выход за границы; в JS проверка через `undefined` работает случайно.
3. **Сравнивать эталон с самим собой** (`j = 0`) — не ошибка, но лишняя работа.
4. **Забыть финальный `return first`** → при полном совпадении функция вернёт `undefined`.
5. **Собирать префикс конкатенацией** `prefix += ch` в цикле → лишние строки; хватает одного `slice` в конце.

## Как узнать такую задачу

- «Общее начало», «общий префикс» нескольких строк — вертикальное сканирование, первое расхождение даёт ответ.
- Много запросов на префиксы большого набора строк — уже повод для префиксного дерева (Trie).
- Похожие задачи: Implement Trie, Longest Common Suffix (то же с конца), Longest Word in Dictionary.
