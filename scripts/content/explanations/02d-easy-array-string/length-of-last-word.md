## Задача простыми словами

Дана строка `s` из английских букв и пробелов. Нужно вернуть длину **последнего слова** — последней непрерывной группы непробельных символов. Пробелы могут стоять в начале, в конце и по несколько подряд между словами; гарантируется, что хотя бы одно слово есть.

Пример: `s = "   fly me   to   the moon  "`. Последнее слово — `moon`, ответ `4`. Хвостовые пробелы словом не являются.

## Наивный подход

Самое короткое решение — разбить строку на слова:

```ts naive
const words = s.trim().split(/\s+/);
return words[words.length - 1].length;
```

Это верно и `O(n)` по времени, но:

- `trim` создаёт новую строку, `split` — массив из всех слов: `O(n)` дополнительной памяти;
- строка **целиком** просматривается дважды, хотя нас интересует только её конец.

Лишняя работа очевидна: чтобы узнать длину **последнего** слова, мы разбираем **все** слова, включая самое первое.

## Ключевое наблюдение

Ответ целиком определяется хвостом строки. Если встать на последний символ и идти влево, то сначала встретятся хвостовые пробелы (их нужно пропустить), затем буквы последнего слова (их нужно посчитать), а первый пробел после них (или начало строки) означает конец работы. Всё, что левее, можно не читать.

## Техники

### Сканирование с конца

**Что это.** Обход строки или массива от последнего элемента к первому одним указателем `i`, который только уменьшается. Применяется, когда ответ зависит от **конца** данных: последнее вхождение, хвостовые символы, суффиксы.

**Типичный шаблон** — несколько последовательных `while` с одним общим указателем, каждый «съедает» свою часть:

```ts naive
let i = s.length - 1;
while (i >= 0 && пропустить(s[i])) i--;
while (i >= 0 && учесть(s[i])) { обработать(s[i]); i--; }
```

Каждый цикл продолжает с того места, где остановился предыдущий, поэтому суммарно указатель проходит каждую позицию не больше одного раза.

**Как применяется здесь.** Первый цикл пропускает пробелы, второй считает буквы. Подробнее о приёмах для строк — во вкладке «Теория».

### Разбор без выделения памяти

Вместо `split`, `trim` и `slice` работаем с индексами исходной строки. Это общий приём для задач на строки с ограничением по памяти: результат вычисляется счётчиками, а не созданием подстрок.

## Разбор кода

```ts
function lengthOfLastWord(s: string): number {
  let i = s.length - 1;
```

Указатель на последний символ строки. Дальше он будет только уменьшаться.

```ts
  // Пропускаем пробелы в конце строки
  while (i >= 0 && s[i] === ' ') {
    i--;
  }
```

Первая фаза: сдвигаемся влево, пока видим пробелы. Проверка `i >= 0` стоит первой, чтобы не читать `s[-1]`. По условию в строке есть слово, поэтому цикл остановится на букве; но и без этой гарантии он корректно закончился бы на `i = -1`. После цикла `s[i]` — последняя буква последнего слова.

```ts
  // Считаем символы последнего слова, пока не встретим пробел или начало строки
  let length = 0;
  while (i >= 0 && s[i] !== ' ') {
    length++;
    i--;
  }
```

Вторая фаза: идём дальше влево и считаем непробельные символы. Остановка — либо пробел перед словом, либо начало строки (`i = -1`), если слово стоит в самом начале. Второй цикл продолжает с того же `i`, где закончил первый, — это и есть «один указатель, несколько фаз».

```ts
  return length;
}

// Время: O(n) в худшем случае, но смотрим только хвост строки
// Память: O(1) — без split и новых строк
```

Счётчик `length` и есть ответ. Остаток строки левее последнего слова не читался вовсе.

## Трассировка

`s = "  fly me  "` (длина 10; позиции: `0`–`1` пробелы, `2`–`4` — `fly`, `5` пробел, `6`–`7` — `me`, `8`–`9` пробелы):

```
старт: i=9
фаза 1: s[9]=' ' → i=8
        s[8]=' ' → i=7
        s[7]='e' → стоп
фаза 2: s[7]='e' → length=1, i=6
        s[6]='m' → length=2, i=5
        s[5]=' ' → стоп
ответ: 2
```

Слово `fly` и пробелы в начале не просматривались.

Слово в начале строки, `s = "a"`: фаза 1 сразу останавливается (`s[0] = 'a'`), фаза 2: `length = 1`, `i = -1` — выход по `i >= 0`. Ответ `1`.

## Почему это работает

После первой фазы `i` указывает на самый правый непробельный символ строки — по определению это последний символ последнего слова (такой есть по условию). Слово — максимальная группа непробельных символов подряд, поэтому оно продолжается влево до первого пробела или до начала строки. Вторая фаза проходит ровно эти символы и считает каждый по одному разу, значит `length` — длина последнего слова.

## Пограничные случаи

- **Без хвостовых пробелов** (`"Hello World"`): фаза 1 не делает ни шага, ответ `5`.
- **Одно слово без пробелов** (`"day"`): фаза 2 доходит до начала строки, ответ `3`.
- **Много пробелов между словами и в конце**: лишние пробелы между словами левее последнего слова вообще не читаются.
- **Строка из одной буквы**: ответ `1`.
- **Строка без слов** (по условию невозможна): обе фазы закончились бы на `i = -1`, ответ `0`.

## Сложность

- **Время `O(n)`** в худшем случае — например, когда вся строка одно слово или почти вся строка — пробелы в конце. Обычно же просматривается только хвост: хвостовые пробелы плюс последнее слово. Указатель проходит каждую позицию не больше одного раза.
- **Память `O(1)`**: индекс и счётчик, новые строки и массивы не создаются.

## Типичные ошибки

1. **`s.split(' ')` без `trim`** → при хвостовых пробелах последний элемент массива — пустая строка, ответ `0`.
2. **Пропустить первую фазу** → при `"moon  "` счёт сразу упрётся в пробел и вернёт `0`.
3. **Порядок проверок `s[i] !== ' ' && i >= 0`** → чтение `s[-1]`; в JS это `undefined`, и ошибки нет, но в других языках — выход за границы.
4. **Считать длину первого слова** при обходе с начала без сброса счётчика на каждом новом слове.

## Как узнать такую задачу

- Вопрос про **последний** элемент, суффикс или хвост строки — сканируйте с конца, а не разбирайте всю строку.
- Ограничение на память или желание не создавать подстроки — работа с индексами вместо `split`/`slice`.
- Похожие задачи: Reverse Words in a String, Plus One (перенос с конца), Backspace String Compare (сравнение с конца).
