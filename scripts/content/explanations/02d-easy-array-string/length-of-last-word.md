## Задача простыми словами

Дана строка `s` из английских букв и пробелов. Нужно вернуть **длину последнего слова**. Слово — это непрерывный кусок без пробелов. Пробелы могут стоять в начале, в конце и по несколько штук подряд.

Примеры: `"Hello World"` → последнее слово `"World"`, ответ `5`. `"   fly me   to   the moon  "` → последнее слово `"moon"`, ответ `4` (пробелы в конце не считаются).

## Наивный подход

Первая мысль — разбить строку по пробелу и взять последний элемент:

```ts naive
const words = s.split(' ');
return words[words.length - 1].length;
```

Для `"Hello World"` это работает, но для `"fly me   to   the moon  "` — нет. `split(' ')` режет по **каждому** пробелу, поэтому два пробела подряд дают пустую строку между ними, а пробелы в конце — пустые строки в хвосте массива: `[..., 'moon', '', '']`. Последний элемент — `''`, и ответ `0` вместо `4`. Проблема не в идее «разбить на слова», а в том, что пробелы нужно обрабатывать аккуратнее.

## Ключевое наблюдение

Пустые «слова» появляются по двум причинам:

1. **пробелы по краям строки** — их убирает `trim()`;
2. **несколько пробелов подряд** — их склеивает регулярное выражение `/\s+/` («один или больше пробельных символов»), если передать его в `split`.

После `s.trim().split(/\s+/)` получается чистый массив настоящих слов, и последнее слово — просто последний элемент.

## Техники

### Разбиение строки на слова: `trim` + `split(/\s+/)`

**Что это.** Стандартная идиома для «разрезать текст на слова»:

- `trim()` возвращает копию строки без пробелов в начале и в конце;
- `split(/\s+/)` режет по любой **группе** пробелов, табуляций и переводов строк, поэтому между соседними словами не остаётся пустых элементов.

**Типичный шаблон:**

```ts naive
const words = text.trim().split(/\s+/);
```

Важно делать `trim()` **до** `split`: иначе ведущий пробел даст пустой первый элемент (`' a b'.split(/\s+/)` → `['', 'a', 'b']`). Та же идиома нужна в Reverse Words in a String, Word Pattern, подсчёте слов.

**Как применяется здесь.** Разбиваем строку на слова и берём длину последнего. Подробнее о строках — во вкладке «Теория».

## Разбор кода

```ts
function lengthOfLastWord(s: string): number {
  // trim убирает пробелы по краям, split(/\s+/) режет по любой
  // группе пробелов — так несколько пробелов подряд не дают пустых слов
  const words = s.trim().split(/\s+/);
```

Сначала `trim()` срезает пробелы с обоих концов: `"   fly me   to   the moon  "` превращается в `"fly me   to   the moon"`. Затем `split(/\s+/)` режет по каждой группе пробелов, сколько бы их ни было: получаем `['fly', 'me', 'to', 'the', 'moon']`. Пустых строк в массиве нет.

```ts
  // Берём последнее слово и возвращаем его длину
  return words[words.length - 1].length;
}
```

Последнее слово — элемент с индексом `words.length - 1`. По условию в строке есть хотя бы одно слово, поэтому массив не пуст и этот элемент существует. Возвращаем его длину.

## Трассировка

`s = "   fly me   to   the moon  "`:

1. `s.trim()` → `"fly me   to   the moon"`.
2. `split(/\s+/)` → `['fly', 'me', 'to', 'the', 'moon']`.
3. `words[4] = 'moon'`, длина `4`.

`s = "day   "`:

1. `trim()` → `"day"`.
2. `split(/\s+/)` → `['day']`.
3. `words[0] = 'day'`, ответ `3`.

`s = "a"`: `trim()` ничего не меняет, массив `['a']`, ответ `1`.

## Почему это работает

После `trim()` строка начинается и заканчивается буквой (слово в строке гарантировано). Значит, каждая группа пробелов в ней стоит **между двумя словами**. `split(/\s+/)` разрезает строку ровно по этим группам, и каждый кусок между разрезами — непрерывная последовательность букв, то есть ровно одно слово. Пустых кусков быть не может: пустой кусок возник бы только между двумя соседними разрезами или у края строки, а соседние пробелы склеены в одну группу, края же очищены `trim()`.

Порядок слов сохраняется, поэтому последний элемент массива — последнее слово строки.

## Пограничные случаи

- **Пробелы в конце** (`"day   "`): срезаются `trim()`, ответ `3`.
- **Пробелы в начале и между словами** (`"  a  bc  "`): массив `['a', 'bc']`, ответ `2`.
- **Одно слово без пробелов** (`"a"`): массив из одного элемента.
- **Строка из одних пробелов** запрещена условием (слово есть всегда); иначе получили бы `['']` и ответ `0`, что тоже разумно.

## Сложность

- **Время `O(n)`**: `trim` и `split` один раз проходят по строке.
- **Память `O(n)`**: новая строка после `trim` и массив всех слов.

**Follow-up на собеседовании — `O(1)` памяти.** Сканировать строку с конца: пропустить хвостовые пробелы, затем считать символы, пока не встретится пробел или начало строки. Так не создаются новые строки, и просматривается только хвост:

```ts naive
let i = s.length - 1;
while (i >= 0 && s[i] === ' ') i--;
let length = 0;
while (i >= 0 && s[i] !== ' ') {
  length++;
  i--;
}
return length;
```

## Типичные ошибки

1. **`split(' ')` без `trim` и без регулярки** → пустые строки в массиве, для `"moon  "` ответ `0`.
2. **`split(/\s+/)` без `trim`** → пробелы в конце дают пустой последний элемент: `"moon  ".split(/\s+/)` → `['moon', '']`.
3. **`trim` только в конце (`trimEnd`) и `split(' ')`** → хвост чистый, но двойные пробелы в середине всё равно дают пустые элементы; для последнего слова это не мешает, но такой код легко сломать при изменении задачи.
4. **`words.pop()` без проверки типа** → в TypeScript `pop()` возвращает `string | undefined`, нужен `!` или индекс.
5. **Считать длину всей строки минус индекс последнего пробела** → не учитывает пробелы в конце.

## Как узнать такую задачу

- Нужно что-то сделать **со словами** строки, а пробелы могут стоять где угодно и по несколько штук — идиома `trim().split(/\s+/)`.
- Нужен только **конец** строки и просят `O(1)` памяти — сканирование с конца указателем.
- Родственные задачи: Reverse Words in a String, Word Pattern, Longest Common Prefix, Valid Palindrome.
