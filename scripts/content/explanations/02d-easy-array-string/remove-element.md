## Задача простыми словами

Дан массив `nums` и число `val`. Нужно «удалить» из массива все вхождения `val` **на месте** и вернуть `k` — сколько элементов осталось. Проверяется только то, что первые `k` ячеек содержат все элементы, не равные `val` (в любом порядке); что лежит дальше — неважно.

Пример: `nums = [3, 2, 2, 3]`, `val = 3`. Ответ `k = 2`, а начало массива — `[2, 2, ...]`.

## Наивный подход

Буквально удалять элементы: найти `val` и вырезать его через `splice`:

```ts naive
for (let i = 0; i < nums.length; ) {
  if (nums[i] === val) nums.splice(i, 1);
  else i++;
}
return nums.length;
```

Это работает, но каждый `splice` **сдвигает весь хвост массива** на одну позицию влево — `O(n)` операций. Если удаляемых элементов много (например, весь массив из `val`), выходит `O(n²)`. Лишняя работа: один и тот же «хороший» элемент сдвигается много раз — по шагу на каждый `val` перед ним, хотя мог бы сразу переехать на финальную позицию.

Другой простой вариант — собрать хорошие элементы в новый массив через `filter`, а потом скопировать обратно. Это `O(n)` по времени, но `O(n)` по памяти, а задача просит работать на месте.

## Ключевое наблюдение

Финальная позиция каждого «хорошего» элемента известна сразу: это **количество хороших элементов, встреченных до него**. Значит, достаточно держать счётчик `k` и копировать очередной хороший элемент прямо в `nums[k]`. Каждый элемент перемещается не больше одного раза.

Копирование безопасно: хороших элементов до позиции `i` не больше, чем вообще элементов до неё, поэтому `k <= i` — запись никогда не обгоняет чтение.

## Техники

### Быстрый и медленный указатели (чтение и запись)

**Что это.** Два индекса идут по массиву в одном направлении: «быстрый» `i` читает каждый элемент, «медленный» `k` показывает, куда записать следующий элемент результата. Префикс `nums[0..k-1]` всегда содержит готовый результат.

**Типичный шаблон:**

```ts naive
let k = 0;
for (let i = 0; i < nums.length; i++) {
  if (оставить(nums[i])) nums[k++] = nums[i];
}
return k;
```

Подходит для любой «фильтрации на месте»: удалить элементы по условию, сжать дубликаты, сдвинуть нули в конец (Move Zeroes).

**Как применяется здесь.** Условие «оставить» — `nums[i] !== val`. Подробнее о двух указателях — во вкладке «Теория».

### Модификация на месте с «мусорным хвостом»

Во многих задачах LeetCode «удаление» означает не уменьшение длины массива, а возврат новой длины `k`. Всё за пределами `k` — мусор, который проверяющий код игнорирует. Это позволяет не тратить время на очистку или настоящее удаление.

## Разбор кода

```ts
function removeElement(nums: number[], val: number): number {
  // k — индекс, куда записываем следующий «оставляемый» элемент
  let k = 0;
```

`k` — одновременно позиция следующей записи и количество уже оставленных элементов. Пока ничего не оставили, `k = 0`.

```ts
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== val) {
      // Элемент нужно оставить — переносим его в начало массива
      nums[k] = nums[i];
      k++;
    }
```

Быстрый указатель `i` проходит каждый элемент ровно один раз. Если элемент не равен `val`, копируем его в `nums[k]` и сдвигаем `k`. Пока удаляемых элементов не встречалось, `k === i`, и присваивание `nums[k] = nums[i]` записывает элемент сам в себя — это безвредно и проще лишней проверки.

```ts
    // Иначе просто пропускаем: элемент «удалён»
  }
```

Для `nums[i] === val` ничего не делаем: `k` стоит на месте, и ячейка `nums[k]` позже будет перезаписана следующим хорошим элементом (или останется в мусорном хвосте).

```ts
  // Первые k элементов — все значения, не равные val
  return k;
}

// Время: O(n) — один проход
// Память: O(1) — меняем массив на месте
```

После цикла `k` равно числу хороших элементов, и все они лежат в `nums[0..k-1]` в исходном порядке.

## Трассировка

`nums = [0, 1, 2, 2, 3, 0, 4, 2]`, `val = 2`:

```
i=0: 0 ≠ 2 → nums[0]=0, k=1   [0,1,2,2,3,0,4,2]
i=1: 1 ≠ 2 → nums[1]=1, k=2   [0,1,2,2,3,0,4,2]
i=2: 2 = val → пропуск, k=2
i=3: 2 = val → пропуск, k=2
i=4: 3 ≠ 2 → nums[2]=3, k=3   [0,1,3,2,3,0,4,2]
i=5: 0 ≠ 2 → nums[3]=0, k=4   [0,1,3,0,3,0,4,2]
i=6: 4 ≠ 2 → nums[4]=4, k=5   [0,1,3,0,4,0,4,2]
i=7: 2 = val → пропуск
```

Возвращаем `k = 5`; первые пять ячеек — `[0, 1, 3, 0, 4]`. Хвост `[0, 4, 2]` — мусор, его никто не смотрит.

Короткий пример из условия, `nums = [3, 2, 2, 3]`, `val = 3`: `i = 0` пропуск, `i = 1` → `nums[0] = 2`, `k = 1`, `i = 2` → `nums[1] = 2`, `k = 2`, `i = 3` пропуск. Ответ `2`, массив `[2, 2, 2, 3]`.

## Почему это работает

Инвариант перед каждой итерацией: `nums[0..k-1]` — это все элементы из `nums[0..i-1]`, не равные `val`, в исходном порядке, и `k <= i`.

- В начале `k = i = 0` — обе части пустые.
- Если `nums[i]` хороший, он дописывается в конец префикса, `k` и `i` оба растут на 1 — инвариант сохраняется.
- Если плохой, растёт только `i` — префикс по-прежнему содержит все хорошие элементы из просмотренной части.

Так как `k <= i`, запись в `nums[k]` попадает в уже прочитанную ячейку и не портит непрочитанные данные. После цикла `i = n`, и префикс длины `k` — ровно ответ.

## Пограничные случаи

- **Пустой массив**: цикл не выполняется, ответ `0`.
- **Все элементы равны `val`**: ни одной записи, ответ `0`.
- **`val` не встречается**: каждый элемент записывается сам в себя, ответ `n`.
- **`val` только в конце**: все записи «на место», последние элементы просто пропускаются.

## Сложность

- **Время `O(n)`**: один проход, на каждом шаге одно сравнение и не больше одной записи.
- **Память `O(1)`**: только два индекса, массив меняется на месте.

## Типичные ошибки

1. **`splice` внутри цикла `for` с `i++`** → после удаления следующий элемент сдвигается на позицию `i` и пропускается; плюс `O(n²)`.
2. **Возвращать `nums.length`** вместо `k` → длина массива не менялась, ответ неверный.
3. **Сдвигать `k` и для удаляемых элементов** → в префикс попадает `val`.
4. **Пытаться «очистить» хвост** или заполнить его нулями — лишняя работа, проверка его не смотрит.
5. **Путать с вариантом «обмен с концом»**: в нём при встрече `val` элемент заменяют последним и уменьшают длину, **не увеличивая `i`** — иначе пропустится перенесённый элемент.

## Как узнать такую задачу

- «Удалите элементы **на месте**», «верните новую длину», «порядок оставшихся не важен / должен сохраниться» — шаблон указателей чтения и записи.
- Нужно отфильтровать массив без дополнительной памяти.
- Похожие задачи: Remove Duplicates from Sorted Array (I и II), Move Zeroes, Sort Array By Parity.
