## Задача простыми словами

Дан массив целых чисел `nums`. Нужно найти **непустой непрерывный** подмассив с наибольшей суммой и вернуть эту сумму (сам подмассив возвращать не нужно).

Пример: `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`. Лучший кусок — `[4, -1, 2, 1]`, его сумма `6`. Если все числа отрицательные, например `[-3, -1, -2]`, ответ — `-1`: пустой подмассив брать нельзя.

## Наивный подход

Перебрать все начала `i` и для каждого наращивать конец `j`, поддерживая сумму:

```ts naive
let best = -Infinity;
for (let i = 0; i < nums.length; i++) {
  let sum = 0;
  for (let j = i; j < nums.length; j++) {
    sum += nums[j];
    best = Math.max(best, sum);
  }
}
return best;
```

Это `O(n²)`: при `n = 10⁵` — около 5 миллиардов сложений. Где лишняя работа? Для каждого нового начала `i` мы заново суммируем те же элементы, хотя уже знаем, что, например, начало с отрицательной накопленной суммой «тащить» бессмысленно. Мы не используем информацию, полученную на предыдущих шагах.

## Ключевое наблюдение

Посмотрим на подмассивы, которые **заканчиваются в позиции `i`**. Лучший из них либо состоит из одного `nums[i]`, либо продолжает лучший подмассив, заканчивающийся в `i - 1`:

```
cur(i) = max(nums[i], cur(i - 1) + nums[i])
```

Иначе говоря: если накопленная сумма слева **отрицательна**, она только мешает — выгоднее начать заново с `nums[i]`. Ответ — максимум `cur(i)` по всем `i`. Всё считается за один проход и `O(1)` памяти.

## Техники

### Алгоритм Кадане

**Что это.** Частный случай динамического программирования: состояние — «лучшая сумма отрезка, оканчивающегося здесь», переход — «продолжить или начать заново». Поскольку `cur(i)` зависит только от `cur(i - 1)`, вся таблица ДП сворачивается в одну переменную.

**Типичный шаблон:**

```ts naive
let cur = 0, best = -Infinity;
for (const x of nums) {
  cur = Math.max(x, cur + x);   // продолжить или начать заново
  best = Math.max(best, cur);   // лучший из всех концов
}
```

**Когда применять.** Нужен лучший **непрерывный** отрезок по сумме (или по другой «аддитивной» величине): максимальная прибыль, наибольшая сумма, минимальная сумма — для минимума меняют `max` на `min`. Подробнее — во вкладке «Теория» (алгоритм Кадане).

**Как применяется здесь.** Ровно по шаблону: `cur` — лучшая сумма отрезка, оканчивающегося на текущем элементе, `best` — глобальный ответ.

### Разделяй и властвуй (follow-up, для сравнения)

Условие предлагает и вариант через деление пополам: лучший отрезок лежит слева, справа или пересекает середину. Это `O(n log n)` (или `O(n)` с четвёркой «сумма, лучший префикс, лучший суффикс, лучший отрезок»). Бандл-решение использует Кадане — он короче и быстрее.

## Разбор кода

```ts
function maxSubArray(nums: number[]): number {
  // cur — лучшая сумма подмассива, который заканчивается в текущей позиции
  let cur = 0;
```

`cur = 0` перед первым элементом — это «пустой отрезок». На первом шаге `Math.max(x, 0 + x) = x`, так что нулевое начальное значение не влияет на ответ: в `best` попадёт сумма настоящего непустого отрезка.

```ts
  // best — лучшая сумма среди всех подмассивов; -Infinity, чтобы
  // корректно обработать массив из одних отрицательных чисел
  let best = -Infinity;
```

Если начать с `best = 0`, то для `[-3, -1, -2]` ответ был бы `0` — сумма пустого подмассива, которая запрещена. `-Infinity` гарантирует, что первый же `cur` её заменит.

```ts
  for (const x of nums) {
    // Либо продолжаем предыдущий отрезок, либо начинаем новый с x:
    // отрицательная накопленная сумма только уменьшила бы результат
    cur = Math.max(x, cur + x);
    best = Math.max(best, cur);
  }
```

Сердце алгоритма. `cur + x` — продлить лучший отрезок, заканчивающийся на предыдущем элементе; `x` — начать новый. Выбор `x` происходит ровно тогда, когда `cur < 0`. Затем обновляем глобальный максимум: лучший отрезок обязан где-то заканчиваться, и в тот момент `best` его «увидит».

```ts
  return best;
}
```

Возвращаем лучшую сумму среди всех позиций конца.

## Трассировка

`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`:

```
x=-2: cur=max(-2, 0-2)=-2   best=-2
x= 1: cur=max( 1,-2+1)= 1   best= 1   (сбросили отрицательное -2)
x=-3: cur=max(-3, 1-3)=-2   best= 1
x= 4: cur=max( 4,-2+4)= 4   best= 4   (снова сброс, новый отрезок с 4)
x=-1: cur=max(-1, 4-1)= 3   best= 4
x= 2: cur=max( 2, 3+2)= 5   best= 5
x= 1: cur=max( 1, 5+1)= 6   best= 6   ← отрезок [4,-1,2,1]
x=-5: cur=max(-5, 6-5)= 1   best= 6
x= 4: cur=max( 4, 1+4)= 5   best= 6
```

Ответ `6`. Обратите внимание на `x = -1`: отрезок не обрывается, хотя элемент отрицательный, — накопленная сумма `4` его «перевешивает», и это окупается дальше.

Пример из отрицательных чисел, `[-3, -1, -2]`: `cur` принимает значения `-3, -1, -2` (каждый раз выгоднее начать заново), `best = -1`.

## Почему это работает

Инвариант: после обработки `nums[i]` переменная `cur` равна максимальной сумме непустого подмассива, **оканчивающегося ровно в `i`**, а `best` — максимуму таких значений для всех позиций `0..i`.

Доказательство перехода: любой подмассив, оканчивающийся в `i`, — это либо `[nums[i]]`, либо подмассив, оканчивающийся в `i - 1`, плюс `nums[i]`. Лучший из второго вида — `cur(i - 1) + nums[i]`, потому что прибавление одного и того же `nums[i]` не меняет порядок сумм. Значит, `cur(i) = max(nums[i], cur(i - 1) + nums[i])` — ровно строка кода.

Любой подмассив где-то заканчивается, поэтому максимум `cur(i)` по всем `i` — это ответ задачи.

## Пограничные случаи

- **Все числа отрицательные**: ответ — наибольший элемент; это обеспечивает `best = -Infinity` (а не `0`).
- **Один элемент**: `cur = best = nums[0]`.
- **Все числа положительные**: отрезок никогда не сбрасывается, ответ — сумма всего массива.
- **Нули**: не мешают, `max` корректно обрабатывает равенства.
- **Переполнения нет**: `|сумма| ≤ 10⁵ · 10⁴ = 10⁹`, это безопасно для `number`.

## Сложность

- **Время `O(n)`**: один проход, на каждом элементе два `Math.max`.
- **Память `O(1)`**: две переменные; таблица ДП не нужна, так как каждое состояние зависит только от предыдущего.

## Типичные ошибки

1. **`best = 0`** → для массива из отрицательных чисел возвращается `0` (пустой подмассив).
2. **Сбрасывать `cur` в `0` при отрицательном элементе**, а не при отрицательной сумме → обрывается выгодный отрезок вроде `[4, -1, 2, 1]`.
3. **Обновлять `best` до пересчёта `cur`** → последний элемент не учитывается.
4. **Путать подмассив и подпоследовательность**: для подпоследовательности ответ — сумма всех положительных, это другая задача.
5. **Писать `cur = Math.max(0, cur + x)` и возвращать `best`** без отдельной обработки → снова ответ `0` на отрицательных данных.

## Как узнать такую задачу

- «Максимальная/минимальная сумма **непрерывного** подмассива», «лучший отрезок», «максимальная прибыль за период».
- Ответ для отрезка, заканчивающегося в `i`, выражается через ответ для `i - 1` — признак ДП, сворачиваемого в одну переменную.
- Родственные задачи: Maximum Sum Circular Subarray (Кадане для максимума и минимума), Maximum Product Subarray (храним и максимум, и минимум), Best Time to Buy and Sell Stock (Кадане на разностях цен).
